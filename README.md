# MUMU CIRCUIT

**최신 수정 — GT 조향·바퀴:** 중속 회전반경 개선, 앞바퀴 개별 애커먼 각도, 전후진 바퀴 회전 방향과 차체/바퀴 보간 일치, 복귀 시 접지 상태 초기화. 정차 후 **바퀴 점검**에서 실제 각도를 확인할 수 있습니다. [비판적 진단·설계·계측 기록](docs/VEHICLE_HANDLING_REDESIGN.md). 현재 `npm run check`는 **35개 시험 + 빌드**이며 아래 시험 개수는 각 단계의 과거 기록입니다.

**최신 구현 — 바람곶 해안 공도:** 차고의 **해안도로 드라이브 →**에서 항구→해안 S커브→갈림길→전망대→회차→항구 귀환을 주행할 수 있습니다. 전망대 편도 약 1.14km, 왼쪽 회차 쉼터도 연결했습니다. 새 스토리 2장이 아니라 **공도 1단계**입니다. [구현·비판적 검수 기록](docs/COAST_ROAD_STAGE1.md). 최신 시험은 **27개 + 빌드**, 브라우저 왕복 검증은 `scripts/verify-coast.cjs`입니다.

**최신 방향: 서킷 → 스토리 기반 해안 공도.** [공도·스토리 전환안](docs/STORY_PUBLIC_ROAD_PLAN.md)을 우선합니다. 차고의 **첫 번째 호출 시작 →**에서 15초 실시간 컷신, 무전 자막, 약 250m 첫 의뢰와 정차 완료를 체험할 수 있습니다. 아래 서킷 중심 소개는 이전 단계 기록입니다. 현재 통행 AI·교차로·다음 챕터는 없습니다. 기존 GT 테스트 주행과 차고는 보존했습니다.

최신 검증 명령: `npm run check`(20개 시험 + 빌드), `scripts/verify-story.cjs`(스토리 실제 주행 검증).

**최신 시각 개선:** 출발부 400m에 차고와 같은 석재·철골·배관·보도·배수구를 적용한 [항구 도로 디테일 시안](docs/HARBOR_ROAD_DETAIL.md)을 구현했습니다. 전체 코스 미술은 아직 미완성이며, 나머지 구간은 고속 계측 시험장입니다.

**다음 작업 기준:** [레이싱 체감·연출 작업 계획](docs/DRIVING_EXPERIENCE_PLAN.md). 레퍼런스의 외형을 복제하지 않고, 항구·해안 정체성을 유지하며 코너/드리프트/탈출 가속의 카메라·소리·피드백을 개선합니다. 계획 단계이며 다음 구현 묶음은 계측 + 코너 시험 구간입니다.

브라우저 레이싱 게임 재구축 프로젝트입니다. 현재는 **외부 모델·텍스처 없이 코드로 만든 GT와 항구 차고**, 그리고 **Rapier 기반 차량 1대 주행 시험장**을 실행합니다. 차고의 `GT 테스트 주행 →` 버튼으로 시작합니다. 완성 서킷·AI 레이스는 아직 없습니다.

**개편 방향은 스타일라이즈드 해안 서킷 + 산업 항구 디오라마 차고입니다.** 현재 차고는 2차 개선 시안입니다. 작동 셔터·부두와 바다·환기팬, 저장되는 색상/환경 설정, 포토 모드, 카메라 4구도를 제공합니다. [차고 발전 계획과 반영 결과](docs/GARAGE_EVOLUTION.md)를 현재 차고 기준으로 확인하세요. 전체 제작 기준은 [신규 제작 실행안](docs/PRODUCTION_PLAN.md), 첫 구현 이력은 [차고 시안 기록](docs/GARAGE_PROTOTYPE.md)에 보존합니다.

탐험·복구 게임 제안은 보류했으며 [대안 기획 이력](docs/REPAIR_TOWN_GAME_PLAN.md)으로만 보존합니다.

삭제 범위와 복구용 백업은 [코드 초기화 기록](docs/CODE_RESET.md)을 확인하세요. `npm run check`는 설정 저장 4개 + 차량 물리·화면 조향·항구 충돌 8개 + 속도감 3개 시험과 빌드를 실행합니다. 브라우저 검증은 `scripts/verify-garage.cjs`, `scripts/verify-driving.cjs`, `scripts/verify-speed-feel.cjs`, `scripts/verify-harbor-road.cjs`로 별도 실행합니다. [차량 1단계 기록](docs/VEHICLE_STAGE1.md), [속도감 개선 2단계](docs/SPEED_FEEL_STAGE2.md)에 현재 구현과 제한을 정리했습니다.

속도감 개선: 고속 카메라 추격 지연 제거, 노면 무늬와 가까운 반사 표지 추가, 엔진음·바람 소리 합성. 소리는 기본 꺼짐이며 주행 화면의 **소리 켜기 / 볼륨**에서 조절합니다.

주행 조작: **W/↑ 가속, S/↓ 제동 후 후진, A·D/←·→ 조향, B 제동 전용, Space 핸드브레이크, R 시작점 복귀, Esc 일시정지.** 터치 버튼도 지원합니다. 18초 가속 시험에서 실제 232.2km/h를 측정했습니다. 현재 변경은 로컬이며 운영 배포는 별도입니다.

## 삭제 전 구현 이력 — 현재 실행되지 않음

- 2개 폐쇄형 서킷과 독립 3D 차고
- Rapier 동적 차체 및 4륜 레이캐스트 서스펜션
- 가속, 제동, 후진, 니트로, 속도별 조향각, 드리프트 접지력
- 차량·배리어 충돌과 고속 주행 CCD
- 동일한 물리 규칙을 사용하는 체크포인트 기반 AI 3대
- GLB 차량 자동 크기 정규화
- 개인 최고 기록 고스트
- Kenney CC0 차량·도로·토이 트랙 에셋
- 차량 GLB 컬러맵 보존과 자동 크기 정규화
- FPS 저하 시 픽셀 비율·블룸·차고 그림자를 자동 조정하는 적응형 그래픽
- 실제 Rapier 가속·제동·후진·조향 동역학 및 배포 번들 예산 자동 검사

```bash
npm install
npm run dev
npm run check
```
