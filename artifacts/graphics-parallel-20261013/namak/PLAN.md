# 남악 시티 시각 고도화 후보 · 2026-10-13

## 목표와 범위

기존 남악의 평평한 녹지·원색 유리·밝기 차가 없는 외벽을 더 읽기 쉬운 도시 경관으로 다듬는다. 2.93km 사진 기반 트랙과 도로·장벽·진행 경로·물리는 그대로 둔다. 실제 GPS/측량 도시 복제라고 표현하지 않는다.

전체 회귀의 입력이 고정되어 있어 현재 구현은 `namakVisuals.candidate.mjs`와 후보 시험으로 준비한다. 부모 에이전트의 시작 신호 이후 소스/시험으로 반영하며 공통 런타임 연결과 전체 검사는 부모가 담당한다. 배포·커밋·푸시는 이 하위 작업에서 하지 않는다.

원본 사진은 조사 폴더의 `jeonnam-park-1.jpg`, `jeonnam-park-5.jpg`, `jndc-oryong-render.jpg`에 있고 실제 로컬 `view_image`로 확인했다. 원본 다운로드의 URL·형식·바이트는 `photo-fetch.json`에 있다. 공식 전남도 페이지는 공공누리 제1유형을 표시한다. 사진은 조사 증거이며 게임 다운로드에 포함하지 않는다.

## 구현 후보

- 석재 보도는 기존 0.6m 정사각 줄눈을 0.9×0.6m 판석과 약한 판별색으로 바꾸며 화면 미분값(`fwidth`)으로 멀리서 줄눈이 깜빡이지 않게 한다. 낮음은 기존 단순 줄눈을 유지한다.
- 외벽/콘크리트는 세로 면에 한해 판넬 줄눈·약한 기단 오염을 준다. 조각 수·정점·충돌 면은 늘리지 않는다.
- 유리·외벽·잔디·잎을 각각 중성 회색/따뜻한 크림/청록/올리브의 재질로 분리한다. 화면 전체 필터나 추가 saturation은 적용하지 않는다. 기존 셰이더 질감과 색 훅을 보존한다.
- 기존 도로 밖 가로수 62그루의 큰 다각형 덩어리를 작고 부드러운 잎 덩어리로 보완한다. 공유 기하1개/재질1개와 인스턴싱,128m 공간 셀을 사용한다. 나무의 기존 기하는 그대로 두고 모든 새 잎이 레이스 장벽보다 바깥에 있는지 시험한다.
- 실시간 조명/그림자 추가0, 새 사진/텍스처 다운로드0. 높음은 최대12셀·9잎 덩어리/그루·230m, 보통은8셀·5덩어리/그루·155m, 낮음은 추가 기하0. 셀 선택은0.2초 간격이고 GLSL 상세는 품질 uniform으로 조절한다.
- 생명 주기 종료 시 새 인스턴스 버퍼/공유 기하/재질을 정확히 한 번 해제하고, 원래 재질의 셰이더 훅·색·거칠기·금속성을 복원한다.

## 검증 계획

1. 실제 GLB의 모든 정점/인덱스/변환/충돌 extras 불변, 새 기하의 장벽 밖 거리, 품질별 드로 호출/기하 상한, 기존 질감과 셰이더 합성, 원본 자원 보존·1회 해제 시험.
2. 후보와 소스 반영본의 명시적 비교 및 관련 시험. 전체 `npm run check`는 부모 에이전트가 통합 후 수행한다.
3. 부모의 격리 headless Edge/WebGL2 검수에서 셰이더 컴파일·같은 위치 전후 화면·네 크기 UI/도로 시야·정해진 조건 프레임 계측을 확인한다. CUA는 이전 연결 실패/사용자 보류 결정에 따라 쓰지 않는다.

Node 시험·기하 상한은 실제 브라우저 프레임 검증과 다르다. 화면 검증/프레임 수치를 실행하지 않은 상태에서 시각 완성·FPS 향상·실기기 지원을 주장하지 않는다.
