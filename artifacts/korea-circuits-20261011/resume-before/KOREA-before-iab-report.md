## 화면 검수에서 발견한 수정

- 야간에 낮 하늘 환경 반사광이 적용돼 건물·차가 과하게 밝았다. 야간 환경은 실내 PMREM으로 바꾸고 야간의 태양 그림자 패스를 없앴다. 도로 위 불투명 흰 조명 사각형도 제거했다. 도로·차선은 실제 조명과 반사 재질로 보인다.
- 간판 루트가 모두 원점에 있어 거리별 가리기가 잘못됐다. 각 간판 위치로 루트를 이동하며 메시의 세계 위치는 유지했다. 표식 초기화가 세계 전체의 그림자를 끄지 않게 범위도 수정했다. 시작점에서 보이는 표식 수는6→1로 바뀌었다.
- 성삼재 도로·숲 아래에 도로를 가리지 않는 지형과 절토 가장자리를 추가했다. 주행 충돌체와 경로 파일이 이전 물리 검증 입력과 바이트 단위로 같은지 확인했다.
- 차고의 코스 링크·버튼은1280×720,1024×768,844×390,667×375에서 화면 밖 잘림0 / 버튼 겹침0. PNG와 수치를 저장했다. 레이스 HUD 전체·메뉴·완주 흐름 검사는 계속 진행 중이며, 휴대폰 실기기 검증이 아니다.
- 최신 코스·야간·메달·로딩 계측을 포함한 `npm run check`가 Colab CPU에서 **226개 통과 / 실패0개**, 검사160.96초·웹 빌드3.17초로 완료됐다. 실제 로그는 `full-check-2.log`다. 첫 전체 실행의225개 중2개 실패는 Git LFS 원본이 포인터였던 환경 문제와 증거 저장 폴더 생성 누락이었다. 실제 LFS 원본을 받아 검증하고 시험에서 폴더를 만들도록 수정했다. 검사 기준은 유지했다.

## 초기 로딩·성능·연결 점검 (재개 전 상태)

- `loading-budgets.json`은 최초 수출본의 **비압축 파일 크기 합계**다. 공통 차량8종·차고·운전석·코스·경로를 합치면 해안22.90MB, 남악26.34MB, 여수9.38MB, 성삼재12.13MB였다. 재수출본 GLB는 위 표처럼 조금 줄었다. 네트워크 전송량·처음 로드 시간·JS/CSS·음악·캐시를 포함한 실측으로 간주하지 않는다.
- Colab 상태 확인과 연결 화면 요청을 수행했으나 `browser_connected:false`; 노트북 도구 목록 요청도 연결 해제 오류로 실패했다. 원격 CPU/GPU 계산을 수행하지 않았다. 반복 레이스의 실행 환경 질문은 사용자 답변이 필요한 상태다.
- 로컬16GB 메모리 중 가용 메모리는 관찰 시 약492MB였다. 브라우저의 변경 전 렌더링 계측 요청이 시간 초과로 실패했다. 동시 작업 부하의 영향 여부는 확정하지 않았다. 프레임·성능의 전후 비교 수치는 없으며 기존 코스 성능 회귀가 확인됐다고도 주장하지 않는다.

## 완료하지 않은 항목·다음 작업

최신 GLB는 여수3,480,804 bytes / 성삼재9,539,688 bytes로 각각25MB 이하이다. 전체 회귀·빌드는 통과했다. 1단계 남은 검증은 산악 지형·야간 커브 화면 검수, HUD·메뉴 전체의 네 화면 크기 측정, 키보드·터치 흐름, 기존 두 코스와 비교한 프레임 시간·첫 로딩 바이트다. 첫 브라우저 프레임 표본은 p95에 약1초 대기가 반복돼 전경/배경 상태를 포함한 통제 측정이 필요하다. 평균 FPS나 짧은 표본만으로 성능 통과를 선언하지 않는다.

관광지도 도형의 직접 확인은 아직 미완료이며 현재 사진·자료 참고에 한계가 있다. 전남 챔피언십·해금·라이벌 개성·추가 시간대는1단계 통과 후 구현한다. 실기기 검증은 하지 않았다.

검증 완료 전이므로 이번 초안을 커밋·푸시하지 않았다. PR 생성·병합·Vercel 배포도 하지 않았다. 변경 전 사본과 현재 초안은 작업 브랜치의 로컬 파일로 보존한다.

## 2026-10-11 브라우저 연결 중단

브라우저 DOM 읽기·목록 확인·게임 탭 재연결에서30초 시간 초과3회가 발생했다. 마지막으로 목록에서 새로 확인된 게임 탭에 연결했지만 응답 전 연결 통로가 닫혔다. 연결/제어 실패는 총4회이며, 시간 초과만4회였다는 중간 보고는 정정한다. 중간 목록 조회와 Chrome 선택은 성공했지만 게임 탭을 제어할 수 없었다. 사용자 지정 “같은 문제로3번 넘게 실패” 조건에 따라 추가 재시도를 중단한다. 코스 물리·226개 회귀·빌드는 성공 상태이며, 화면과 성능의 미검증을 통과로 바꾸지 않는다.

다음으로 가장 중요한 작업은 Chrome 브라우저 제어 연결을 복구하고,5192 여수 게임 탭을 전경에 둔 채 프레임 시간과 네 해상도 HUD·성삼재 화면을 확인하는 것이다. 그 전까지2단계 구현·커밋·푸시는 하지 않았다. PR 생성·병합·Vercel 배포는 하지 않았다.
