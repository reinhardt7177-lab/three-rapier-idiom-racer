# 투톤 휠 수출 비용 수정

최초 수출의 수프라 메시/프리미티브: 이전 47/47, 후보 90/130.
우라칸: 이전 46/47, 후보 88/129.

원인: `web_meshes()`와 웹 `batchStaticMeshes()`는 재질 한 개의 메시만 묶는다.
투톤 스포크마다 재질 슬롯 2개가 생겨 40개의 스포크가 독립 수출됐다.

수정: 원본 저장은 부품별로 유지한다. 수출 복사본에서 같은 `Wheel_*`의
투톤 스포크만 Blender join으로 한 메시로 묶고 2개 재질을 유지한다.
기존 일반 배칭을 이어서 실행한다. 지오메트리, 피벗, 투톤 외형은 바꾸지 않는다.
새 회귀 기준: GLB 프리미티브 수가 원본보다 12개 이상 늘어나면 실패.

현재 전체 검사 입력을 바꾸지 않기 위해 검사 종료 후 이 수정을 반영한다.
