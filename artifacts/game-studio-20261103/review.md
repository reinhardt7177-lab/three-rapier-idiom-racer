# 독립 코드 검토

요청된 Game Studio와 requesting-code-review/실행계획 지침에 따라 별도 읽기 전용 리뷰 에이전트가 실제 코드를 검토했다. 파일 수정·무거운 레이스·브라우저·실기기 검사는 리뷰어가 수행하지 않았다.

## 새 변경에서 발견하고 수정한 것

1. P2: Asphalt roughness 하한.65가 비의.48 uniform을무효화했다. 최종shader식을읽는RED→GREEN시험추가,.04~1.0으로수정.
2. P2/이식성위험: derivative-derivedfade를height에곱한뒤미분했다. height→1차미분→fade로수정,회귀추가.
3. P2: 7버튼이320px에서잘림. 실제DOM복귀끝335px재현,400px이하2행44px으로수정. 새실측잘림0.
4. P2: 온라인재개비활성/회전inert일때focus실패. enabled fallback/blocked와onlinephase재검사로수정. 후속코드리뷰에서추가지적없음.

## 기존 게임에서 찾은 것

- P1: 도로복귀시일반차점유를검사하지않음. 경량좌표재현과새유닛시험으로확인,일반차상태포함으로수정했다. 저접지후보미완주의원인으로확인된것은아니다.
- P1: 전방속도만으로고속횡슬립조향/보정판단. 후보가평지목표는만족했으나교통완주악화로보류했다. 사용자최신답변대로안정물리유지.
- P2: 터치사이드브레이크조작누락. DRIFT버튼과동시입력/독립해제시험추가.
- P2: 일시정지메뉴focus경계없음. dialog/초점진입·순환추가;14Tab모두내부확인.
- 추적카메라가림검사없음은코드위험. 특정코스에서실제벽가림재현을하지않았으므로확정결함으로표시하지않았다.

최종그래픽과후속입력/복귀/메뉴diff의정적검토에서새출시차단지적없음. 실제프레임비용/기기지원/전체완주는별도의실행결과로판단한다.
# 캐시 연결 실패 수정 후 최종 읽기 전용 재검토

- 전체 첫 실행525/526에서 비남악 지면의 캐시 키 버전 변경 때문에 성삼재 연결 계약이 실패했다. 기존 시험을 바꾸지 않고, 실제 변경된 도로만v2/기존 지면v1으로 분리했다.
- 관련23/23 재검사 통과. 최종 전체 명령은 재실행 중이며 이 정적 검토로 통과를 대신하지 않는다.
- 독립 검토자는 해당 분기와 최종 제품 diff에서 새 출시 차단 문제를 발견하지 못했다. 브라우저·휴대폰·GPU 성능을 검토자가 실제 시험했다는 뜻은 아니다.
