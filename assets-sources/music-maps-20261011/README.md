## 생성 방향

공통으로 보컬·랩·가사·말소리·보이스 샘플 없는 새 작곡, 특정 아티스트나 기존 곡을 모방하지 않는 음악을 요청했다. 엔진과 스키드 효과음을 위한 공간, 과도하지 않은 저역과 고역, 짧은 도입부와 반복 재생에 적합한 끝맺음을 요청했다.

- 해안: 햇살, 시원한 바닷바람, 따뜻한 기타와 키보드, 탄력 있는 힙합 리듬.
- 남악: 도심 대로, 건물과 간판, 경쾌한 개러지 리듬과 펑키한 베이스.
- 여수: 청남색·보랏빛 하늘, 돌산대교와 거북선대교의 조명, 금빛·청록빛 바다 반사와 수변 질주. 플럭 신스, 피아노, 은은한 기타와 넓은 패드.
- 지리산: 숲의 그늘, 산 능선과 헤어핀을 달리는 상승감. 자연스러운 타악기와 플루트, 짧은 가야금 색채를 요청.

## 검증과 남은 작업

네 MP3 모두 44.1 kHz 스테레오이고 전체 디코딩은 오류 없이 종료했다. 파일별 길이·바이트·SHA256과 로그는 `artifacts/music-maps-20261011/`에 있다. 여수 Gemini 플레이어도 재생 시간이 10초까지 증가한 뒤 일시정지되는 것을 확인했다.

요청 BPM, 보컬 부재, 곡 분위기와 루프 경계의 음악적 품질은 별도의 청취 검증을 완료한 것으로 주장하지 않는다. 남악은 요청한 60~90초보다 조금 길게 생성되었으며 원본을 자르지 않았다. FFmpeg volumedetect 결과 MP3의 평균 레벨은 해안 -14.4 dB, 나머지 -14.3 dB, 최대 레벨은 모두 0.0 dB다. 이 값은 LUFS 측정이 아니다. 게임 연결 시 효과음과의 음량 조정, 반복 경계 청취, 필요 시 별도 루프 편집본 제작이 남아 있다.

해안 저장 과정에서 기존 Seven Mile Horizon(68.867초)이 먼저 내려오는 문제를 발견했다. 새 대화 화면의 80.367초 원본을 다시 확보했고, 이전 곡 사본은 `coastal-existing-seven-mile-horizon-reference.mp4`로 구분했다. 이전 곡은 이번 네 곡에 포함하지 않는다. 기존 게임 음악과 사용자 대화 초안은 보존했다.
