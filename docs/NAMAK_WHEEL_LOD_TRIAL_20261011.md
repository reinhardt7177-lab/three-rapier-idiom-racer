# 남악 타이어 LOD 실험 제외 · 2026-10-11

## 결론

타이어 홈 렌더 LOD 실험을 제품에서 제외하고, 사용자 지정 성능 악화 중단 기준에 따라 새 그래픽 확장과 자동 작업6을 일시정지했다. 최종 제품 소스는 e1a6237의251개 검사 통과본과138개 입력 SHA256가 모두 같다. 이 문서는 출시 통과나6시간 작업 완료 보고가 아니다.13:15~약15:00은 경과 시간이며 연속 실행 시간을 뜻하지 않는다.

## 가설·범위

차체 재질별 메시와 휠 리그는 이미 분리되어 있어 단순 재병합으로 줄일 여지가 작았다. 실제 수프라 GLB에서 타이어 홈 메시1개는8,960삼각형,4개35,840삼각형이다. 먼 AI5대에서는 최대179,200삼각형을 줄일 수 있다는 가설을 확인했다.

실험은 Tread grooves 재질 메시의 보수적인 투영 구 크기만 계산했다. 타이어 전체가16px 미만이면 홈만 숨기고20px를 넘으면 복원했다. 처음 설명한1px 단위의 홈 실측이 아니라 전체 타이어 투영 크기를 사용한 보수적인 시도다. 플레이어는 항상 전체 디테일, 차고도 전체 디테일이다. 고무 타이어·림·브레이크·조향·회전·서스펜션·도로·충돌·경로·원본 Blender/GLB/법선/UV는 변경하지 않았다. 단위 시험은 지오메트리/재질 공유·원래 숨김·투영 크기·FOV·뷰포트·근접/플레이어 보존을 확인했다.

## 실제 제품 비교

Desktop IAB/Windows i5-1135G7/1280×720/DPR1, 수프라/보통1랩/3인칭/고스트 없음/정지 출발, 최근240프레임이다. 수정 전은 직전 e1a6237을 따로 빌드한5195, 실험본은5192다. 공통 GLB는 동일 파일을 사용했다. 캐시/드라이버/다른 프로세스 부하를 격리하지 않은 순차 측정이므로 정확한 원인 귀속은 보류한다.

## 검증·실패·복원

- 실험 관련 리소스/리그24시험 통과0실패,378.72ms. 첫 로컬 실험 빌드4.59초. 맵·원본·조명 비용은 변화0. 실험본의 추가 코드/투영 계산 비용이 있었으나 GPU 시간을 따로 측정하지 않았다.
- Colab 준비는 연결 확인/도구 스키마 확인 후 실행했다. 도구 검색 응답이 두 차례 시간 초과해 기존 연결을 다시 요청했다. 작업 셀 FYX1YQEjhiW_ 추가는 확인됐지만 runner를 실행했다는 결과는 얻지 못했다. 이 실험의 전체 npm run check를 실행/통과했다고 주장하지 않는다. 기존 노트북/사용자 셀은 삭제하지 않았다. 셀 추가 지연을 중복 실행하지 않도록 해당 인덱스를 확인했다.
- 제품 변경3파일을 이번 작업 직전 사본으로 복원하고 새 모듈은 실험 기록으로 옮겼다. 복원 제품138개 해시가 직전 실제 Colab CPU251개 검사 통과 소스와 전부 일치했다. 복원 로컬 빌드8.29초 통과. 빌드 뒤 자동 작업 설정 경로를 찾는 셸 명령은 CODEX_HOME 환경 변수가 없어 실패했고, 실제 사용자 홈의 설정 파일로 확인했다. 게임 빌드 실패와 구분한다.
- 브라우저 baseline 로딩 중 비활성 출발 버튼을 누른 검수 선택자1회 실패 후 준비 완료 상태에서 정상 재시도했다. 게임 입력 오류라고 주장하지 않는다. 이번 실험본은 네 크기 UI/완주/입력 전체 검증 전 성능 기준에서 제외했다. 최종 소스와 같은 직전251개 검증·네 화면/입력·6대 완주 결과는 이전 단위 결과로 유지한다.
- artifacts/visual-polish-20261011/wheel-lod-trial은 적용되지 않는 실험 코드 사본이다. before/after 원자료4개, 화면, 관련 시험 로그, 입력 해시·복원 해시·빌드 로그를 함께 보존했다.

## 남은 작업

남악 지속 p95 약33ms와 과거 성삼재1초 간격의 원인 분리가 먼저다. 재개 시에는 그래픽/물리/DOM commit/호스트 대기의 전체 프레임 타임라인을 확보하고, 화면 카메라·AI 위치·실제 GPU 장치·호스트 부하를 통제한 짧은 비교를 해야 한다. 고스트의 양면 투명2패스와 차량 디테일 재수출은 별도 가설이며 검증 없이 채택하지 않는다. 여수 다리/수면 반사와 성삼재 추가 숲/능선 Blender 고도화는 미완료다. 신규 기능·PR·병합·배포는 하지 않았다.
