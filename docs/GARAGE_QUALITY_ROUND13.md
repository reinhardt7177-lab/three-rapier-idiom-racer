# Garage Quality Round 13

## 차량별 조명 프리셋

차량 선택이 UI 색상만 바꾸지 않도록, 선택 차량의 액센트를 쇼룸 월드에도 전달했다.

- 첫 번째 쇼룸 스포트라이트가 차량 액센트 색상을 사용
- 스테이지 링·서비스 링·림 라이트 펄스와 동일한 색상 체계 유지
- 차량 GLB 등장 페이드 인으로 선택 전환을 부드럽게 연결
- 후면 네온 간판과 바닥 마킹에 실제 선택 차량명 표시

검증한 프리셋:

- APEX GT: 레드 액센트
- VOLT X: 시안 액센트
- RALLY R: 골드 액센트

## 트랙 선택 테마

트랙 선택 화면에 현재 트랙의 색상 후광을 추가해 목록과 3D 월드가 하나의 테마로 읽히게 했다. `:has()` 기반 규칙은 기존 DOM 구조를 유지하면서 선택 행만 기준으로 후광을 전환한다.

- 하버 링: 시안 / 선셋 그린 월드
- 네온 에이트: 핑크 / 딥 블루 나이트 월드
- 알파인 스프린트: 골드 / 밝은 알파인 월드
