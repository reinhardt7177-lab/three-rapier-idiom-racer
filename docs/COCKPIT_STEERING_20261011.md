# 1인칭 핸들 방향 수정 · 2026-10-11

## 문제와 원인

사용자 설명은 실제 주행 조향이 아니라 운전석 화면의 핸들 회전이 반대라는 뜻이다. 물리 앞바퀴의 양수 yaw는 좌회전이고 카메라에 붙은 Blender 핸들의 양수 Z 회전도 위쪽 파란 표식을 운전자 왼쪽으로 이동시킨다. `cockpit.js`의 표시 각도에 붙은 음수 부호가 둘을 반대로 만들었다. 심각도 P1의 표현/조작 불일치로 처리했다.

## 변경

- 운전석 `SteeringWheel` 표시 각도의 음수 부호만 제거했다. 기존 회전 배율 4는 유지했다.
- 실제 키보드/터치 입력, Rapier 조향·차량 물리, 3인칭 바퀴, 주행 카메라, Blender 원본/GLB, 코스·충돌·진행 데이터는 수정하지 않았다.
- 기존 시험은 잘못된 음수 공식을 그대로 기대했다. 이를 유한 값 확인으로 바꾸고 실제 Blender GLB의 `WheelCentreStripe`를 카메라에 투영하는 동작 회귀를 추가했다. 기준을 느슨하게 해서 통과시키지 않았다.
- 편집 전 tracked 변경 0, 파일 시각을 확인하고 변경 전 소스·시험·NEXT_STEPS 사본을 `artifacts/cockpit-steering-20261011/before/`에 남겼다.

## 실제 실행한 검증

1. **수정 전 재현:** 새 시험을 기존 소스에 실행했을 때 6통과/1실패. `KeyA / keyboard / 1 / compact=false`에서 윗 표식이 운전자 입력 반대로 움직였다는 AssertionError를 보존했다.
2. **수정 후 관련 회귀:** 로컬 운전석 7시험 모두 통과, 225ms. A/D·좌우 방향키·포인터 소유 좌우 입력 × 전진/후진 × 일반/작은 운전석, 총 24조합. 실제 조향 함수의 앞바퀴 방향과 표식의 화면 방향을 비교하고 입력 해제 후 중심 복귀도 확인했다.
3. **이번 로컬 빌드:** Vite 2.60초 성공. 메인 JS `index-DNRevSdF.js` 244,525바이트, 직전 배포 244,526에서 1바이트 감소. 전체 dist는 31파일/64,705,199바이트로 직전 배포보다 1바이트 작다. 정적 모델·텍스처·음악은 추가하지 않았다. 기존 큰 Three/Rapier 청크 경고는 남아 있다.
4. **실제 브라우저:** 로컬 개발 서버의 정상 UI로 검수용 자동 페달을 켜고 여수 맑음/보통/1랩을 실제 Rapier로 주행했다. 1인칭 전환→완주 81.34초·3위·동메달→재시작을 확인했다. 자동 페달은 기존 DEV 검수 기능이며 사람의 운전 체감이나 실제 키/터치 장시간 누르기 검수를 뜻하지 않는다.
5. **네 화면 크기:** 1280×720, 1024×768, 844×390, 667×375에서 실제 1인칭 렌더와 HUD 경계를 측정했다. 측정 대상 HUD·시점 버튼의 잘림/겹침 0. 1024×768은 게임 1024×576, 844×390은 게임 약694×390의 기존 가로 프레임을 유지한다. 화면 변경으로 열린 일시정지에서 주행 재개를 확인했다. 휴대폰 실기기 검증이 아니다.

브라우저 두 번째 레이스도 81.34초·3위로 완주하고 차고 복귀했으며, 오류 로그 0건이다. **이번 전체 회귀:** 실제 Colab CPU에서 `npm run check` 293시험/실패0/빌드까지 exitCode0, 933.80초. Colab 빌드는 3.31초이며 로컬과 같은 `index-DNRevSdF.js`를 만들었다. 맑음 라이벌24레이스144대 + 비14레이스84대, 합계38레이스228대 모두 유효한 완주 시간을 기록했다. 검사 후 원격159입력 해시와 현재 로컬159입력 해시 모두 불일치0이다. 이 결과를 다시 내려받아 `colab-verified/`와 `local-input-verification.json`, `race-summary.json`에 보존했다. GPU 계산이 아니다.

운영 배포 결과는 정식 주소 확인 후 별도 기록한다.

## 검수 도구 실패 기록

보조 Node REPL 화면 좌표 덤프는 기존 변수 이름 충돌, Three 모듈 검색 경로 누락, GLTFLoader 버퍼 해석 오류를 차례로 만나 중단했다. 이 덤프를 성공 근거로 쓰지 않았다. 동일 GLB를 읽는 정상 Node CLI 회귀 7시험과 실제 브라우저 렌더는 통과했다. 원자료 `optional-repl-projection-failures.json`을 보존했다. 기존 Preview 서버에는 DEV 자동 페달이 없어 별도 개발 서버 5199를 열었다. 제품이나 입력 기준은 바꾸지 않았다.

## 한계와 다음 작업
