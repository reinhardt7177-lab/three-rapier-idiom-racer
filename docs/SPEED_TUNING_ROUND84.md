# Speed tuning QA — round 84

## 목표

사용자 체감 기준을 “최고속도 200km/h 이상”으로 올리고, HUD 숫자만 바꾸는 방식이 아니라 Rapier 주행 속도 자체가 상한에 도달하도록 튜닝했다.

## 변경 사항

- 차종 10종의 `topSpeed`를 200~255km/h로 재설정했다.
  - APEX GT 220, VOLT X 255, RALLY R 210, SPECTER S 225
  - TRAILBLAZER 200, PURSUIT 240, REDLINE 6 200, BOXRUNNER 205
  - KART OOBI 215, FIELD FORCE 200
- `handlingProfile`에서 최고속도는 `topSpeedKmh / 3.6`으로 물리 상한에 연결했다.
- 차종별 가속력·후진력·부스트력을 고속 규격에 맞게 다시 계산했다.
- Rapier `world.step()` 이후 `applySpeedAssist`를 적용해 노면 마찰이나 짧은 코너에서 엔진 힘이 끊기는 현상을 완화했다. 충돌·접지·차체 회전은 Rapier가 계속 담당하고, 보조는 전진 속도 성분만 보정한다.
- 자동 주행 보조가 켜진 상태에서 4.5초 이상 정체되면 체크포인트 기준으로 재정렬한다.
- 고속 코너에서 차체 상하축이 무너지면 `flipTime` 0.72초 후 체크포인트로 재정렬하고, 과도한 롤 각속도도 감쇠한다.
- GLB/절차 차량 색상은 낮은 밝기 배율로 통일해 흰색으로 날아가는 현상을 줄였다.

## 검증

- `npm.cmd run check` 통과: 에셋·물리·차고·서킷·비주얼·Vite 빌드.
- 브라우저 주행에서 PURSUIT가 150→187km/h까지 상승하는 것을 확인했고, 다음 직선 구간에서 200km/h 이상을 목표 상한으로 유지하도록 보정했다.
- HUD는 기존처럼 Rapier 속도(m/s)를 `×3.6`해 km/h로 표시한다.

## 남은 QA

- 각 차종의 실제 최고속도와 코너 탈출 시간을 한 번씩 측정한다.
- 고속 충돌 시 차체가 연석에 걸리는 구간을 트랙별로 기록한다.
