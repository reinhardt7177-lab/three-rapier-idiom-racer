# 남악 고정 장면 A/B/A 진단 · 2026-10-11

## 결론

거부했던 타이어 LOD를 제품에 다시 적용하지 않았다. 물리·차량·카메라·레이스 시간을 멈추고 동일 장면에서 전체 디테일 → 먼 라이벌 타이어 홈만 제외 → 전체 디테일 복원을 각각 360프레임 비교하는 DEV 전용 진단을 추가했다. 실제 비교에서 p95는 33.5→33.4→33.4ms였다. 삼각형 감소만으로 남악 지속 지연이 해결됐다고 할 근거가 없다. 새 장식 기하 확장과 자동 작업6의 PAUSED 상태는 유지한다.

## 방법과 보존

- `qaProfile&qaFrozen`을 명시한 개발 서버에서 레이스 일시정지 시 한 번 실행한다. 기본 제품에는 이 진단을 켤 수 없다. 추가 렌더 패스는 없으며 정지 중 기존 렌더를 1080회 실행한다. 물리 입력이나 진행 거리 보정은 하지 않는다.
- 투영 크기는 준비 시 한 번만 계산하고 숨김 변경은 구간 전환 때만 수행한다. 이전 실패 실험의 매 프레임 행렬/LOD 계산과 달라 그 실험의 성능을 재검증한 결과로 쓰지 않는다.
- 플레이어·고무 타이어·림·브레이크·바퀴 리그와 기존 숨김 상태는 보존한다. 완료·취소·재출발·차고 복귀·dispose에서 원래 가시성을 복구한다. Blender/GLB·UV·법선·도로·충돌·경로는 불변이다.
- 전체 1079개 프레임 간격을 구간 경계까지 보존한다. CPU 제출 시간과 실제 비동기 GPU 타이머는 겹쳐 실행되므로 더해서 프레임 시간이라고 하지 않는다. 느린 표본을 제거하지 않는다.
