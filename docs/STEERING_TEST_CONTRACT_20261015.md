# 현재 조향감을 보존한 검사 기준 정합

2026-10-15 · 로컬 검사 수정. 조향·차량 물리·게임 런타임은 변경하지 않았다.

**두 불일치 해결, 전체 456/456 통과와 Vite 빌드 성공.** 제품 입력 143개의 SHA-256이 작업 전과 같아 현재 조향 설정이 그대로 보존됐음을 확인했다.

## 원인과 수정 범위

`scripts/namak-polish.test.mjs`의 마지막 두 검사는 이전 플레이어 설정인 감도 1.3과 저속 조향 상한 0.52rad를 전제로 했다. 현재 [조향 5회 개선](STEERING_FIVE_PASS_20261015.md)은 감도 1.69, 저속 상한 0.56rad, 90km/h까지 최대 18%인 중속 보강과 180km/h까지의 완만한 복귀를 사용한다. 수정 전 같은 파일에서 두 실패를 다시 재현했다.

게임을 이전 설정으로 되돌리지 않고 해당 검사 두 개만 현재 설계에 맞췄다.

| 검사 | 유지·보강한 기준 |
| --- | --- |
| 속도별 조향 범위 | 0·40km/h 상한 0.56rad, 90km/h 보강 1.18, 135km/h 보강 1.09, 180·230km/h 기존 고속 범위 유지. 기대 각도 오차 <1e-12rad, 후진·좌우 대칭·뒷바퀴 조향 0과 AI 기본 상한 0.52rad 확인 |
| 실제 Rapier 조향 | 게임과 같은 `playerRaceTuning`·플레이어 감도를 사용해 100·180km/h 좌우 각각 검사. 매 프레임 4바퀴 접지·차체 세움 지표 >0.97·실제 이동 방향 기준 유지 |
| 상태와 실제 바퀴의 연결 | 상태의 조향 한계는 현재 속도, 실제 적용 각도는 물리 단계 시작 속도로 대조. 앞바퀴 각도는 Rapier의 단정밀도 값과 `Math.fround`로 정확히 일치해야 함 |

`src/driving/steering.js`, `src/driving/physics.js`, 차량 튜닝·입력·카메라·AI와 모델을 수정하지 않았다. 기존 8종 실제 회전 반경 회귀 검사의 기준값과 5% 이상 개선 기준도 변경하지 않았다.

## 검증

- 수정 전 재현: **2개 실행·2개 실패**, `reproduce.log`와 종료 코드 1 보존.
- 조향 집중 검사: **4개 파일·25/25 통과**, `focused.log`·종료 코드 0. 남악 표현 검사와 실제 8종 회전, 고속·반대 입력·복원, 운전석·남악 한 바퀴 주행 포함.
- 전체 등록 검사: **69개 파일·456/456 통과**, 실패·취소·건너뛰기·TODO 모두 0. **1,182.63초(19분 42.63초)**, `full.log`·종료 코드 0. 집중 검사 25개는 이 전체 범위에 포함하며 합산하지 않는다.
- Vite 빌드: **성공**, Vite 표시 **19.49초**, 명령 전체 **25.89초**, `build.log`·종료 코드 0. 결과 35개 파일의 SHA-256을 `build-files.json`에 보존했다. 기존 500kB 초과 청크 경고는 남아 있다.
- 제품 입력 보존: `src`·`public`·차량 Blender 원본·고정 조향 기준값·패키지/빌드 입력 **143개 SHA-256 변경 0**. `inputs-before.json`·`inputs-after.json`·`input-comparison.json`에 보존했다.

전체 검사는 `package.json`의 `check:rebuild`에 등록된 모든 시험 파일을 동일하게 사용하며, 실행 병렬 수만 4로 지정한다. 목록과 실행 환경은 `full-manifest.json`에 보존한다. 계산은 로컬 Windows CPU / Rapier WASM에서 실행하며 Colab을 사용하지 않는다.

```powershell
node --test --test-concurrency=4 scripts/namak-polish.test.mjs scripts/steering-final.test.mjs scripts/steering-turn.test.mjs scripts/steering.test.mjs
npm run check:rebuild
```

증거 위치: `artifacts/steering-contract-20261015/`. `completion.json`에 최종 집계를 기록했다. 기존 생성형 검사 결과 13개는 실행 전에 별도 사본을 보존하고 검증 뒤 원래 내용과 수정 시각으로 복원했다. 이번 실행 결과는 `regression-results/`에 따로 보관했다. 이전 AI 작업의 실패 로그도 그대로 남긴다. 이 후속 검증은 [AI 3회 개선 당시 남은 두 불일치](RIVAL_AI_3PASS_20261015.md)를 해결하는 작업이며, 과거 실행을 소급해 통과로 바꾸지 않는다.

기존 빗길·라이벌 개성 검사 작성기 두 곳은 산출물의 `device`에 과거 Colab 문구를 고정해 두고 있다. 이번 실행 환경의 근거는 그 문구가 아니라 실제 로컬 명령과 `full-manifest.json`이며, 원격 계산이나 GPU 활용으로 보고하지 않는다.

## 범위

검사 코드와 문서만 수정했다. 제품 조향감의 사람 평가, 실기기 입력·성능, 서로 다른 기기의 온라인 플레이를 새로 검증한 결과는 아니다. 커밋·푸시·운영 배포는 수행하지 않았다.
