# MUMU CIRCUIT 진행·보상 QA 보고서

## 검증 범위

- 레이스 종료 시 개인 최고 기록(PB)과 고스트 저장
- 완주·승리·골드 누적
- 완주/승리 조건에 따른 차량 해금
- 이전 프로필이 새 해금 차량 목록을 오염시키지 않는지 확인
- 차량 에셋·CC0 에셋·Vite 프로덕션 빌드

## 자동 검증 결과

`npm.cmd run check` 통과.

- CC0 에셋 167개 / 7.4 MB
- 차량 카탈로그 10종, 모두 glTF 헤더·메시·노드·휠 노드 확인
- 진행 검증: 5회 완주 / 4승 / 430 G / 10종 해금
- Vite 프로덕션 빌드 성공

## 수정한 회귀 버그

보상 적용 시 기존 프로필의 `unlocked` 배열을 직접 수정하던 문제를 고쳤다. 이제 배열을 복제한 뒤 차량을 추가하므로 결과 화면이 새로 해금된 차량을 정확히 표시하고, 이전 프로필 비교도 안전하다.

## 브라우저 확인

차고 화면에서 차량 선택, 트랙 진입, 테마별 3D 런타임 부팅, HUD 표시를 확인했다. 실제 완주 입력은 브라우저 자동화에서 키 홀드가 제한되어 별도 수동 플레이 확인이 남아 있다.

## 이번 시각 폴리싱

- 차고 천장 트러스·발광 라인·진단 스크린·서비스 리프트 기둥 추가
- 턴테이블에 시안/골드 이중 링과 차량 키 라이트 추가
- 차고 카드·트랙 카드·진입 버튼 호버/포커스 상태 추가
- 레이스 시작 그리드 종방향 간격을 넓혀 차량 겹침을 완화
- 하버 링·네온 에이트·알파인 스프린트 3개 테마를 브라우저에서 모두 확인

## 주행 보조 및 완주 검증

- `CRUISE` 토글로 가속 유지 입력을 확인했다(약 50 km/h까지 도달).
- `LINE` 보조 조향으로 알파인 스프린트 2랩 완주를 확인했다.
- 결과 리캡에서 `P1 / 111.08 SEC / +80 G / 2 FINISHES · 2 WINS`와 `PURSUIT · BOXRUNNER` 신규 해금을 확인했다.
- 창 포커스 이탈·탭 숨김·포인터 이탈 시 입력을 해제하도록 보강했다.
- 신규 브라우저 탭의 차고 부팅 로그는 오류·경고 0건이었다.
