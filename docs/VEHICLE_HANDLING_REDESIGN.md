# GT 조향·바퀴 재설계

## 판단과 변경 범위

차고·공도·차체 디자인과 Rapier 동적 차체는 보존했다. 이번 문제는 차체를 다시 모델링하기보다 조향 제한과 물리/표시 연결을 수정하는 것이 우선이었다. 차의 위치나 회전을 직접 덮어쓰는 보정은 넣지 않았다.

확인한 문제:

- 기존 속도 제한식은 40km/h에서 11.4°, 60km/h에서 5.1°만 허용했다. 공도 중속 코너에서 조향 여유가 부족했다.
- 두 앞바퀴에 같은 각도를 주어 저속 회전 시 각 바퀴의 회전 중심이 일치하지 않았다.
- 모델은 +Z 전진·X 바퀴축인데, Rapier의 양의 전진 회전값을 화면에서 음수로 뒤집었다.
- 차체는 이전/현재 물리 상태 사이를 보간하고 바퀴는 현재값만 사용해 갱신 시점이 달랐다.
- 복귀 직후 핸드브레이크 상태와 후륜 접지 설정이 남을 수 있었다.

## 새 설계

`src/vehicleSpec.js`에 축간거리 2.84m·윤거 2.03m·타이어 반경 0.39m를 통일했다. `steering.js`가 입력 응답, 속도별 한계, 앞바퀴 개별 각도, 바퀴 표시 보간을 담당한다.

1. 좌우 입력을 부드럽게 반영하고, 놓기/반대 방향 전환의 반응을 분리했다. 0.2초 응답 시험을 통과한다.
2. 속도별 제한은 유지하되 중속 조향 여유를 늘렸다. 중앙 조향 최대 약 29.8°, 정차 시 안쪽 약 35.7°/바깥쪽 약 25.4°다. 고속에서 정차 각도를 그대로 허용하지 않는다.
3. 안쪽 앞바퀴가 더 꺾이는 **애커먼 조향**을 Rapier 각 바퀴에 적용한다. 후륜 조향은 0°다.
4. 바퀴의 서스펜션 높이·조향·구름 회전을 차체와 같은 보간 시각에 표시한다. 누적 회전각을 2π에서 잘라 역회전시키지 않는다.
5. 복귀 시 조향 입력, 브레이크/드리프트 상태, 후륜 접지 설정을 함께 초기화한다.

기술 참고: [Rapier 차량 컨트롤러 공식 문서](https://rapier.rs/javascript3d/classes/DynamicRayCastVehicleController.html), [MathWorks 애커먼 조향 설명](https://www.mathworks.com/help/vdynblks/ref/kinematicsteering.html). 이 게임의 속도 제한·접지 수치는 게임용 튜닝이며 실제 GT 타이어의 성능 인증값이 아니다.

## 계측 결과

평지·배리어 없는 동일 시험장, 실제 엔진/브레이크 입력으로 목표 속도를 유지하며 최대 조향 6초를 수행했다. 뒤쪽 3초의 이동거리÷누적 방향 변화로 **차체 중심 궤적의 평균 회전반경**을 계산했다. 바깥 타이어 기준 회전반경이나 자동차 제원표의 최소 회전반경과는 다르다.

| 목표 속도 | 수정 전 | 수정 후 |
|---|---:|---:|
| 20km/h | 6.42m | 5.18m |
| 40km/h | 13.99m | 9.63m |
| 60km/h | 23.01m | 20.44m |

좌우 대칭·4륜 접지, 230km/h 최대 조향 시 차체 안정성, 전후진 시 조향 방향, 바퀴 회전거리와 실제 이동거리의 일치를 시험했다. 최고속 시험은 기존과 동일한 실제 232.2km/h다. 순간 수치만 높인 것이 아니다.

## 직접 확인

- 주행 화면에서 완전히 정차 → **정차 후 바퀴 점검**.
- A/D 또는 좌우 터치 버튼으로 전륜 각도와 실제 모델을 비교한다. 표시는 운전자 기준이다. 차 앞에서 바라보는 점검 카메라의 화면 좌우와 혼동하지 않는다.
- 점검 중에는 브레이크로 정차를 유지하고 가속/후진을 막는다. **점검 닫고 주행**으로 정상 추격 카메라와 주행에 복귀한다.
- 일반 주행에서는 기존 W/S/A/D·화살표·B·Space·R·C 조작을 유지한다.

## 검증 명령과 한계

`npm run check`: 전체 35개 시험 + 빌드. 바퀴 전용 8개는 `scripts/steering.test.mjs`.

브라우저 검증: `scripts/verify-steering.cjs`(각도·키/터치·점검·복귀), `scripts/verify-driving.cjs`(고속·제동·후진·일시정지), `scripts/verify-coast.cjs`(실제 키 입력 해안길 왕복). 실행 결과는 각각 `artifacts/steering-redesign`, `artifacts/vehicle-stage1`, `artifacts/coastal-road`에 남는다.

최종 세 브라우저 시험 모두 통과했다. 해안길 왕복은 약 197.8초, 최대 draw call 208, 브라우저 오류·실패한 요청·외부 요청 0건이다. 병렬 브라우저 실행 중 일반 주행 시험이 타임아웃되고 왕복 시험이 경로점을 놓친 이력이 있어, 최종 검증은 순차 실행했다. 왕복 시험 운전기는 지나친 점을 계속 추적하지 않도록 제한된 전방 구간의 가장 가까운 경로점을 찾게 보완했다. 실제 게임의 차량 이동·체크포인트·완료 판정은 이 검증 보완으로 우회하지 않았다.

아직 레이캐스트 4륜 모델이다. 타이어 변형, 정밀 슬립각 기반 타이어 모델, 완성된 드리프트 제어기는 구현하지 않았다. 후륜 그립 저하를 이용하는 기존 핸드브레이크는 유지한다. 높은 휠 회전 속도에서는 프레임 샘플링 때문에 스포크가 정지/역회전처럼 보이는 현상은 별도로 생길 수 있다. 머티리얼/형상 리모델링, GPU 실기기 FPS 보장, GitHub 반영·운영 배포는 이번 범위에 포함하지 않는다.
