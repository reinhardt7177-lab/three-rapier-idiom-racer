# 해변 BGM · Blender 운전석 · 빠른 라이벌

2026-10-10 로컬 제작본. Three.js + Rapier를 유지하며 기존 차량 8종의 외장·맵·차고를 보존했다. GitHub Pages에 이번 변경을 배포하지 않았다.

## 구현

- 승인한 Gemini 해변 힙합 **Seven Mile Horizon**을 로컬 MP3로 연결했다. 길이 68.847초, 파일 1,309,073바이트. 출발 클릭으로 시작해 반복 재생하며 메뉴·포커스 상실·결과 화면에서 정지한다. 재시작·차량 변경 때 음악 객체를 추가 생성하지 않는다.
- 메뉴에서 BGM 켜기/끄기와 0~60% 볼륨을 조절한다. 기본 24%; `M`은 엔진과 BGM을 함께 음소거한다. 음악 설정·시점은 같은 실행 세션의 재시작과 차고 복귀에서 유지하며 페이지 새로고침 시 기본값으로 돌아간다.
- `V` 또는 화면의 시점 버튼으로 3인칭/1인칭을 전환한다. 차량별 높이·폭을 운전자 눈 위치에 반영한다. 고속 주행 시 수평 위치를 즉시 따라가며 높이·노면 경사는 완만하게 추종한다. 차체 롤과 임의의 흔들림을 추가하지 않는다.
- **실제 Blender 5.2.1에서 만든 3D 운전석**을 GLB로 수출했다. 패딩 대시보드, 계기판, 송풍구, 센터 디스플레이·기후 조절 노브, 변속기, 금속 스포크·버튼·패들·중앙 표시가 있는 핸들, 얇은 앞유리 프레임을 포함한다. 이전 SVG 핸들은 제거했다.
- `SteeringWheel`, `SpeedNeedle`, `RPMNeedle` 피벗을 보존했다. 핸들은 실제 앞바퀴 조향의 4배 회전, 속도계는 0~260km/h, RPM계는 0~8000RPM에 대응한다. 계기 바늘 방향과 눈금의 일치를 실제 GLB를 로드하는 시험으로 확인했다. 좌석 시각 모델은 충돌체·질량·차량 지오메트리를 바꾸지 않는다.
- 운전석은 8종 공통 커스텀 모델이다. 브랜드별 실내 복제, 운전자 팔·손, 조작 가능한 센터 디스플레이는 구현하지 않았다. 세로 화면에서는 운전석을 조금 뒤/아래에 배치해 도로 시야를 확보한다.
- AI 직선 목표 상한을 138→185km/h로 올렸다. 완만한 코너에서는 추가 속도를 허용하지만 기존 목표가 80km/h 미만인 급커브는 보존했다. 실제 도로 확인과 주변 차량 간격 검사, 전방 제동은 유지한다.
- 새 속도 설정에서 드러난 정차 차량 뒤 추월 정체와 차선 복귀 충돌 대기를 수정했다. 후방 차량이 가까워 이동할 수 없으면 현재 차선으로 전진하며 전방 제동을 유지한다. 차량 순간이동으로 속도를 높이지 않는다.

## 검증과 발견한 실패

전체 회귀 검사 147개 통과·웹 빌드 성공. 결과는 `artifacts/race-experience-20261010/check-blender-cockpit-final.log`에 보존한다. 운전석 시험은 실제 수출 GLB를 로드해 피벗, 바늘 방향, 조향 시 원본 지오메트리 보존, 숨겨진 카메라 자식의 메모리 해제를 확인한다. 기존 주행·입력·충돌·VFX·렌더링·전체 맵 시험을 포함한다. 최종 운전석 GLB는 617,448바이트, 21,678삼각형, 메시 17개·재질 9개다.

라이벌 전체 맵 A/B 결과:

| 차량 | 이전 완주 시간 | 변경 후 | 감소 |
| --- | ---: | ---: | ---: |
| SLK | 237.56초 | 218.69초 | 18.87초 |
| Mustang | 253.10초 | 209.09초 | 44.01초 |
| 911 | 233.78초 | 232.29초 | 1.48초 |
| GT-R | 241.14초 | 209.13초 | 32.01초 |
| RX-7 | 229.99초 | 214.46초 | 15.53초 |

평균 239.11→216.73초, 약 9.4% 감소. AI 5대가 전체 코스를 물리 주행으로 완주했으며 세 대는 실제 추월 후 차선 복귀를 기록했다. 동일 직선 GT-R A/B 시험은 25초 동안 최고 138.08→185.05km/h, 이동 거리 850.86→1059.83m를 기록했다. 표시 속도만 바꾼 결과가 아니다.

초기 AI 설정에서 산길 급커브 정체, 수정 중 해변의 두 차량 상호 정차를 발견해 각각 수정했다. 실패 자료는 `faster-failed-full-course.json`, `traffic-failed-full-course.json`, `targeted.log`, `targeted-recheck.log`에 남아 있다. 첫 운전석 수출은 45,000삼각형 예산 시험을 실패했다. 글자 곡선·베벨·원형 분할을 줄여 시험 기준을 유지하고 다시 수출했다. 앞유리 프레임/스포크의 회전 적용 순서와 계기 바늘 방향도 실제 렌더링에서 확인해 수정했다.

브라우저 확인: 차량 8종 선택→출발→1인칭 가속(56~77km/h, 바퀴 4개 접지)→메뉴→차고, 3인칭 복귀, 음악 단독/전체 음소거·재개·볼륨 조절·재시작, 키보드와 터치 가속, 화면 회전 시 자동 일시정지·입력 해제. 1280×720, 390×844, 844×390 화면 크기 에뮬레이션으로 운전석·도로 시야를 확인했다. 증거는 같은 폴더의 `browser-proof.json`과 `blender-cockpit-*.png`에 보존한다.

## 남은 검수

실제 휴대폰 10분 이상 주행, 사람의 혼잡한 레이스 운전과 헤드폰/휴대폰 음악 균형 평가가 필요하다. 자동 회귀 시험과 함께 실행한 최초 레이스 진입에서 수초의 멈춤이 관찰됐다. 셰이더 준비와 CPU 경합이 원인일 가능성이 있으나 분리 측정하지 않았으므로 원인을 확정하지 않는다. 예열·첫 프레임 비용을 별도로 측정할 필요가 있다. 도심 연석·산길의 기존 착지 충격까지 전부 해결했다고 간주하지 않는다. 공통 운전석의 RPM 붉은 눈금은 6500부터이며 차량별 정확한 레드라인은 HUD 표시를 따른다.
