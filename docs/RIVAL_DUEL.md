## 플레이

차고 → **해안 라이벌 대결 → 라이벌 대결 출발**. 코랄 GT와 함께 출발해 같은 3개 계측선을 순서대로 통과한다. 약 770m 코스, 제한 90초. SHIFT/터치 NITRO와 액션 핸드브레이크를 사용할 수 있다. 결승 통과 뒤 자동으로 감속하고 승패/재도전을 제공한다.

**비접촉 프로토타입이다. 두 차량은 서로 통과한다.** 충돌 추월이나 몸싸움을 구현했다고 주장하지 않는다. 기존 기록전·고스트·라이선스에는 저장하지 않으며, 2장 스토리/보상을 해금하지 않는다.

## 라이벌이 달리는 방법

- 별도 Rapier 월드에서 동일한 차량·도로·액션 물리를 사용한다. 첫 배치/재시작 이외에는 위치·속도를 강제로 쓰지 않는다.
- 앞쪽 도로를 바라보는 조향 제어, 구간별 목표 속도와 제동 입력으로 주행한다. 플레이어 위치를 이용한 속도 보정이나 순간이동은 없다.
- 상대는 현재 니트로/핸드브레이크를 사용하지 않는 기본 난이도다. 같은 힘을 이용할 수 있는 차지만 입력 전략이 다르다.
- 실제 세 게이트의 통과 시점으로 판정한다. 도로 이탈/복귀는 플레이어 무효, 라이벌 이탈은 라이벌 실패로 구분한다. 결승선에 도달하지 않은 상태를 완주로 만들지 않는다.
- 플레이어 제한 시간 초과 시 안전 감속 후 무효 결과. 일시정지는 두 물리 시계 모두 멈추며 재도전은 둘 다 초기화한다.
- 라이벌 차체/바퀴는 물리 스냅샷을 보간해 표시한다. 독립 엔진 음원, 접촉 충돌, 공격적 추월, 난이도 선택은 후속 범위다.
