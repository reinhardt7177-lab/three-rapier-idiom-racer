# 차체 꿀렁임·배기·타이어 효과 보정 · 2026-10-09

## 사용자 문제와 변경

사용자가 실제 주행의 꿀렁임과 배기·스키드 연기가 보이지 않는 문제를 보고했다. 당시 배기 시스템은 웹 런타임에 없었다. 타이어 신호는 측면 미끄러짐 위주였으며 직선 핸드브레이크에서는 연기·자국을 거의 만들지 않았다.

- **차체:** 3륜 이상 지지되고 차체가 직립에 가까울 때 앞뒤·좌우 회전 속도를 물리 토크로 감쇠한다. 계수는 질량×5이며 수직축 조향은 유지한다. 기존 서스펜션과 바퀴 위치를 사용한다. 점프에서는 적용하지 않는다.
- **카메라:** 안정화된 레이스 시야에서 가속·제동 신호에 따른 앞뒤 이동과 FOV 변화를 제거한다. 속도·니트로의 작은 변화와 실제 충돌 반응은 유지한다.
- **바퀴 접지:** 타이어 광선이 다른 차량의 범퍼·지붕을 지면으로 삼지 않도록 동적 강체를 제외한다. 차량 간 차체 충돌은 계속 계산한다. [Rapier 공식 차량 컨트롤러 안내](https://rapier.rs/docs/user_guides/javascript/vehicle_controller/)의 동적 강체 제외 방식에 맞춘다.
- **배기:** Blender v4 제작 코드의 배기구 두 위치에 맞춰 공회전·가속 배기 효과를 연결한다. 월드에 남는96개 입자 풀, 한 번의 그리기 호출이다. 플레이어 차량에 연결하며 수프라·SLK·머스탱별 위치를 적용한다.
- **타이어:** 접지·실제 감속·핸드브레이크·측면 슬립을 이용해 급제동/핸드브레이크의 연기·자국을 만든다. 화면을 향하는 사각형 입자로 변경해 하드웨어 점 크기 제한을 피하고 밀도·수명·불투명도를 강화한다. 최대160개 입자, 한 번의 그리기 호출이다. 공중·정지 상태에서는 새 스키드 연기를 만들지 않는다.

배기는 가시성을 위한 아케이드 연출이다. 타이어 앞뒤 회전은 Rapier의 운동학적 광선 차량 모델을 사용하므로, 독립 타이어 각운동량·열·ABS나 엔진 연소를 시뮬레이션한 결과는 아니다. 브레이크 스크럽은 실제 감속과 제동 입력으로 계산한다. 기존 월드·차량 GLB와 Blender 원본은 수정하지 않았다.

## 검증

`npm run check:rebuild`: **66개 통과 / 실패0**, 웹 빌드 통과. `final-check.log`에 결과를 보존했다. 기존 청크 크기 경고 유지.

- 세 차량의 정상/강한 회전 충격 뒤 감쇠·접지 회복, 평지200km/h 이상 가속, 고속 충돌·후진 탈출, 여섯 차의 실제6.84km 완주.
- 변속 토크가 반복해서 끊겨도 안정화 카메라의 위치·FOV가 가속 신호에 흔들리지 않는지 확인.
- 동적 차량만 아래에 둔 재현에서 무필터 타이어 광선은4륜 접지, 새 필터는0륜 접지. 고정 지면 추가 후4륜 접지. 최초 시험은 새 충돌체를 등록할 world.step을 빼먹어 실패했고 수정 후 통과했다 (`vfx-fixture-failure.log`).
- 세 차량의 실제 가속→급제동에서 연기·자국 생성, 효과를 읽는 차량과 동일 입력의 대조 차량 위치·회전 일치. 최대 연기160개, 자국512개 이하.
- 양쪽 배기구의 변환 위치, 입자 풀 상한·공중/정지 스키드 억제·후진·일시정지·회복/차고 전환·자원 해제 검사.
- `hash-check.json`: 월드·차량3종 GLB SHA256 유지.
