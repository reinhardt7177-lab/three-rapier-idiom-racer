# Circuit quality round 71

이번 라운드는 서킷을 “도로 + 배경”이 아니라 실제 레이스 코스로 읽히게 만드는 주행 시각 개선에 초점을 맞췄다.

## 적용 내용

- `offsetRibbon()`으로 트랙 안쪽/바깥쪽에 테마별 연속 엣지 라인을 추가했다. 커브에서도 코스 경계가 끊기지 않고 보여 조향 기준이 선명해진다.
- 가드레일 구간에 세로 포스트와 3단 안전망 와이어를 추가했다. 기존 반사 레일과 함께 고속 코너의 위험 구간을 시각적으로 표시한다.
- 피트 진입선과 12개의 유도 LED를 추가해 피트 구역을 본선과 분리했다.
- 스타트 그리드에 P1~P4 플로어 마킹을 추가해 출발 위치가 실제 그리드처럼 읽힌다.

## 검증

- `npm.cmd run check`
- `npm.cmd run build`
- 로컬 Vite 서버 `http://localhost:5173/` HTTP 200 확인

다음 회귀 확인에서는 스타트 그리드, 피트 진입, 야간 네온 구간, 알파인 헤어핀을 각각 캡처해 모바일에서도 라인과 안전시설이 과밀하지 않은지 확인한다.
