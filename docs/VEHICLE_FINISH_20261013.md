# 8종 차량 마감과 렌더링 비용 개선 · 2026-10-13~14

## 범위와 보존

8종의 기존 v6 Blender 모델을 다듬었다. 차체 도장, 창유리, 램프, 사이드미러,
휠, 브레이크, 공력 부품의 재질과 반사를 구분하는 작업이다. 공장 CAD나
정식 실차 모델로 바꾼 작업은 아니다. 기존의 단순화된 차체 비례와 실루엣은 남는다.

- 편집 원본: `assets-sources/vehicles-v6/*.blend`.
- 재현 스크립트: `scripts/blender/polish_vehicle_finish.py`.
- 웹 자산: `public/assets/rebuild/{supra,slk,mustang,porsche911,gtr,rx7,m3,huracan}.glb`.
- 변경 전 사본, 파일 시각/해시와 기존 타 작업 상태: `artifacts/vehicle-finish-20261013/before/`, `before-manifest.json`.
- 차체/타이어 원본 정점과 Chassis/Suspension/Steering/Wheel 행렬을 Blender에서 비교하고 수출을 차단하는 검사를 넣었다.
- 물리 튜닝, activeRide, 차체 모션, 주행 경로, 메달, 온라인 프로토콜은 수정하지 않았다.
- 같은 폴더의 별도 남악 건축 변경은 보존하며 차량 커밋에 섞지 않는다.

## 실제 화면 검수

8종의 전후 전면/후면을 실제 브라우저로 캡처해 [비교 갤러리](../artifacts/vehicle-finish-20261013/comparison.html)에 모았다.
별도 자산 검사 화면에서 잠긴 차량도 확인했으며, 제품의 해금 기록을 변경하지 않았다.
휠 근접·주간/야간 반사와 실제 차고의 차량 선택도 확인했다. 최종 실제 주행과
네 크기 UI 기록은 `vertex-*.json/png`에 보존한다. 화면 변경 시 안전 일시정지를
해제한 뒤 활동 중 HUD를 별도로 측정하며, 정지/결과 화면을 주행 검증으로 세지 않는다.

최종 실제 남악 1랩은 플레이어 **86.1417초**, 6대 모두 완주, 플레이어와
모든 AI 복귀0회였다. 최종 차고→출발→3인칭/1인칭→완주→결과→차고→
재출발→메뉴→차고를 확인했다. 메뉴와 차고에서 페달/조향/니트로 입력은
모두 해제됐다. 콘솔 오류/경고0건이다. 키보드/터치 취소의 단위 회귀와
선행 후보의 실제 입력 검수는 보존했으며 최종 자산은 입력 코드를 바꾸지 않았다.

1280×720, 1024×768, 844×390, 667×375의 차고/HUD/결과/메뉴 16조건에서
잘림0건이다. HUD/결과/메뉴와 차고3크기의 겹침은0건이다. **1024×768 차고는
최고기록/메달이 표시될 때 차량 제목 상자와 출발 패널 상자가 약1px 겹친다.**
텍스트끼리 겹치거나 버튼이 가려지지는 않지만 측정 실패로 남겼다. 변경 전
차량/반사 버전에서 동일 조건을 재현했다(`baseline-garage-medal-1024.json/png`).
이번 차량 마감으로 생긴 회귀는 아니며 기존 P3 레이아웃 간격 문제다.
모든 화면이 겹침0이라고 보고하지 않는다. 실물 휴대폰 검증은 아니다.

## 실패와 수정 이력

- 초기 마감 리비전 시험 2회는 잘못된 메타데이터 노드를 찾았다. 실제 Chassis_Rig를 검사하도록 수정했다.
- 일부 차의 램프/미러 이름 분류 누락은 원본 재질 기반 분류로 수정했다.
- 최초 47→130 프리미티브 증가를 찾아 수출 복사본 배칭58, 최종 정점 색상54로 줄였다.
- 최적화 전 전체 검사 한 번은 591.85초에서 중단했다. 통과로 세지 않는다.
- 두 재질 후보 전체 검사는 427/427·빌드6.93초로 통과했다. 벽시계65,438.35초에는 날짜를 넘긴 관측 공백이 있으므로 능동 작업 시간으로 해석하지 않는다.
- 두 재질 후보 낮음 A/B/A는 p95 모두33.4ms이고 B의 평균/CPU 제출이 악화됐다. 표본을 보존하고 정점 색상으로 비용을 줄였다. 마지막 A2는 Blender 작업과 겹쳤을 수 있어 최종 판정에 사용하지 않았다.
- Huracán 수출 중 시험을 먼저 실행해 예산 시험이 일시 실패했다. 수출 종료 후 동일 시험34/34, 셰이더 시험 추가 후 최종35/35가 통과했다.
- 브라우저 제어 3초 응답 제한과 카운트다운 대기 실패는 상태를 다시 읽고 포커스/안전 일시정지를 해제해 검수했다. 이를 게임 오류 또는 성공 증거로 세지 않았다.

나쁜 프레임·실패 로그·중단 보고서는 제거하지 않았다. 최종 물리 입력과
보호한 소스의 해시가 같은지도 검사했다.

## 잔여 위험과 다음 작업

차량은 여전히 실차 특징을 해석한 게임 모델이다. 특히 전면 형상·유리 하단·
램프 외곽의 실차 비례는 추가 모델링 여지가 있다. 실제 휴대폰, 장시간 발열,
서로 다른 기기/네트워크의 온라인 외관과 사람 운전 평가는 이번 검증이 아니다.
1024 차고의 기존1px 상자 간격과 높은 품질의 p9533.3ms가 남아 있다.
다음 가장 중요한 작업은 이 시안의 차량별 전면/측면을 사용자가 평가한 뒤
가장 어색한 차 한 종의 실루엣을 우선 재제작하는 것이다.
