## 현재 결론

**1단계 코스 기준을 통과했다. 2단계 챔피언십의 기능 흐름은 확인했지만 성능 게이트에서 멈췄다.** 기존 남악의 최신 프레임 표본에서 지연이 관측되어, 사용자가 지정한 “기존 코스 성능이 나빠지면 멈추고 보고” 조건에 따라 해금·라이벌 개성·추가 시간대 구현은 시작하지 않는다. 전체 요청 완료가 아니다.

## 실패와 수정

- 처음 도로 ±7m 레이 검사에서 조각 사이 간격 실패2회를 기록했다. 공유 중간점으로 도로를 연결한 뒤 동일 기준으로 재검증했다.
- 정상 휴게소의 시각 지붕/벽이 도로를 덮는 결함을 중요 구간 캡처에서 발견했다. 전체 경로 대비 건물/전망대 공간을 확보하고 시각 메시 관통 시험을 추가했다. 경로·충돌 자료 해시는 그대로였다.
- 초기 야간 조명 평면이 도로를 덮어 보이던 문제를 조명 평면 제거로 수정했다.
- 배경 탭이 동시에 렌더링하던 성능 측정 혼선을 기록하고, 일시정지 렌더 생략을 넣었다. 이번 남악 지연은 별도의 최신 표본이며 이전 개선으로 덮지 않는다.
- 검증용 옛 버전 임시 폴더를 삭제하려던 작업은 자동 승인 검토가 “blocked by policy”로 거절했다. 구체적 이유는 제공되지 않았다. 삭제하지 않고 보존했다.

## 미검증·남은 위험

- **메달 차량/코스 해금, 5명 라이벌 성격, 다른 코스 야간은 미구현**. 남악 기존 성능 원인 분석이 우선이다.
- 현재 AI 런타임에는 기존 자동 복귀가 남아 있다. 이번 실제 주행에서 발생0이어도 코드가 제거됐다는 의미는 아니다. 라이벌 개성 단계에서 페달 탈출로 바꾸고 순간이동 없는 전체 완주를 검증해야 한다.
- 남악 헤드리스 fixture와 라이브 봉합 벽에는 기존 차이가 있다. 실제 브라우저 완주와 벽 별도 회귀를 함께 기록하되 완전한 자료 일치라고 주장하지 않는다.
- 저장은 브라우저 local/sessionStorage다. 휴대폰 실기기·장시간 메모리/발열·사람 난이도/시야 체감·전체 프레임 안정성은 미검증.
- Three/Rapier 번들500KB 초과 경고는 남아 있다.
