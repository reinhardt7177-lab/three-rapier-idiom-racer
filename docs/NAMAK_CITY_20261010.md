# 남악 시티 서킷 · 2026-10-10

## 트랙 구성

- 도청대로 출발 → 남악상가거리 → 영산강 수변 → 중앙공원 순환 → 도청대로 결승.
- 길이 2,927.34m, 주행로 폭 22m, 경로 간격 약 2m, 1,464개 경로 표본.
- 평탄한 아스팔트와 연속된 경계벽. 건물 본체는 실제 회전된 바닥 면적으로 도로와의 거리를 검사한다.
- 기존 해안 월드 6.84km는 유지. 차고의 코스 선택 링크로 맵과 해당 경로를 함께 불러온다. 선택한 맵 하나만 로드한다.
- 차량 8종·라이벌 5대·운전석·음악 2곡은 기존 기능을 사용한다. 코스 전환은 새 레이스를 준비하며 진행 중 레이스는 이어받지 않는다.

## 발견·수정 기록

1. 전체 미리보기의 카메라 원거리 한계가 기본 100m라 빈 화면으로 렌더링됐다. 맵 크기에 맞춰 10,000m로 수정했다. 실패 이미지는 `preview-initial-empty.png`로 보존했다.
2. 긴 청사를 바닥 면적 대신 외접 원으로 검사해 모델이 생략됐다. 회전된 사각형과 경로 사이의 실제 거리로 수정하고 청사를 재생성했다.
3. 출발선 페인트 상단이 0.07m로 떠 있었다. 노면에 밀착시키고 실제 GLB의 차량 공간 검사를 다시 수행했다. 실패 로그는 `map-tests-clearance-failure.log`에 있다.
4. 플레이어가 출발선에 계속 서 있으면 8m 뒤 차량은 추월을 시작할 공간이 부족했다. 남악의 출발 행 간격을 12m로 설정했다. 한 바퀴 돌아 다시 같은 정차 차량을 만날 때도 추월 판단이 다시 필요함을 추가 검사에서 발견했다. 재추월 전에 속도에 맞는 제동 거리를 확보한다. 실패 증거는 `stationary-grid-failure.log`에 있다.
5. 완주 차량이 결승선에서 저속으로 멈추면 두 차선의 통행을 막았다. 완주 순위·시간은 고정하되 AI는 현재 횡방향 위치를 유지하며 50m 더 이동한 뒤 제동한다. 이동 중에도 전방 차량 제동과 도로 주행 검사를 사용한다.
6. 움직이지 않는 뒤차에도 미래 차선 변경의 예측 여유를 요구해 정차 행렬이 풀리지 않았다. 차선에 정렬된 차가 앞으로 출발할 때는 뒤에서 정차한 차의 예측 여유만 제외한다. Rapier의 실제 충돌은 유지하며, 뒤차가 움직이거나 옆으로 이동하거나 자신이 후진·차선 변경 도중이면 기존 검사를 적용한다. 중간 차선 변경의 기존 동작이 달라지는 회귀 실패를 발견해 적용 조건을 좁혔다. `rear-buffer-regression-failure.log`와 `stationary-browser-failure.png`에 수정 전 증거를 보존했다.

## 검증과 한계

자동 검사는 실제 내보낸 GLB의 도로 방향·단절·차량 상부 공간, 건물 바닥 면적의 도로 여유, 코스별 모델/경로 연결을 검사한다. 실제 Blender 충돌 데이터로 차량 6대 자동 주행과 플레이어 정차 상태의 라이벌 5대 완주를 별도로 검사한다. 정차 시험은 런타임과 같은 추월 계획기·속도 배분·12m 출발 간격·결승 통과 후 이동을 사용하며 플레이어를 5cm 이상 밀지 않았는지도 확인한다.

브라우저에서는 차고 → 남악 출발·가속 → 운전석 전환·제동 → 메뉴·차고 복귀 → 해안 맵 선택·출발 → 남악으로 복귀를 확인했다. 코스별 제목·거리·모델·경로가 함께 바뀐다. 기본 창은 약 830×668px, 게임 영역은 830×467px이며 가로 화면을 유지했다. 화면 크기 대입을 실제 휴대폰 검증으로 간주하지 않는다.

최종 관련 자동 검사 **64개 통과**, `npm run build` 성공. `regression-final.log`에 남악 검사 5개, 추월·회피·정차 행렬 검사, 기존 해안 6.84km 전 구간 자동 레이스, 가로 모드·입력·음악·운전석·렌더링 검사를 함께 기록했다. 남악 정차 시험은 114.77초의 시뮬레이션 안에 라이벌 5대가 완주했다. 차량 6대의 기본 경로 주행 시험도 별도로 통과했다.

최종 브라우저에서도 플레이어가 출발선에 멈춰 있는 상태로 라이벌 5대 모두 `FINISH`를 확인했다(관찰 시 레이스 시간 약 113.43초). 동시 키보드 가속·조향 해제, 터치 GAS 해제, 메뉴 입력 초기화, 운전석 전환, 도로 복귀, 재시작과 차고 복귀를 확인했다. 증거는 `browser-flow.json`, `rivals-finish.png`, `first-person.png`, `namak-street.png`다. 브라우저 오류 로그는 마지막 검수에서 비어 있었다.

자동 시험과 브라우저 렌더링을 동시에 실행했으므로 관찰된 프레임 수치를 안정적인 성능 벤치마크로 간주하지 않는다. 신규 맵 GLB는 약 14.14MB이며 압축·반복 건물의 상세 단계 조절과 장시간 성능 검수는 다음 최적화 대상이다. 실제 휴대폰과 사람이 전 구간을 운전하는 체감 평가는 별도 확인이 필요하다. 플레이어의 최종 결과 화면은 이번 브라우저 주행에서 도달하지 않았으며 자동 완주를 사람의 전 구간 운전으로 보고하지 않는다.

형태와 주변 경관을 갖춘 웹 게임용 맵이며 실사 사진처럼 재현된 도시나 AAA급 완성도를 주장하지 않는다. 현재는 건물의 창·발코니·간판·수변 시설까지 제작한 단계이고, 반복되는 건물 형태와 식생 표현은 후속 미술 폴리싱 대상이다.
