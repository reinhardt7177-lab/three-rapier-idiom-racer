# Racing line quality round 74

차량 조작 보조 기능이 화면에서도 설명되도록 실제 코스 중앙에 동적 레이싱 라인을 추가했다.

## 적용 내용

- 120개 세그먼트로 트랙 포인트를 따라가는 테마별 발광 라인을 생성한다.
- `LINE` 보조가 켜지고 레이스가 시작된 경우에만 표시한다.
- 라인 투명도에 미세한 펄스를 적용해 정적인 디버그 선이 아니라 게임 HUD 요소처럼 보이게 했다.
- 런타임 종료 시 `runtimeAlive` 체크로 별도 애니메이션 루프가 정리된다.

## 검증

- 전체 정적 검사 및 Vite 빌드 통과
- 기본 상태에서는 라인이 숨겨지고, LINE 보조를 켠 주행에서만 표시되는 구조 확인
