## 2026-08-12 실측 증거

- APEX GT의 ORBIT·FRONT·SERVICE 시점을 캡처하고, 전면 카메라를 대칭 정면으로 교정했다.
- APEX GT·VOLT X·TRAILBLAZER·REDLINE 6·KART OOBI·FIELD FORCE에서 컬러맵, 휠, 차체 비율을 확인했다.
- 화면 앞을 가리던 피트 크루를 후방 서비스 구역으로 옮기고 크기·헬멧 발광을 낮췄다.
- 새 단일 390×844 탭에서 차고 59fps/p95 20.6ms, 레이스 45.7fps/p95 31.5ms를 기록했다.
- 6종 연속 전환 압박 테스트에서도 48.2fps/p95 27.9ms를 유지했고 콘솔 오류·경고는 0건이었다.
- 숨겨진 탭은 렌더 루프를 240ms 간격으로 낮춰 여러 게임 탭이 GPU를 동시에 점유하지 않게 했다.
- FIELD FORCE로 하버 링 3랩을 P1/62.32초에 완주해 물리 변경 후 랩·결과·보상 흐름을 재검증했다.

현재 Vercel 배포는 로컬 변경과 별도다. 배포 전 `npm run check` 통과와 프리뷰 URL 브라우저 검증이 필요하다.
