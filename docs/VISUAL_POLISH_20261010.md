# 1차 그래픽·코스 안내 폴리싱 · 2026-10-10

## 범위

현재 Blender + Three.js + Rapier 웹 앱의 재질·조명·코스 HUD를 수정했다. 차량8종의 형상·리깅, 맵/충돌 지형, 주행 물리와 AI 제어는 이번 변경에 포함하지 않는다. 공개 배포를 갱신하지 않았다.

## 변경

- 차량: 원본 페인트 색상은 유지하고 반사 마감을 조절했다. 도장 금속성0.34, 거칠기0.26, 클리어코트0.8/거칠기0.16. 유리는 거칠기0.14로 조절했다. 모델 표면의 형태 자체를 새로 제작한 작업은 아니다.
- 야외: 이미 반사 환경을 만들 때 쓰던 하늘을 실제 배경에도 표시한다. 카메라를 따라가며 맵 끝에서 하늘 밖으로 빠져나가지 않는다. 야외 환경광 강도0.12→0.32, 보조광0.55→0.45로 조절했다.
- 노면·지면: 하나의64×64 노이즈 텍스처를 공유해 잔질감과 큰 색 변화가 생긴다. 세계 좌표를 사용하므로 UV가 없는 도로에서도 이어진다. 밉맵으로 먼 곳의 반짝이는 잔무늬를 줄인다. 새 텍스처 원본16KiB, 삼각형·충돌체 증가는 없다. 하늘은 그리기 호출1회가 추가된다.
- 코스 안내: 실제 경로의30m 구간 방향 변화로 좌/우커브·급커브를 판정한다. 최대250m 앞을 안내하며 남은 레이스 거리와 진행률을 함께 표시한다. 작은 방향 오류는 짧은 단독 커브로 표시하지 않는다. 경로 점 밀도가 달라져도 같은 기준을 유지한다.
- 결승·복귀: 다음 바퀴의 커브를 표시하지 않도록 남은 거리까지 탐색한다. 마지막50m에서는 결승선을 우선 표시한다. 후진·복귀 시 진행 거리 기준으로 남은 거리를 다시 계산한다. 주행 중인 커브는 ‘커브 진행 중’으로 표시한다.
- HUD: 기존 상단 카드 안에 정보를 넣고 좁은 화면에서 글자·화살표·간격을 줄인다. 순위 패널은 아래로 내려 카드와 겹치지 않게 했다. 매 순간 바뀌는 거리의 음성 안내는 강제로 반복하지 않는다.

## 검증 기록

- 신규 시험7개: 좌/우와 코스 경계, 경로 점 밀도, 결승/후진/복귀, 실제 도심 코너, 단독 방향 오류, 충돌 정점 보존과 텍스처 단일 해제, 페인트 색상·텍스처 보존.
- 기존 리깅 시험은 원본 재질 수치를 그대로 요구해8건 실패했다. 의도한 마감 수치를 명시적으로 확인하면서 원본 템플릿의 금속성·거칠기·색상 보존 검사를 추가했다. 바퀴·캘리퍼·서스펜션·인스턴스 분리·기울어진 차체 검사는 삭제하지 않았다.
- 경로 점 밀도 시험은 초기에 실패했다. 고정30m보다 바깥의 샘플까지 잡히는 차이를 실제 샘플 간 거리로 정규화해 수정했다. 마지막50m의 결승 우선 표시도 경계 시험으로 확인한다.
- 실패 기록은 `artifacts/visual-polish-20261010/full-check-material-contract-before.log`, 중단 기록은 `full-check-finish-boundary-interrupted.log`에 보존했다.
- 최종 `npm run check:rebuild`: **113/113 통과**, 시험65.36초, 웹 빌드3.45초. `artifacts/visual-polish-20261010/full-check.log`. 기존 전체 코스 물리 시험·충돌·카메라·포인터 소유권/취소·포커스 해제 검사를 포함한다. 빌드의 대형 번들 경고는 남아 있다.
- 최종 브라우저: Windows 로컬 Codex 인앱 브라우저에서1280×720,390×844,844×390 화면을 확인했다. 가로 HUD는 상단 끝115px/순위 시작127px, 속도계 끝253.5px/터치 시작272.4px로 서로 겹치지 않았다. 세로에서도 HUD를 상단·양쪽에 두고 차량 주변 중앙 시야를 유지한다.
- 차량8종 선택 확인, 셰이더/브라우저 오류0건. 포인터로 GAS3초:81km/h, 놓은 뒤 가속·조향 입력0. W+SPACE+A 동시 입력 후 니트로0.844, 메뉴에서 모든 입력 해제. 수동 복귀는0km/h로 초기화하고 차고 복귀·다시 출발을 확인했다. S 키는 정지 상태에서 후진으로 전환되는 것도 확인했다.
- 사람이 완주한 레이스의 결과 화면까지 이번 브라우저에서 연결 검수하지는 않았다. 두 손가락의 실제 터치·포인터 취소·다른 앱 전환은 실기기에서 별도 검수한다. 자동 전체 코스 시험을 사람의 운전 평가로 간주하지 않는다.

## 한계·다음 작업

이 작업으로 차체 모델의 실루엣이나 도심 도로 진동이 해결됐다고 주장하지 않는다. 실제 휴대폰의 GPU·발열·두 손가락 입력 검증과 사람이 전체 코스를 운전하는 검수는 별도로 필요하다. 방향 안내는 경로 형태를 요약한 것이며 차종별 안전 속도를 보장하지 않는다.
