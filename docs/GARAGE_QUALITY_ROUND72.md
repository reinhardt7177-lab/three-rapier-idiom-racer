# Garage quality round 72

차고지의 역할을 단순한 차량 선택 화면에서 실제 모터스포츠 서비스 베이로 확장했다.

## 적용 내용

- 중앙 쇼룸 뒤쪽에 `garageInspectionArch`를 추가했다. 양쪽 프레임, 발광 라인, 상단 라이트, 이동식 스캔 바가 차량을 검사하는 것처럼 동작한다.
- 스캔 아치는 `runtimeAlive`를 확인하며 정리 시 애니메이션 루프가 종료된다. 모바일에서는 속도와 조명을 낮춰 GPU 부담을 줄인다.
- 중앙 플랫폼 전면에 노랑/검정 피트 안전 스트라이프를 추가해 차량 전시 영역과 서비스 동선을 분리했다.
- 기존 telemetry panel, overhead crane, pit crew, Retro Urban 배경과 충돌하지 않도록 아치는 차량 뒤쪽에 배치했다.

## 검증 기준

- 차고 첫 진입에서 폴백 차량이 먼저 보이고 검사 아치가 뒤에서 작동해야 한다.
- SERVICE 카메라에서 스캔 바가 차량을 가리지 않고 좌우로 이동해야 한다.
- `prefers-reduced-motion` 및 모바일 품질 모드에서 아치의 조명/스캔 속도가 낮아져야 한다.
- 전체 정적 검사와 Vite 빌드를 다시 통과시킨다.
