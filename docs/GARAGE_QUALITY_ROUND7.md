# Garage Quality Round 7

## 이번 라운드에서 다듬은 것

- Kenney 차량 텍스처와 Retro Urban 텍스처의 URL 매핑을 분리했다. 차량의 `cars/Textures/colormap.png`가 도시 텍스처로 잘못 치환되지 않도록 하고, Retro Urban 장식만 curated 텍스처 폴더로 보정한다.
- 쇼룸 조명을 낮춰 차체의 하이라이트가 날아가지 않도록 했다. 스테이지 포인트 라이트, 세 개의 스포트라이트, ACES 노출, 블룸 강도를 함께 조정해 차체 색·타이어·휠 피벗이 한 화면에서 읽히게 만들었다.
- 차량 선택 화면에서 서킷 선택 화면으로 넘어간 뒤 실제 하버 링 레이스 진입까지 회귀 확인했다.
- 새로고침 후 브라우저 콘솔에서 텍스처 로딩 경고가 재발하지 않는 것을 확인했다.

## 품질 기준

1. 차량 재질은 흰색으로 번지지 않고 선택한 차의 대표 색을 유지한다.
2. 도시 장식은 지연 로딩되어 첫 쇼룸 프레임을 막지 않는다.
3. 차량과 장식 GLB의 텍스처 경로는 서로의 `colormap.png`를 공유하지 않는다.
4. 쇼룸 → 서킷 선택 → 레이스 진입 흐름에서 콘솔 오류가 없어야 한다.
