# 레이싱 AI 3회 고도화 · 2026-10-15

## 목적과 적용 범위

플레이어가 앞차를 관찰하고 추월 타이밍을 고를 수 있도록 라이벌의 판단을 보강한다. 현재 작업 폴더의 기존 차량·그래픽·주행감 변경을 보존하며 AI 제어와 관련 검사만 수정했다. 로컬 개발본이며 운영 배포는 별도다.

## 1차: 상황에 맞는 제동과 회피

- 현재 바퀴 접지의 노면 grip을 제동 거리 계산에 반영한다. 낮은 접지에서는 코너를 더 멀리 보고 감속한다.
- 마주 오는 차량의 부호 있는 전방 속도를 접근 속도에 반영한다.
- 옆 차량의 횡방향 속도를 최대 1.2초 예측해 끼어들기 전에 감속한다.
- 일반 `aiInput` 호출은 기존 동작을 유지하고 라이벌 계획기가 새 안전 옵션을 선택한다.

## 2차: 슬립스트림과 니트로 운영

- 같은 차선의 움직이는 앞차가 14~30m 안에 있고 속도 차가 작을 때, 충전량이 낮으면 잠깐 슬립스트림을 유지한 뒤 추월한다.
- 정차 차량이나 빠르게 따라잡는 앞차에는 충전 대기를 적용하지 않는다.
- 니트로를 짧게 나눠 사용하고 분사 사이에 충전 시간을 둔다. 충전량이 낮으면 발동 요청을 멈춘다.
- 공중·접지 부족·벽 접촉·조향 보정·제동·차선 이동·충전 대기 중에는 새 니트로 분사를 하지 않는다.
- 니트로의 실제 소모와 충전은 기존 차량 물리가 처리한다. AI가 연료나 힘을 직접 추가하지 않는다.

## 3차: 개성, 난이도, 결승 공략

| 구성 | 보통 | 어려움 |
| --- | --- | --- |
| 기본 슬립스트림 대기 | 1.1초 | 0.7초 |
| 니트로 시작 잔량 기준 | 18 | 12 |
| 한 번의 최대 분사 | 1.3초 | 1.8초 |
| 분사 후 대기 | 1.5초 | 1초 |
| 결승 공격 구간 | 남은 400m | 남은 600m |

라이벌별 계수를 추가로 적용한다. RAVEN은 짧게 기다리고 적은 잔량부터 공격하며, MIST는 더 오래 충전하고 잔량을 보존한다. NOVA의 코너, BLAZE의 직선, LUNA의 균형형 기존 속도 특성도 유지한다. 쉬움은 전술 대기와 결승 공격을 추가하지 않는다.

결승 구간에서는 충전 대기를 생략하고 추월에 필요한 속도 우위와 니트로 발동 기준을 조금 낮춘다. **3랩 레이스는 총 주행 거리**를 사용하므로 첫 랩의 결승선에서 최종 공격으로 바뀌지 않는다. 플레이어와의 격차로 출력·위치를 조작하는 보정은 추가하지 않았다.

추월 중 새로 만난 느린 라이벌도 다시 공략한다. 연속 시도 사이에는 성격별 대기 시간을 두고, 이미 달리는 차선을 새 추월 차선으로 재선택하는 중복 시도를 차단한다. 정차 장애물은 대기 시간과 관계없이 기존 안전 판단으로 우회할 수 있다.

- 초기 짧은 검사에서 차량 8종이 실제 Rapier 직선에서 정차 플레이어를 접촉 없이 추월·복귀했다. 전체 코스 무충돌 보장은 아니다.

- 최종 후보의 해안 쉬움 3랩에서 SLK·RX-7이 10.57km 지점의 벽에 막혔다. 변경 전 동일 조건은 6대가 633.94초 안에 완주했다. 쉬움에까지 새 예측 제동을 적용한 회귀로 분리하고, 쉬움은 기존 제동 판단을 명시적으로 유지하게 수정했다. 제한 시간을 늘리거나 자동 복귀를 넣지 않고 같은 1,260초 상한으로 다시 검사한다. 실패 원본은 `final-easy-regression.json`·`.log`에 보존한다.
- 같은 폴더의 병행 작업에서 `physics.js`·`steering.js`도 바뀌었다. 따라서 최초 사본과의 시간 차이를 AI만의 효과로 해석하지 않는다. 쉬움 제동 보존 후 현재 물리에서 실시한 재검사는 6대가 629.49초 안에 완주했다. 최신 전체 7조건과 이전 AI의 핵심 대조 조건도 현재 물리에서 별도로 실행한다.

### 별도 조향 검사의 불일치 · AI 작업 종료 당시

`scripts/namak-polish.test.mjs`의 두 옛 검사는 모든 도로 속도에서 조향이 정확히 1.3배이며 저속 정지 한계가 0.52라고 요구한다. 병행 작업의 현재 `steering.js`는 코너 속도 구간에 추가 gain과 playerBlend를 적용하므로 이 전제와 충돌한다. 이 두 검사는 라이벌 계획기를 호출하지 않는다. AI 작업에서 해당 사용자 코드를 되돌리거나 옛 검사의 수치 기준을 완화하지 않았다.

현재 조향 설계를 검사하는 `scripts/steering-turn.test.mjs`는 별도 실행 **4/4 통과**했다. `steering-current.log`에 실제 8종 물리 회전·접지·고속·남악 완주 결과를 보존했다. 다만 이 결과가 위 두 옛 검사의 실패를 지우지는 않는다. 후속 작업은 현재 조향 설계와 기존 검사 계약을 정합시키는 것이다.
