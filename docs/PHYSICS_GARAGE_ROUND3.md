# 주행·차고지 품질 라운드 3

## 주행 보정

- 크루즈 스로틀을 켜고 조향 입력이 없을 때 레이싱 라인 보조를 자동 활성화한다.
- 보조 조향의 선행 체크포인트를 8개에서 10개로 늘리고 보정 강도를 높여 코너에서 바깥 연석으로 밀리는 현상을 줄였다.
- 사용자가 크루즈를 켜면 `LINE` 버튼도 함께 활성 상태로 표시된다.
- 하버 링에서 45~46km/h 크루즈로 코너를 통과하는 브라우저 검증을 완료했다.

## 차고지 생동감

- 서비스 베이에 3단 정비 상태 신호와 점멸 beacon을 추가했다.
- Retro Urban GLB가 참조하는 `roof.png`, `metal.png`, `planks.png`를 올바른 `Textures/` 상대 경로에 복원했다.
- 새 브라우저 탭에서 GLTF 텍스처 오류 0건을 확인했다.
- 턴테이블 링은 차량 실루엣을 방해하지 않도록 숨기고, 바닥 라인·스팟 조명으로 무대 중심을 유지했다.

## 회귀 확인

- 차고지 ORBIT / SERVICE 화면
- APEX GT·VOLT X 차량 교체
- 390×844 모바일 차고지
- 하버 링 크루즈 코너 주행
- 에셋·차량·진행 데이터 검사 통과
