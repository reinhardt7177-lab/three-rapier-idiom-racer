# 코너 조향·접지 보강 · 2026-10-10

## 문제와 수정

남악 코너에서 차량이 바깥쪽으로 밀리고 충분히 돌아가지 않는다는 사용자 보고에 따라 현재보다 조향을 1.3배 강화했다. 여기서 회전반경 개선은 더 작은 원으로 돌도록 한다는 뜻이다.

- 플레이어 조향 감도: 이전 기본 대비 1.3 → 1.69. 현재 설정에 추가 30%를 적용한다.
- 이전 조향 함수의 감도 상한 1.3도 1.69로 수정해 실제 앞바퀴에 전달한다.
- 플레이어 타이어 grip도 기존 차량별 값의 1.3배로 보강한다. 각도만 늘린 최초 시도에서는 수프라의 실제 회전반경이 약 24.3m로 줄지 않았다. 타이어 접지 한계에 닿았기 때문이다.
- `playerRaceTuning()`은 차량 설정의 복사본을 반환한다. AI 5대는 원래 조향 감도·접지 설정을 사용한다.
- 저속 최대 중심 조향각은 기존 0.52rad를 유지한다. 이미 최대 각도에 닿은 저속 구간은 추가 30%가 그대로 적용되지 않는다. 고속에서는 기존 속도별 제한 곡선을 유지하며 그 안에서 각도를 강화한다.
- 물리 회전과 앞바퀴 표시·운전석 핸들은 같은 조향 상태를 사용한다. 차체 위치나 회전 방향을 강제로 바꿔 코너링을 연출하지 않는다. 기존 접지 자세 안정화 장치는 수정하지 않았다.

## 실제 물리 비교

평평한 시험장에서 실제 변속·가속으로 약 90km/h에 진입한 뒤 좌우 조향을 비교했다. 급조향 중 타이어 마찰로 차가 감속할 수 있으므로 핸들이 반응한 이후의 87~93km/h 표본만 회전반경 측정에 사용했다. 이전·수정본의 표본 평균 속도 차이는 1km/h 미만이며, 아래 결과에서 실제 차이는 0.1km/h 이내다.

| 수프라 | 24.81m | 19.43m | 21.7% |

같은 시험에서 차량8종의 좌우 회전, 앞바퀴 실제 각도, 네 바퀴 접지와 차체 자세를 확인했다. 180km/h 시험과 입력 해제 후 핸들 복귀도 확인했다. 회전반경은 각도와 정확히 같은 비율로 변하는 값이 아니다.
