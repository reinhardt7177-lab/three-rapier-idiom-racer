## 해결할 문제와 범위

## 재현과 원인

일반 6대 + 일반 교통 6대 여수 자동 주행은 기존 소스에서 전원 완주했다. 따라서 일반 완주 성공만으로 사용자의 코너 정체를 부정하지 않았다.

실제 여수 아스팔트의 56.99km/h 제한 커브(경로 지점 211)에 정차 플레이어와 같은 차로의 AI를 놓으면, 변경 전 양쪽 차로에서 AI는 35초 내내 `follow/curve`, 추월 시도 0회로 멈춘다. 기존 계획기는 커브에서 추월을 항상 금지해, 앞차가 계속 정차하면 무한 대기가 된다.

수정은 정체 대기 1.2초 이상·자차 8km/h 미만·앞차 약 3.6km/h 미만·9~35m 여유일 때만 기존 전체 아스팔트/장애물/후방 접근차 검사를 통과한 반대 차로로 우회한다. 우회는 14km/h와 짧은 경로 조준을 사용한다. 앞차를 완전히 지날 때까지 이 제한을 유지한다. 직선에서 추월을 시작한 차가 코너의 정차 차량을 만날 때도 짧은 저속 경로를 사용해 안쪽을 가로지르지 않게 한다. 페달만 바꾸며 위치·진행 거리를 보정하지 않는다.

실제 레이스는 추격 카메라에 `stableRide:true`를 전달하는데, 기존 카메라는 이 경우 충돌 흔들림까지 꺼 버렸다. 실제 접촉 때만 빠르게 사라지는 최대 12cm 추격 카메라 반응과 1도 미만 운전석 렌즈 반응을 적용했다. 정지 중에는 시간 진행이 없고, 움직임 줄이기 설정에서는 끈다.

## 충돌의 결과와 구분

- 실제 월드 solver 전후의 수평 속도 차이만 관찰한다. 일반 타이어 가속과 수직 지지는 제외한다.
- 큰 충돌 뒤 최대 0.65초 동안 구동력 최대 48%, 뒷타이어 접지 최대 14%가 일시적으로 줄었다 회복한다. 입력·후진·제동은 계속 작동한다. 몸체 자세/속도/각도를 강제로 쓰지 않는다.
- 벽에 계속 기대어 가속하는 경우의 구동력은 60%, 긁힘 저항은 기존 5.5→9m/s²다. 실제 벽 접촉이 풀리면 적용하지 않는다.
- 벽 긁힘은 작은 지속 불꽃·금속음, 차량 충돌은 낮은 차체 충격음, 강한 벽 충돌은 더 밝은 금속음을 사용한다. 고정 160개 입자 버퍼를 유지한다.

## 현재 검증과 실패

새 5대 정체 시험에서 초기 후보는 한쪽 차로를 지나면서 접촉했다. 그 표본과 실패 기준을 보존하고, 정차 차량 곁에서 보통 속도로 복귀하며 코너를 자르는 원인을 수정했다. 최종 양쪽 차로 모두 5대가 실제로 통과했고 플레이어 접촉 0·오프로드 표본 0이었다. 마지막 차량 통과는 각각 22.45초와 24.375초다.

운전석 각도 시험 초기에는 +Z를 보는 카메라의 Euler z값이 π일 수 있는 점을 놓쳤다. 허용 각도를 바꾸지 않고 기준 카메라와의 quaternion 각도 차이로 실제 추가 회전을 측정하도록 바로잡았다. 첫 도로 fixture 검색은 Rapier 공간 질의 갱신 전이라 실패했으며 월드 초기 스텝 후 기존 동일한 아스팔트 조건으로 다시 구성했다.

첫 전체 검사는 481개 중 480개 통과·1개 실패(846.618초)였다. 실패는 `ride-repair.test.mjs`의 기존 안정 카메라 계약이었다. 해당 시험의 무진동 기준을 낮추지 않고 `contactResponse` 명시 옵션을 도입해 기존 기본 동작을 보존하고 실제 레이스에서만 접촉 반응을 켰다. 기존 시험+새 충돌 시험 11/11 재통과(1.420초). 전체 검사는 이 수정 후 다시 수행한다.

## 후속 화면 검사에서 발견한 결함

브라우저에서 실제 벽 충돌(수평 충돌 변화량 10.27m/s)을 재현했을 때, CCD가 이미 차체를 분리해 이벤트에 대응하는 solver 접촉점이 없었다. 이 경우 불꽃이 나오지 않았다. 실제 접촉력 이벤트가 존재하는 경우에만 상대 충돌체 표면으로 투영한 점을 연출 위치로 사용하도록 보완했다. 물리 차체를 이동하거나 충돌을 새로 만들지 않는다. 접촉점 출처도 `solver`/`collider-projection`으로 구분한다.

정체 탈출을 취소하고 원래 차로로 돌아오면 저속 제한을 반드시 해제한다. 최초 취소 시험은 실제 커브의 정상 목표 속도가 28.69km/h인데 35km/h를 요구한 잘못된 fixture였다. 제한 숫자를 낮춰 제품 검사를 통과시키지 않고, 동일 커브·동일 차량의 새 일반 계획기 결과와 정확히 비교하도록 고쳤다. 계획기의 0.2초 재판단 간격도 기다린다. 이 시험은 탈출 제한 14km/h가 남는 경우 계속 실패한다.

최종 관련 시험은 20/20(5.968초): 양쪽 차로 실제 5대 통과·탈출 취소, 충돌 회복/분류/카메라/CCD 불꽃, 기존 안정 주행·충돌 검사다. 새 투영 시험의 첫 실패는 Rapier 벡터의 프로토타입과 일반 객체를 비교한 시험 오류였으며 좌표 비교로 바로잡았다. 실패 로그는 보존한다.

전체 검사 재실행 중 두 번은 각각 취소 fixture 수정과 위 화면에서 발견한 불꽃 결함 수정 때문에 직접 중단했다. 중단된 로그를 전체 성공으로 세지 않는다. 최종 전체 검사는 `check-complete.log`에 기록한다.
