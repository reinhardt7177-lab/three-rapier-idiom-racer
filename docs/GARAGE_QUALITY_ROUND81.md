# Garage quality round 81

서비스 카메라에서 정비 구역이 단순한 바닥 패드로 보이지 않도록 실제 리프트 실루엣을 추가했다.

- `garageLiftRig()`가 중앙 리프트 데크, 양쪽 레일, 리프트 암, 상태등을 구성한다.
- 서비스 카메라에서 상태등이 호흡하듯 점멸해 차량 점검 중인 느낌을 만든다.
- 기존 `BAY 02`, `SERVICE GRID`, `PIT CONTROL`, 검사 아치와 겹치지 않도록 서비스 베이 내부에 배치했다.
- 모바일에서는 리프트 그림자 계산을 줄여 기존 성능 예산을 유지한다.

검증: `npm run check` 통과.
