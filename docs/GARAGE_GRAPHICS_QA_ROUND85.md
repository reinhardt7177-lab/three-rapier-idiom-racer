# Garage graphics QA — round 85

이번 라운드는 차고지의 영웅 차량 노출과 모바일 화면을 기준으로 진행했다.

## 적용

- Kenney 차량 차체 재질을 낮은 거칠기·중간 금속성으로 조정해 실루엣 하이라이트를 확보했다.
- 차량 뒤쪽의 과한 색 번짐을 줄이고, 중립 키라이트를 사용해 빨강·파랑·청록 차량의 도색 대비를 유지했다.
- 차고 조명은 `limitGarageLighting`으로 상한을 두고, 차고 마지막 빌드 단계에서 전체 조명을 다시 캡핑한다.
- 모바일 카메라 줌을 `0.78`로 적용해 390px 화면에서도 영웅 차량이 화면 아래에서 잘리지 않게 했다.
- 차고의 쇼룸 모드(FRONT / ORBIT / SERVICE), 텔레메트리 패널, 피트 크루, 오버헤드 리그와 기존 Retro Urban 프롭 배치를 유지하면서 화면 계층을 확인했다.

## 시각 검증

- 데스크톱 차고: APEX GT 전면/오빗 뷰에서 차량 도색, 스펙 패널, 차고 배경 간 대비 확인.
- 390×844 모바일 차고: 차량 전체 실루엣, 프로필 카드, 차량 도크 스크롤, SELECT CIRCUIT 버튼 확인.
- 390×844 트랙 선택: 3개 서킷 카드와 ENTER RACE 버튼이 겹치지 않음.
- 390×844 레이스: HUD, 트랙 맵, 속도계, 조작 버튼이 화면 안에 유지됨.

## 다음 라운드 후보

- 차고 SERVICE 뷰에 실제 휠 교체 애니메이션과 공구 카트 상호작용 추가.
- 각 트랙의 관중석·피트·타이어월 밀도를 동일한 시각 기준으로 맞추고, 고속 코너의 연석 충돌을 추가 검증.
