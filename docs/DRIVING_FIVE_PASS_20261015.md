# 운전감·조향·주행 연출 5회 고도화

2026-10-15 · 로컬 구현과 관련 검증 완료. 운영 배포·커밋·푸시는 수행하지 않았다.

## 비교 기준과 판단

- [EA / NFS Unbound — The World Is Your Canvas](https://www.ea.com/games/need-for-speed/need-for-speed-unbound/news/the-world-is-your-canvas): 가속·드리프트 등 실제 행동에 맞춰 표현을 주는 방향을 참고했다. 이번 게임에는 사실적인 연기를 유지하면서 강도를 행동에 연결했다.
- [Gran Turismo 7 / Update 1.31 물리·보조 설정 변경](https://www.gran-turismo.com/us/gt7/news/00_1462138.html): 타이어·서스펜션·조향 반응을 함께 점검하는 기준으로 삼았다. 해당 게임의 비공개 물리나 감각을 복제한 것은 아니다.
- 현재 게임을 측정한 결과, 조향의 좌우 대칭·짧은 입력 응답·자동 복원·접지는 관련 물리 시험을 통과했다. 숫자를 일괄 증폭하기보다 확인된 입력 충돌과 표현 지연을 수정했다.

## 다섯 번의 점검과 수정

| 회차 | 발견 사항 | 최종 반영 | 검증 |
| --- | --- | --- | --- |
| 1. 출발·가속·제동 | 실제 변속에 비해 RPM 음향 반응이 늦어 변속감이 약함 | 실제 `shifting` 구간의 RPM 추종 시간을 65ms로 단축. 실제 엔진 신호·변속 시 음량 처리 유지 | 수정 전 실패 재현 후 관련 11개 통과. 117ms 안에 충분한 RPM 하강 확인 |
| 2. 핸들·입력 | 터치 페달이 포커스를 가진 상태에서 키보드 조향이 무시됨 | 주행 페달에 표식을 붙여 키보드 동시 조작 허용. 메뉴 버튼의 기본 키보드 동작 유지 | 관련 16개 통과. 짧은 좌우 입력, 대칭, 복원, 실제 남악 조향 포함 |
| 3. 드리프트·VFX | 작은 미끄러짐에도 강한 연기가 나고 고속 배기가스가 과밀함 | 바퀴별 실제 slip으로 연기 크기·투명도 조절. 고속에서 배기가스 발생량 감소 | 관련 22개 통과. 공중 타이어 무발생·160개 입자 한도·정지 시 배기 유지 |
| 4. 추격 카메라 | 안정화 옵션이 가속·제동 반응까지 억제함 | 실제 페달·가감속 신호를 천천히 추종하는 거리/FOV 반응. 전진 슬라이드 때 실제 진행 방향을 일부 바라봄 | 관련 18개 통과. 30/60/120Hz·정지·reduced motion·230km/h 거리 한도·변속 중 출렁임 제한 |
| 5. 1인칭·통합 | 운전석에도 가감속 구분이 부족함 | 눈과 실내 위치는 유지하며 작은 렌즈 반응 추가. 레이스 런타임에 두 카메라 연결 | 관련 89개 전부 통과. 실제 Rapier→신호→연기·음향·추격 카메라 통합 및 별도 1인칭 시험 |

카메라 반응은 가속 시 약 0.42초, 제동 시 약 0.16초로 반응한다. 변속 때마다 카메라가 앞뒤로 튀지 않도록 별도 필터를 사용한다. 카메라만 바뀌며 차체·휠·충돌 자세를 덮어쓰지 않는다.

## 변경 전후 실측

동일한 평지·실제 레이스용 8종 튜닝·120Hz 물리에서 0→100km/h, 이어서 약 100→0km/h 제동을 측정했다. `baseline.json`과 `final-matrix.json`의 8행은 바이트까지 같다. 아래는 게임 내 수치이며 실차 제조사 수치가 아니다.

| 차량 | 0→100km/h | 제동 거리 | 정지 접지 |
| --- | ---: | ---: | ---: |
| Supra | 4.025초 | 36.950m | 4바퀴 |
| SLK | 4.917초 | 36.943m | 4바퀴 |
| Mustang | 4.183초 | 37.145m | 4바퀴 |
| Porsche 911 | 3.883초 | 37.015m | 4바퀴 |
| GT-R | 4.000초 | 37.053m | 4바퀴 |
| RX-7 | 3.642초 | 36.850m | 4바퀴 |
| M3 | 4.233초 | 37.050m | 4바퀴 |
| Huracán | 3.125초 | 36.991m | 4바퀴 |

기존 가속·제동·조향 물리 튜닝은 유지했다. 이번 작업은 체감 전달과 확인된 입력 오류를 개선한 것이다. 레이스의 기존 `launchEnabled:false` 설정도 바꾸지 않았으며 새 번아웃 물리를 구현했다고 주장하지 않는다.

## 실행한 검증과 재실행

- 최종 관련 13개 파일, 89/89 통과, 약 199.7초. 전체 프로젝트 시험 전부를 재실행한 결과는 아니다.
- Vite 빌드 성공, 58.48초. 기존 큰 번들 경고는 남아 있다.
- 실제 내장 브라우저: 남악 차고→출발→키보드 가속 76km/h→조향/드리프트·제동 입력→1인칭→메뉴→차고 복귀. 별도 고정 빌드에서는 64km/h 가속, 조향 후 도로 복귀, 62km/h 가속 화면 저장, 1인칭 전환을 확인했다. 플레이어 수동 완주나 정밀 제동거리 측정으로 확대하지 않는다.
- 개발 서버의 변경 감지로 중간 캡처가 로딩 화면이 된 사례를 보존했다. 빌드 완료 후 별도 `qa-build-final`에 복사하고 5199 포트에서 다시 확인했다. 이 고정 빌드에서도 메뉴의 입력·시간 정지와 차고 복귀를 확인했고 실행 오류는 0건이었다. `browser-final.json`에 남겼다.
- 테스트 제목을 실제 검증 범위에 맞춰 정리한 뒤 새 전용 9개 시험도 다시 통과했다(`final-targeted.log`).
- 5198에서 일시 변경한 날씨 설정은 원래의 비로 복원했다. 진행 데이터는 삭제하지 않았다.

```powershell
npm run check:driving-feel
npm run build
node scripts/driving-feel-matrix.mjs artifacts/driving-five-pass-20261015/recheck-matrix.json
```

최종 전용 명령은 위 89개 시험과 같은 목록이며 새 회귀 시험은 `check:race`, `check:rebuild`에도 추가했다.

## 실패·한계와 다음 확인

- 1차 통합 시험은 고정된 가속 시간에 비해 제동 구간이 짧아 정지하지 못했다. 실패 로그를 남기고 자극 조건을 ‘실측 100km/h에 도달하면 제동’으로 바꿨다. 정지 성공 기준이나 제품 브레이크는 완화하지 않았다.
- 초기 브라우저 연결/탐색 시간 초과와 로딩 화면 캡처를 보존했다. 이후 같은 탭에서 실제 진입·주행을 확인했다.
- 이번 변경의 FPS 향상이나 장시간 안정성, 실기기 터치·게임패드·핸들 컨트롤러, 사람이 듣는 음질 평가는 측정하지 않았다. 실제 사용자가 주행하며 카메라 강도와 엔진음을 평가하는 것이 다음 확인이다.
- 같은 작업 폴더에서 진행 중인 차량 미술·AI·지도 변경은 보존했다. 이 문서의 89개 결과를 다른 동시 작업 전체의 검증 결과로 간주하지 않는다.
- Colab 실제 계산은 사용하지 않았다. 최신 사용자 지침에 따라 추가 자동 연결·자동 활용은 중지한다.
