# 여수 밤바다 · 교량 빛과 수면 표현 개선

## 요청·현재 판정

2026-10-13 사용자의 맵별 병렬 그래픽 고도화·최적화 요청 중 여수를 담당했다. 기존 OSM 도로·경로·Blender/GLB·물리·AI·교통·메달은 보존한다. 부모 작업의 기존 여수 빗길 회귀 해결과 전체 검사 뒤 공통 런타임에 연결한다.

**담당 모듈의 Node 시험 13개는 통과했다.** 실제 게임의 시각 개선 여부, GPU 셰이더 컴파일, 브라우저 프레임 전후 값은 부모의 별도 검수 대상이다. 이 문서의 초기화 시간과 기하 비용을 평균 FPS 또는 제품 성능 향상으로 표현하지 않는다. 커밋·푸시·PR·main 병합·배포는 담당 작업에서 수행하지 않았다.

## 구현

- `src/rebuild/yeosuVisuals.js`에 별도 시각 모듈을 추가했다. 기존 밤하늘과 6개 지역/전조등 광원을 재사용하며 새 실제 조명·그림자 맵·후처리 Bloom·반사 렌더 패스는 추가하지 않는다.
- Blender가 원래 노드를 재질/구간으로 합친 뒤에도 발광 표면에서 위치를 읽는다. 실제 현재 GLB에서 교량 8곳, 도로 조명 298곳, 간격을 둔 수변/교량 반사 광원 61곳을 추출해 `src/rebuild/yeosuVisualLayout.js`에 오프라인으로 저장했다. 임의 위치에 새 교량을 만들지 않는다.
- layout은 정확한 GLB SHA256·바이트 크기·코스 revision과 좌표/역할을 기록한다. 런타임에서는 발광 삼각형 수와 좌표 모멘트로 현재 구조를 식별한다. 기존 배칭/루트 이동은 유지하되 구조/revision이 달라지면 현재 발광 지오메트리를 읽는 경로로 돌아가며, 출시 시험은 정확한 원본 GLB 해시와 좌표 일치를 요구한다. GLB를 변경했을 때 옛 배열을 무조건 재사용하지 않는다. 인터리브 버퍼의 정점도 처리한다.
- 기존 2삼각형 바다의 시각 표면을 공유 셰이더의 2삼각형 바다로 교체한다. 원본 바다의 충돌·지오메트리·재질·행렬은 그대로이며, 레이스 표시 중에만 원본의 `visible`을 가리고 레이스 밖/해제 시 원래 값으로 복원한다.
- 물결과 카메라 쪽으로 길게 끊어진 청록/분홍/따뜻한 반사 줄기를 계산한다. **분석적 시각 근사이며 실제 화면 공간 반사나 광선 추적 반사가 아니다.** 원래 사각 반사 장식보다 8cm 위의 새 수면이 사각형을 덮는다.
- 8m 격자 데이터 텍스처로 도로 중심·가장자리의 주변을 보수적으로 제외한다. 모든 경로 지점 −7/0/+7m가 마스크에 포함되는지 실제 경로로 확인했다. 이 텍스처는 충돌체나 접지 판정에 사용하지 않는다.
- 교량 상단/가로등 주변의 작은 빛 번짐은 공유 재질의 인스턴스 쿼드 1~2회로 그린다. 카메라 거리에서 감쇠하며 그림자를 만들지 않는다. 고유 GPU 자원은 한 번 해제하고 원본 자원을 해제하지 않는다.
- 레이스 시간으로 물결을 갱신해 일시정지 중 움직이지 않는다. 반사 광원 선택은 매 프레임 정렬하지 않고 0.25초 간격에만 계산한다.

공통: 새 실시간 조명 0, 그림자 맵 0, 반사 별도 패스 0, 새 하늘 0, 반사 제외 텍스처 85,593bytes, layout 모듈 21,343bytes. 기존 GLB/경로/Blender 파일의 크기와 바이트 해시는 변경하지 않았다. 추가 JavaScript와 GPU 셰이더의 실제 번들/프레임 비용은 통합 후 별도 측정이 필요하다.

첫 연결 성분 구현에서 광원 추출 5,565.64ms·전체 모듈 구성 6,748.44ms가 나왔다. 이 느린 수치를 [원자료](../artifacts/graphics-parallel-20261013/yeosu/candidate-cost-initial-recorded.json)에 남겼다. Blender 상자 표면의 24정점/36인덱스 형태를 전체 블록마다 검사하는 빠른 경로를 추가하고, 형식이 다른 9개 메시만 일반 연결 성분 검사로 처리했다. 실제 113개 발광 메시에서 5,180개 상자를 확인했다.

빠른 경로 표본은 추출 72.78ms·전체 모듈 구성 54.20ms였다. 전후 호스트 부하가 달랐으므로 통제된 개선 비율로 선언하지 않는다. 두 방식 모두 교량8/도로298/반사61곳이며 조명 위치는 현재 GLB에서 가져온다. [현재 비용 표본](../artifacts/graphics-parallel-20261013/yeosu/candidate-cost.json).

동적 추출 버전의 8시험 실행에서는 광원 추출 시험이 5,116.86ms였고 전체 시험이 30,186.99ms였다. 이 나쁜 호스트 부하 표본도 보존한다. 시작 시 CPU 초기화 비용이 항상 54ms라고 선언하지 않는다.

부모 요청에 따라 오프라인 layout을 적용했다. [layout 생성·원본 해시 근거](../artifacts/graphics-parallel-20261013/yeosu/bake-provenance.json)의 생성 CPU 시간은 313.38ms였다. [bake 적용 계측](../artifacts/graphics-parallel-20261013/yeosu/baked-cost-first.json)에서는 현재 구조 확인/좌표 준비 894.02ms·전체 모듈 구성 1,465.08ms로 여전히 부하에 따른 초기화 지연이 남았다. 120회 객체 갱신의 CPU 평균0.01390/p950.06640/최대0.84550ms였다. 이는 GPU 프레임·레이스 성능이 아니며 해당 계측 뒤 인터리브 정점의 구조 확인만 추가했고 매 프레임 update 코드는 유지했다.

오프라인 layout 재생성은 [전용 helper](../artifacts/graphics-parallel-20261013/yeosu/bake-layout.mjs)로 실행하며, 이전 자료를 덮어쓰지 않도록 먼저 기존 생성 근거를 새 이름으로 보존해야 한다. 원본 GLB가 달라지면 SHA·구조·layout을 함께 다시 만들고 관련 시험을 실행한다.

## 실제 실행한 검사

로컬 Windows Node/Rapier와 별도로 이 담당 시험은 Three.js CPU 객체 검사다. Colab 또는 GPU 검사를 실행했다고 주장하지 않는다.

`node --test scripts/yeosu-visuals.test.mjs`: **13/13 통과**, 실패·스킵 0. [최종 시험 로그](../artifacts/graphics-parallel-20261013/yeosu/unit-tests-layout-final.log). 이전 [7개](../artifacts/graphics-parallel-20261013/yeosu/unit-tests.log)·[8개](../artifacts/graphics-parallel-20261013/yeosu/unit-tests-final.log)·[12개](../artifacts/graphics-parallel-20261013/yeosu/unit-tests-baked.log) 표본을 보존했다.

1. 실제 GLB의 교량 8곳/수변 간격/빛 위치 확인.
2. 모든 원본 정점·재질 참조·충돌 annotation·행렬 불변.
3. 실제 경로 전체 ±7m 반사 제외·바다 높이가 아스팔트보다 충분히 아래·Fog uniform 확인.
4. 품질별 추가 호출/삼각형/광원 상한, 새 실제 조명/반사 패스/하늘 없음.
5. 일시정지 시간 유지·거리 선택·원래 바다 표시 복원.
6. 고유 GPU 자원의 한 번 해제·원본 자원 보존.
7. 관련 없는 빈 세계에서는 빛/바다/추가 호출 없음.
8. 재경기 시 elapsed가 300→0으로 돌아가도 바로 반사 광원을 다시 선택하고, 품질 변경 즉시 셰이더 광원 상한을 적용한다.
9. 정확한 GLB SHA와 layout source 좌표가 0.1mm 이내로 일치한다.
10. 런타임 배칭 후에도 구조 식별이 일치한다.
11. 변경된 발광 geometry/revision은 현재 표면으로 fallback한다.
12. world 루트 이동에 따라 모든 baked 광원도 이동한다.
13. 인터리브 GLTF 정점은 같은 위치일 때 layout을 유지하고 변경 시 안전하게 fallback한다.

담당 파일은 새 파일이므로 기존 파일 사본은 없으며, [변경 전 존재/시각 기록](../artifacts/graphics-parallel-20261013/yeosu/before/file-state.json)과 [기존 제작물 해시](../artifacts/graphics-parallel-20261013/yeosu/before/asset-hashes.json)를 보존했다. runtime/package/공통 제작 스크립트는 담당 작업에서 변경하지 않았다.

## 미검증·다음 우선순위

부모 작업에서 기존 여수 빗길 완주 회귀를 먼저 해결한 뒤 모듈을 연결한다. 같은 Intel Iris Xe/WebGL2·화면·DPR·카메라·경과 시점에서 기존/수정 야경과 도로 시야, 셰이더 오류, 30초 프레임 평균/p95/최대/>50ms, 실제 초기 다운로드와 네 화면 크기의 UI를 검수한다. 해안·남악 기존 코스 p95가 2ms 이상 악화하면 원인을 고치거나 품질 설정 뒤로 제한한다.

수면의 분석적 반사가 사진처럼 보이는지는 아직 화면으로 판정하지 않았다. 완전한 해안 지형/개별 건물 고증·실제 휴대폰·장시간 발열/성능은 미검증이다. AAA 품질·현장 완전 재현·전체 게임 출시 통과로 표현하지 않는다.
