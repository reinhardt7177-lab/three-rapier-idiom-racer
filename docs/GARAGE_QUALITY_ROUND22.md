# Garage quality round 22 — showroom final pass

이번 라운드는 차고를 레이싱 게임의 허브 화면처럼 보이게 하는 마지막 시각 품질 패스다.

## 3D 무대

- 차량 중심 원형 스테이지에 네 방향 진입 유도 chevron 마크를 추가했다.
- 차량별 accent 색상과 스테이지 링·반사광·서비스 조명을 같은 색 체계로 유지했다.
- FRONT / ORBIT / SERVICE 세 카메라를 실제 브라우저에서 확인했다.

## UI 계층

- 차고 헤더를 작은 bay 배지와 그림자 계층으로 정리했다.
- 선택 차량 패널에 상단 accent rail, 더 선명한 스탯 바, 깊이감 있는 패널 그림자를 추가했다.
- 하단 차량 도크를 유리 패널처럼 묶고, 선택 차량과 `SELECT CIRCUIT` 버튼의 대비를 강화했다.
- telemetry / last run 패널이 도크에 묻히지 않도록 z-index 계층을 재정렬했다.
- 모바일에서는 패딩·텍스트 크기·그림자 강도를 줄여 같은 정보 우선순위를 유지한다.

## 검증 결과

- 차고 렌더링: canvas, 10대 차량 카드, 선택 상태 확인
- 차고 → 트랙 선택 → 레이스 진입 성공
- 확인 상태: `RACE LIVE`, `SECTOR 01 / 03`, `LAP 1/3`
- 브라우저 로그: 오류 없음 (Vite/React 개발 안내 로그만 존재)
- 빌드 성공
- CC0 에셋 201개 / 7.5 MB, 차량 카탈로그 10개, 진행도 검증 통과
