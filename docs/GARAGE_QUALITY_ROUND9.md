# Garage Quality Round 9

## 이번 라운드 결과

- React Strict Mode와 화면 전환으로 런타임이 교체될 때 Three.js WebGL 컨텍스트를 명시적으로 반납하도록 정리했다.
- `renderer.forceContextLoss()`를 dispose 직전에 호출해 여러 번 새로고침하거나 다른 화면으로 이동해도 GPU 컨텍스트가 누적되지 않게 했다.
- 새 탭에서 차고지 렌더링을 다시 확인했고, 빈 화면·WebGL 생성 오류 없이 쇼룸과 차량 카드가 정상 표시됐다.
- 크루즈 주행으로 레이스 런타임을 장시간 유지한 뒤 같은 탭에서 차고지로 복귀해도 렌더링이 살아 있는지 확인했다.

## 품질 기준

1. Strict Mode 초기화/정리 사이클에서 WebGL 컨텍스트가 누수되지 않는다.
2. 레이스 화면을 오래 유지한 뒤 차고지로 돌아와도 차고지 캔버스가 검게 변하지 않는다.
3. 새로고침 후 차량·차고지 소품·UI가 함께 렌더링되고 콘솔 오류가 없어야 한다.

## 다음 라운드

- 레이스 결과 카드의 실제 완료 화면을 장거리 주행과 함께 시각 검증한다.
- 결과 화면에서 `RETURN TO GARAGE`를 눌렀을 때 선택 차량과 마지막 기록 배지가 자연스럽게 이어지는지 확인한다.
- WebGL 복구 이벤트가 발생한 브라우저에서도 재렌더링할 수 있도록 복원 핸들러를 검토한다.
