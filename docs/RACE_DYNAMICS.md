# 차량 주행·충돌 고도화 · 2026-10-09

현재 작업 대상은 Blender 외형 v4와 Three.js/Rapier 웹 재구성본이다. [로컬 실행](http://127.0.0.1:5190/). 공개 GitHub Pages의 기존 Unity v53에 배포한 변경은 아니다.

## 반영한 동작

- 플레이어와 AI 5대가 하나의 물리 월드에서 120Hz로 계산된다. 차체 위치와 기울기는 실제 동적 강체 결과를 사용한다.
- 차종별 질량·차체 충돌 크기와 무게중심을 적용했다. 수프라 1,480kg, SLK 1,450kg, 머스탱 1,680kg는 게임 조정값이며 제조사 시뮬레이션 데이터 인증값이 아니다.
- 후륜 구동, 토크 곡선, 6단 자동 변속, 짧은 변속 구동력 차단, 후진과 엔진 브레이크를 연결했다. 엔진음과 HUD가 같은 변속기 RPM을 사용한다.
- 네 바퀴가 개별 서스펜션 길이와 하중을 계산한다. 실제 조향각과 이동에 따른 회전을 Blender 리그에 전달한다. 디스크는 바퀴와 돌고 캘리퍼는 고정된다. 가짜 출발 회전은 이 버전에서 사용하지 않는다.
- 제동 시 앞쪽 하중 증가, 가속 시 차체 피치, 좌우 하중 차이를 줄이는 안티롤 힘과 속도에 따른 다운포스를 적용했다. 조작을 쉽게 하는 기존 드리프트·스핀 회복 보조는 유지한다.
- 차체끼리·벽·도로와의 충돌은 Rapier가 해결한다. 실제 접촉의 힘과 위치에서만 불꽃·충격음·짧은 카메라 반응이 발생한다. 연출 때문에 추가 충돌 충격을 중복 적용하지 않는다.
- 고속 카메라는 보간된 차량 자세를 따라간다. 움직임 줄이기 환경에서는 충격 흔들림을 끈다.
- RPM 게이지와 변속 표시를 추가하고 844×390 가로 화면에서 사라지던 터치 버튼과 잘리던 정차 메뉴를 수정했다.

## 도심 충돌 결함 수정

새 차량 충돌 형태로 원래 맵을 주행하자 `City_Road_Asphalt`의 경로 인덱스 571 부근에서 큰 접촉력이 발생했다. 첫 계측은 약 389만 N이었고, 선두가 걸리면서 뒤 차량도 멈췄다. AI 코너 감속·주행선 폭 조정만으로는 재현이 사라지지 않았다.

복구 삼각형 메시의 내부 경계 접촉 법선을 `TriMeshFlags.FIX_INTERNAL_EDGES`로 보정하자 같은 전체 코스 검사가 통과했다. 도로·장벽·지형 160개 충돌체를 그대로 사용하며 삼각형 제거나 평면 대체를 하지 않는다. 런타임과 검사는 같은 `worldCollision.js` 생성 함수를 사용한다. [Rapier 내부 경계 플래그](https://rapier.rs/javascript3d/enums/TriMeshFlags.html).

## 검증의 한계와 다음 단계

레이캐스트 바퀴와 강체 차체를 사용하는 레이싱 게임 물리다. 타이어 변형·차체 파손·실차 정밀 타이어 모델·제조사별 완전 재현은 포함하지 않는다. 엔진음은 합성음이며 녹음된 실차 소리가 아니다.

브라우저는 데스크톱의 크기 에뮬레이션으로 검사했다. 실제 휴대폰의 동시 손가락 터치, 포인터 취소·포커스 상실 상태의 반복 조작, 장시간 성능과 사람이 전 코스를 운전하는 체감 평가가 남아 있다. 이번 짧은 브라우저 주행에서 FPS 표시는 약 55~60이었으나 성능 인증 결과로 사용하지 않는다. Three/Rapier 청크 크기 경고도 남아 있다.

다음 우선순위는 사람이 수프라·SLK·머스탱으로 코너 진입과 충돌 후 탈출을 평가하고 실제 모바일 조작·성능을 확인하는 것이다. 기존 Unity 실행본과 Blender v2/v3/v4 원본은 보존한다.
