# Circuit Quality Round 3

## 이번 라운드 변경

- 트랙 선택 오버뷰에서 지면 끝이 보이던 회색 삼각형을 제거하기 위해 오버뷰 지면을 1,400×1,400으로 확장하고 카메라 far plane을 1,200으로 조정했다.
- Harbor Ring / Neon Eight / Alpine Sprint 각각의 코너 구간에 색상별 트랙 신호등 3개를 추가했다.
- 신호등은 레이스 중에도 링·램프·포인트 라이트가 서로 다른 위상으로 맥동해 주행 방향과 코너 리듬을 전달한다.
- 출발선 양쪽에 테마 컬러 플래그를 추가하고, 패널별 미세 회전·깊이 흔들림을 적용해 정지 화면에서도 경기장 운영감을 살렸다.
- 기존 연석·감속 표지·섹터 게이트·관중석·피트 구역과 겹치지 않도록 트랙 바깥쪽에 배치했다.

## 검증

- Harbor Ring 오버뷰에서 지면 경계가 보이지 않고 트랙 전체가 안정적으로 채워지는지 확인
- 출발 카운트다운과 섹터 HUD가 유지되는지 확인
- 레이스 진입 후 동적 신호 생성이 콘솔 오류를 만들지 않는지 확인
- 모바일 레이아웃은 기존 390×844 회귀 기준으로 재확인
