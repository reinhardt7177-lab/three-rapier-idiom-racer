# 서킷 퀄리티 라운드 63

## 관중석 생동감 패스

- 3개 관중석 구역에 저폴리 관중을 실제 좌석 위치에 맞춰 배치했다.
- 관중은 테마별 응원 색상을 사용해 하버·네온·알파인 서킷과 자연스럽게 연결된다.
- 레이스 중 미세한 상하·좌우 응원 모션을 적용했다.
- `prefers-reduced-motion` 환경에서는 모션을 22%로 낮춰 접근성과 안정성을 확보했다.
- 관중은 좌석과 같은 저폴리 스타일을 사용하고 그림자를 받아 장면 깊이를 만든다.
- 모바일 품질 모드에서는 관중 그림자 캐스팅을 끄고 실루엣·색상·모션만 유지해 프레임 안정성을 우선한다.

## 검증

- 서킷 정적 검사: 30개 마커 / 10개 지구 에셋
- 전체 `npm.cmd run check` 통과
- Vite production build 통과
