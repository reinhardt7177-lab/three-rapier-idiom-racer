# 남악 고스트 양면 렌더 비교 · 2026-10-11

## 결론

고스트의 앞·뒷면 두 번 그리기를 한 번으로 바꾸면47호출/146,010삼각형이 감소했다. 하지만 두 번째 반복에서 프레임 p95 개선이 재현되지 않았다. 단일 패스를 제품에 적용하지 않았고 성능 게이트 통과로 처리하지 않는다. 새 콘텐츠/경관 확장과 자동 작업6의 PAUSED 상태는 유지한다.

## 구현·보존

- 개발 서버에서 `qaProfile&qaFrozen&qaFrozenGhost`를 모두 켜고 레이스를 일시정지할 때만 실행한다. 360프레임씩 전체→고스트 단일 패스→전체 복원의 A/B/A다. 기본 타이어 비교 방식도 유지했다.
- 고스트의 양면 반투명 재질15개에만 `forceSinglePass`를 바꾸며, 물리·차량·고스트·카메라 자세와 시간을 고정한다. 색·투명도·깊이 쓰기·가시성·기하·그림자는 바꾸지 않는다. 완료·취소·재출발·차고·dispose에서 원래 플래그를 복구한다.
- 제품의 렌더 방식은 그대로다. 새 진단 식별 문자열은 제품 번들에서 없고 실제 제품5192 차고 DOM에서도 `frozen/profile/qaDriver`가 모두 없음을 확인했다(`product-off.json`).
- 수정 전 사본은 `artifacts/ghost-pass-20261011/before/`다. 시작 추적 변경0 및 파일 시각을 확인했다. 같은 전용 브랜치를 사용한다. Blender/GLB/도로/경로/충돌/음악 파일은 바꾸지 않았다.
