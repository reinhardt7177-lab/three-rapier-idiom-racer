# 한국 코스 목표 점검·고스트 부하 조사 · 2026-10-11

## 결론

전체 목표는 아직 완료되지 않았다. 여수·성삼재와 전남 챔피언십은 구현돼 있으나 기존 남악 성능 게이트가 해결되지 않았고, 메달 해금·라이벌 개성·다른 코스 시간대는 미구현이다. 사용자가 지정한 중단 조건에 따라 새 확장은 계속 보류한다. 이번에는 제품 변경 없이 현재 파일과 보존된 원자료를 다시 확인했다.

새로운 근거는 **양면 반투명 고스트의 두 번 그리기**다. 수프라의 실제 GLB는 양면 메시 primitive 47개/146,010삼각형이다. 런타임이 이를 전부 반투명으로 바꾸고, 설치된 Three.js 렌더러는 양면·반투명·`forceSinglePass=false`일 때 앞·뒷면을 각각 그린다. 따라서 94호출/292,020삼각형이 발생하는 구조이며, 기존 고정 장면의 `other` 95호출/292,212삼각형과 맞는다. 나머지 1호출/192삼각형은 이번 정적 분석에서 고스트로 분류하지 않았다.

이 일치는 고스트의 구조적 부하 근거다. 고스트를 줄이면 남악 p95가 해결된다는 성능 통과 근거가 아니다. 고스트 없는 과거 표본도 p95 약33.4ms였고, 동일 장면에서 고스트의 앞·뒷면 처리만 달리한 브라우저 비교와 외형 검수가 아직 없다.

## 이번에 실제로 실행한 검증

- `node artifacts/goal-audit-20261011/inspect.mjs`: 로컬의 작은 JSON/GLB 메타데이터 분석과 SHA256 대조. 명령 경과 약1.82초. 물리·GPU 모델·새 헤드리스 레이스 실행이 아니다.
- 최종 Colab 전체 검사 증거의 입력139개를 현재 파일과 다시 대조: 불일치0. 현재 제품 입력이 최종 검사 당시와 같음을 확인했다. **255개 전체 검사/203.331초는 이전 실행 기록**이며 이번에 다시 실행한 결과로 쓰지 않는다.
- 두 코스의 Blender 원본·생성 스크립트·GLB·경로 JSON의 존재·바이트·SHA256을 기록했다. GLB 여수3,480,804B, 성삼재9,539,680B로 각25MB 이하다.
- 기존 실제 Colab CPU 레이스 행렬12건을 읽어 난이도3종×1/3랩의 누락0, 기록된6대 완주72/72를 재집계했다. 성삼재 기록의 최소 차체 상향 성분은 약0.98453 이상이었다. 새 주행 검사가 아니다.
- 차량8종 모두 실제 GLB의 모든 primitive가 양면임을 확인했다. 실차/고스트의 메시·재질·충돌·경로는 수정하지 않았다.
- 세 고정 구간의 `other` CPU 직접 제출 평균은6.10/5.48/6.20ms, 호출95/삼각형292,212로 동일했다. 이 분류는 고스트 전용이 아니므로 시간을 전부 고스트 비용이라고 표현하지 않는다. 각6개의 계측 표본이다.
- 긴 간격에는 서로 다른 양상이 섞였다. 66.7ms 간격 직전 CPU work68.9ms/render68.7ms가 있었지만, 다른50.1ms 간격 직전 work19.0ms/render18.8ms도 있었다. CPU 처리만으로 모든 지연을 설명할 수 없다. callbackDelay는 호스트 대기·브라우저 스케줄링·다른 작업 등을 분리한 측정이 아니며 GPU 시간과 더하거나 프레임 시간에서 단순히 빼지 않는다.

재현 스크립트와 집계: `artifacts/goal-audit-20261011/inspect.mjs`, `inspection.json`. 입력 증거의 SHA256도 저장했다. 기존 나쁜 표본을 제외하거나 기준을 느슨하게 하지 않았다. 새 브라우저 FPS·UI·첫 다운로드·입력 검사를 실행했다고 주장하지 않는다. 문서/조사만 변경했으므로 이번 전체 npm run check는 실행하지 않았다.
