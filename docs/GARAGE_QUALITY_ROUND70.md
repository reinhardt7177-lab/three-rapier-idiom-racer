# Garage quality · Round 70

이번 패스는 차량이 실제 쇼룸에서 “게임 오브젝트”가 아니라 “전시되는 머신”처럼 보이는지에 초점을 맞췄다.

## 변경

- Kenney GLB 차체의 원본 메시·휠 노드·피벗·정규화 수치를 유지하면서, 차체 재질을 `MeshPhysicalMaterial` 기반의 불투명·양면 재질로 정규화했다.
- 브라우저별 GLB 차체 재질 문제가 발생해도 바퀴만 남지 않도록 가독성 폴백을 유지했다.
- 폴백 차체를 둥근 모서리 섀시, 노즈, 사이드 포드, 콕핏, 측면 발광 스트라이프, 리어 라이트 바로 재구성했다.
- 차종 파일에 따라 카트·해치/세단·SUV/트럭 계열의 폭·높이·휠 간격을 다르게 적용하고, 선택 차량의 액센트 컬러를 차체에 반영했다.
- 차량 교체 시 기존 폴백/FX/휠 참조를 보존하고 새 카탈로그 모델만 추가하도록 교체 경로를 분리했다.
- 트랙 주변 반복 소품은 첫 프레임에서 모두 파싱하지 않고 idle 지연 로딩으로 넘겨, 쇼룸 첫 화면 진입을 가볍게 했다.
- Vite HMR 오류가 남은 세션은 개발 서버를 재기동해 깨끗한 브라우저 탭에서 검증했다.

## 검증

- 차고 오빗 화면에서 APEX GT 차체·콕핏·스트라이프·휠·서비스 조명 확인
- `npm.cmd run build` 통과
- `node scripts/check-visual-quality.mjs` 통과: 14 runtime markers / 6 UI markers / 3 tracks / 10 curated GLBs
- 새 브라우저 탭 콘솔 경고·오류 0건

남은 선택 과제는 각 Kenney 차종의 고유 차체 텍스처를 다시 켜는 자산별 패스다. 현재는 어떤 브라우저에서도 차체가 사라지지 않는 것을 우선 보장하면서, 쇼룸 화면의 실루엣과 조명 품질을 높인 상태다.
