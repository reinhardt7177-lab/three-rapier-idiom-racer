# 차량 외장 v6 · 2026-10-09~10

## 사용자 문제와 수정 범위

우라칸 사진의 둥근 차체, 따로 붙은 램프·흡기구, 가벼워 보이는 휠을 기준으로 외장을 다시 제작했다. 이번 작업은 Blender 메시와 재질, 웹용 GLB에 한정한다. 주행 물리·바퀴 중심·회전축·조향축·배기 효과의 기준 위치를 유지한다.

| 대상 | 실제 변경 |
| --- | --- |
| Huracán | 별도 각진 차체 단면, 낮은 쐐기형 앞부분, 넓은 뒤 필러, 차체와 연결된 미러, 곡면에 밀착한 램프·Y자 LED, 실제로 파인 앞·옆 흡기구, 차체를 따르는 엔진 루버, 뒤 Y자 램프·그릴·디퓨저 |
| Porsche 911 | 분리된 구형 램프 덩어리 제거, 후드와 이어지는 펜더, 원형 램프 구멍과 네 점 조명, 짧아진 뒤 유리와 지붕, 뒤 그릴·미등 높이 보정 |
| GT-R / RX-7 / M3 / 911 | 지붕·창틀·옆 유리가 같은 곡선을 따르도록 재제작, 유리 하단과 실제 차체 사이를 잇는 페인트 패널, 차체에 연결된 미러 |

공장 CAD나 공식 제작 모델을 사용한 것은 아니다. 실차 특징을 해석한 게임용 Blender 모델이며, 정확한 실차 재현이나 상용 게임 수준의 모델 완성을 주장하지 않는다.

## 원본과 재현

- 최신 편집 원본: `assets-sources/vehicles-v6/`의 8개 `.blend`.
- 2026-10-10 사용자 요청으로 v2~v5·복구 차량 원본과 교체 전 웹 차량 사본을 삭제했다. 최신 v6의 8종 편집 원본은 유지한다.
- 현재 제작 방식: v6 `.blend`를 Blender 5.2에서 직접 편집하고 저장한다. 이전 버전을 입력으로 삼던 재제작 스크립트는 정리했다.
- 저장 원본 재수출: `scripts/blender/export_fleet_eight.py`. 기본 원본은 v6이며 `-- --only huracan`으로 한 종을 수출한다. 이전 버전 수출은 지원하지 않는다.
- 웹 메시 묶음은 독립 모듈 `scripts/blender/web_meshes.py`로 유지한다. 삭제한 이전 제작 스크립트를 불러오지 않는다.
- Blender에서 외장 변경 전후의 서스펜션·조향·바퀴 피벗 행렬을 비교한다. 값이 달라지거나 메시가 비어 있거나 좌표가 유한하지 않으면 내보내기를 중단한다.
- 흡기구와 911 램프 구멍은 폐곡면 Boolean 처리 전후의 체적 감소를 확인한다. 초기 Exact 처리에서 차체가 사라지는 실패를 보존하고, 닫힌 메시를 사용하는 Manifold 처리와 최소 체적 감소 검사를 적용했다.
- 웹에는 같은 부모·같은 재질의 메시만 묶고 Draco 압축을 적용한다. 편집 원본의 부품은 분리되어 있다.

## 검증 기록

`npm run check:rebuild`에서 **99개 통과·실패 0, 웹 빌드 성공**. 8종 원본·GLB 리그, 고속 접지·제동·바퀴 회전·충돌, 복원된 6.84km 코스의 8종 자동 운전을 이번 파일로 다시 확인했다. 제작 전후 피벗 행렬 검사도 통과했다. 웹 빌드의 8종 GLB와 `public`의 SHA-256이 모두 같았다.

실제 브라우저에서 8종 선택·전면 렌더링, 우라칸과 911·GT-R·RX-7·M3 후면, 우라칸 출발·가속·일시 정지·재시작·차고 복귀를 확인했다. 새 후면 보기에서는 벽에 가리지 않았고 RX-7 램프 패널이 차체 밖으로 돌출하던 문제가 줄었다. 375×812 세로·844×390 가로 화면에서 차량과 8종 선택 버튼·출발 버튼을 확인했다. 검수 중 수집된 브라우저 오류 로그는 없었다. 화면 크기 변경을 휴대폰 실기기 검수로 해석하지 않는다.

우라칸 재출발의 90km/h 표본에서 타이어 4개 접지, 바퀴 회전, 차체 X/Z 회전 속도 약 `5.4e-12 / 3.0e-13`, 가속 키 해제 후 입력 0을 관찰했다. 이는 짧은 주행 표본이며 모든 노면에서 반복 흔들림이 없다는 사람의 평가를 대신하지 않는다.

### 성능과 용량

최종 8종 GLB 합계는 **4,613,812바이트(약 4.61MB)**다. 상세 휠과 램프로 다운로드·삼각형 비용이 늘었다. 이번 작업을 성능 최적화로 주장하지 않는다.

인앱 브라우저, 1280×720, DPR 1.25의 첫 주행 표본은 약25FPS였다. 재출발 표본은 표시34FPS, 최근240프레임 평균26.32ms·95백분위33.5ms·최대83.4ms였다. 초기 셰이더 준비·다른 프로그램 부하가 섞일 수 있는 짧은 관찰이며 장시간 성능 보증이 아니다. **큰 화면 프레임 개선과 실제 휴대폰의 메모리·발열·지속 성능 검수가 남아 있다.**
