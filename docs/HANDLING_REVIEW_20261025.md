## 권장 수정 순서와 통과 조건

1. **속도 기준·보정 전환부터 수정:** 실제 이동 중인 차에 저속 조향각·보정 해제가 적용되지 않게 한다. 좌우·전후진·큰 슬립·보정 켬/끔을 함께 확인한다.
2. **플레이어와 라이벌 교정 범위를 분리:** 현재 보통/어려움 AI의 검증된 설정을 고정한 뒤 플레이어 후보를 평가한다. 도로 지지·충돌체는 유지한다.
3. **선회·드리프트의 운전감 평가:** 앞서 사용자가 제시한80km/h 선회15~18m/s²와 보정 켬90km/h 드리프트1.5초 뒤45km/h 이상/회전110°/초 이하를 후보 평가 기준으로 삼는다. 현재는 미달이며 계수를 바꾸지 않고 성공으로 표시하지 않는다. 조향의 초반 반응을 살리되 속도별 최대각·반대 조향 전환을 조정한다.
4. **충돌·카메라·그래픽 순서로 연결:** 정면/측면/스침의 실제 감속과 회복, 시점별 시야를 사람의 조작으로 평가한다. 강한 연출로 물리 문제를 가리지 않는다.
5. **적용 전 회귀:**8종 위 측정,4코스 쉬움/보통/어려움의 플레이어·AI 완주, 입력 해제, 새 고정 조건 프레임을 재검증한다. 완주나 안정성이 악화되면 후보를 중단한다. 본 검토의40개 시험만으로 물리 후보의 출시를 승인하지 않는다.

가장 중요한 다음 작업은 **실제 이동 속도에 맞춘 조향 상한과 드리프트 보정 전환을 플레이어 범위에서 먼저 고치는 것**이다. 이번 검토에서는 제품 코드를 변경하지 않았다.
