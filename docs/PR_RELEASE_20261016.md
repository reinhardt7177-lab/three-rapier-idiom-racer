## 어떻게 만들었나

1. **웹으로 재구성:** 남아 있던 Unity 실행 자료에서 선택된 메시·재질·해안 경로를 추출했습니다. Unity 프로젝트와 C# 전체를 복구한 것은 아닙니다. 복구 차량의 형태 결함 때문에 현재 차량은 Blender 재제작 모델로 교체했습니다.
2. **편집 가능한 원본:** `.blend`는 `assets-sources/`, 웹에서 읽는 GLB·경로는 `public/assets/rebuild/`에 나눴습니다. Blender 생성·폴리싱·수출 스크립트를 보관하고 Draco 압축을 사용합니다. `world.blend`는 Git LFS입니다.
3. **물리와 외형 분리:** 실제 차체 지지·충돌·진행 계산과 시각적인 차체 기울기를 분리했습니다. Wheel/Steering/Suspension 노드와 운전석 핸들에 해당 조작값을 연결했습니다. 큰 카메라 흔들림으로 운전감을 대신하지 않도록 했습니다.
4. **자료에 기반한 코스:** 공개 지도·위성·현장·관광/국립공원 자료를 비교하고 출처와 실제 재현의 한계를 `docs/`에 남겼습니다. 여수 OSM 평면을 실제 고도 측량으로 표현하지 않습니다. 성삼재는 레이스용 순환 코스입니다.
5. **반복 검증:** 실제 Rapier 헤드리스 레이스, 단위 시험, 입력·정지·복귀·결과 흐름, 네 가로 화면 크기를 확인했습니다. 평균 FPS 외에 p95·최대·50ms 초과를 보존하고, 나쁜 표본이나 실패 후보를 삭제해 성능 통과를 만들지 않았습니다.
6. **친구 대전:** 방장이 두 차량의 Rapier 물리·결승을 계산하고 참가자는 페달 입력을 전송합니다. PeerJS 중개와 WebRTC 데이터 채널을 사용합니다. QR은 외부 QR 서비스로 보내지 않고 로컬 생성하며 버튼을 누를 때만 청크를 불러옵니다.

## 온라인 검토에서 고친 문제

- 참가 확인·출발 준비가 끝나지 않아도 ping만으로 무한 대기하던 경로에 제한을 뒀습니다.
- 전송 혼잡 때 출발·정지 제어 메시지를 조용히 잃지 않고 실패를 경기 중단으로 처리합니다.
- `runId`로 이전 경기 제어 메시지를 거르고, 정지 중 입력·조기 출발을 거부합니다.
- 시간 초과 뒤 도착한 연결 결과는 폐기해 종료한 방이 되살아나지 않도록 했습니다.
- 프로토콜 v2와 설정 유효성을 양쪽에서 확인합니다. 중도 이탈을 정상 승리·완주로 저장하지 않습니다.
- QR 세로 창의 하단 잘림을 별도 레이어로 수정하고, 링크·코드 입력 대안을 유지했습니다.

## 이번 최종 자료 정리

- 초기 화면부터 현재 QR까지 대표 이미지 **정확히 20장 / 6,141,804B**를 `docs/blog/images`로 모았습니다. 번호·설명·원본 위치·해시가 있습니다.
- 작업 시작 이미지 736장/94,762,590B에서 이미지 파일 순감 약 **88.62MB**, 추가 임시 코드·모델 복제본/완료된 입력 묶음 **157파일/64.30MB**를 정리했습니다.
- 현재 코드·에셋·Blender 원본·필수 시험 fixture와 수치/실패 로그는 보존합니다. Git 과거 이력을 지우거나 재작성하지 않습니다.
- 새로 보관한 맵별 Gemini 음악 4곡의 원본은 아직 제품에 연결하지 않았습니다. 현재 제품 BGM은 기존 2곡입니다.
- 무무클래스는 기존 ‘앱 올리기’로 등록했습니다. 무무클래스 메뉴·플랫폼 소스·DB 구조는 바꾸지 않았습니다.
- 환경/키 파일·로컬 에이전트 설정·설치 의존성·도구 전송 응답·임시 압축물은 새 공개 대상에서 제외합니다.

## 남은 한계와 다음 우선순위

1. 실제 두 기기·다른 통신망에서 QR 초대, NAT, 지연, 연결 종료, 완주·재경기 검수가 최우선입니다.
2. 친구 초대 방식이며 공개 자동 매칭/순위 서버/호스트 이전/전용 TURN 서비스 보장은 없습니다. 호스트 신뢰 구조입니다.
3. 실차는 자체 참고 모델, 운전석은 공통 모델입니다. 제조사 제휴·정밀 스캔·AAA 완성품을 주장하지 않습니다.
4. 코스는 레이스에 맞춰 편집한 지역 기반 풍경입니다. 높은 품질의 장시간 성능과 사람의 주행 재미 평가가 남습니다.
5. 기존 개발 도구 취약점 6건은 QR 마감 문서에 기록돼 있으며 이번 정리에서 패키지 버전을 임의로 올리지 않았습니다.
6. 과거 문서·비교 HTML의 스크린샷 링크는 사용자 요청으로 삭제돼 깨질 수 있습니다. 현재 20장 갤러리와 Git 이력을 사용합니다.

main에 직접 커밋하지 않았으며 이 PR을 병합하지 않습니다. 기존 PR #7과 누적 이력에 겹치는 부분이 있어 병합 시 함께 검토해야 합니다. 이번 자료 정리에서 게임 운영 빌드·DNS를 다시 변경하지 않습니다.
