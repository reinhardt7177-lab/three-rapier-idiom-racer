# Garage quality round 26 — hero vehicle focus

이번 라운드는 차고 장식물을 무작정 늘리지 않고, 선택 차량이 화면의 주인공으로 읽히는 집중 연출에 맞췄다.

## 반영 내용

- 무대 외곽에 차량 accent 기준 24개 포커스 라이트 틱 추가
- 틱마다 서로 다른 위상으로 미세한 밝기·스케일 펄스를 적용해 정적인 링을 쇼룸 조명처럼 보이게 개선
- 차고 전용 bloom strength를 별도로 조정해 언더글로우·무대 링·천장 조명이 서로 뭉개지지 않으면서 살아나도록 조정
- 좌측 카피 영역에 accent rail과 약한 색 확산을 추가해 3D 무대와 HUD의 시선 연결 강화
- 모바일에서는 bloom과 장식 밀도를 낮춰 동일한 분위기를 유지하면서 프레임 비용을 제한

## 검증 기준

- 선택 차량 accent가 바뀌면 포커스 틱·언더글로우·차고 카피 rail이 함께 바뀌어야 한다.
- `prefers-reduced-motion` 환경에서는 CSS 연출이 정지되어야 한다.
- 빌드와 CC0/차량/진행도 검사 통과 후 데스크톱·320px 브라우저에서 오버플로와 콘솔 오류를 확인한다.
