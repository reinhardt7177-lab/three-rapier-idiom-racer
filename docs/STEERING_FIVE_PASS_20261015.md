# 핸들 각·조향 반응 5회 점검

2026-10-15 · 로컬 수정. 운영 배포·커밋·푸시는 수행하지 않았다.

## 결과

저속 최대 바퀴 각도, 중속 조향 범위, 짧은 입력·반대 방향 입력 반응, 실제 타이어 힘과 실내 핸들 표현을 조정했다. 실제 Rapier 측정에서 8종 모두 60·90km/h 회전 반경이 이전보다 **9.22~16.68% 감소**했다. 속도를 낮춰 얻은 결과가 아니라 같은 속도대의 측정이다.

## 다섯 차례 점검

| 회차 | 점검·발견 | 조정·확인 |
| --- | --- | --- |
| 1. 저속 최대 각 | 기존 중심 바퀴 각도 상한 29.79° | 플레이어 상한 32.09°. 8종 실제 앞바퀴에 적용, 안쪽 바퀴 40° 미만·뒷바퀴 조향 0·Ackermann 유지. 관련 3개 통과 |
| 2. 중속 코너 | 60·90km/h에서 속도 제한에 따른 각도 감소가 큼 | 도시 속도대 조향 범위 최대 18% 증가, 90→180km/h에서 부드럽게 기존 범위로 복귀. AI 기본 설정 유지. 관련 3개 통과 |
| 3. 짧은 입력·반대 입력 | 짧은 키 입력에서 목표 조향에 도달하기 전 손을 놓기 쉬움 | 플레이어 입력 필터의 진입 반응 16%, 반대 입력 20%, 복원 8% 강화. 30/60/120Hz·정지·초기화 확인. 관련 6개 통과 |
| 4. 실내 핸들 | 앞바퀴 한쪽 각도의 4배만 표시해 고속에서 움직임이 작고 좌우 표시량도 다름 | 실제 중심 조향을 기준으로 10배 표시, 애니메이션 상한 약 160°. 실제 상태에 연동하며 입력값만으로 회전시키지 않음. 운전석 관련 포함 12개 통과 |
| 5. 실제 회전·연속 조작 | 각도만 늘린 중간안은 Supra 60km/h 회전 반경이 9.616→9.732m로 오히려 약간 커짐 | 타이어 힘의 한계를 확인하고 해당 속도 범위에서 플레이어 타이어 용량을 최대 12% 함께 보강. 실제 힘으로 회전 반경 개선, 8종 짧은 드리프트·반대 조향·복원 통과 |

180km/h 이상 최대 바퀴 각도와 타이어 보강량은 기존 설정으로 돌아온다. 입력 반응은 빨라졌으므로 고속의 모든 순간 궤적까지 동일하다는 뜻은 아니다. AI 감도 1은 기존 필터·각도·타이어 설정을 그대로 사용한다. 차체 방향·위치를 직접 덮어쓰거나 추가 회전 토크를 넣지 않았다.

## 같은 속도에서 측정한 전후 값

Supra, 평지, 실제 레이스용 튜닝, 120Hz Rapier, 좌우 각각 측정. 표는 오른쪽 입력이며 반대쪽도 별도 측정했다. 바퀴 각도는 중심 조향 기준이고 안쪽·바깥쪽 타이어 각도는 Ackermann에 따라 다르다.

| 항목 | 이전 | 최종 |
| --- | ---: | ---: |
| 저속 최대 바퀴 각도 | 29.79° | 32.09° |
| 60km/h 최대 바퀴 각도 | 15.30° | 18.05° |
| 90km/h 최대 바퀴 각도 | 6.85° | 8.08° |
| 180km/h 최대 바퀴 각도 | 1.31° | 1.31° |
| 230km/h 최대 바퀴 각도 | 0.75° | 0.75° |
| 30km/h 회전 반경 | 4.509m | 4.145m |
| 60km/h 회전 반경 | 9.616m | 8.682m |
| 90km/h 회전 반경 | 19.618m | 17.637m |

| 100ms 뒤 조향 입력 필터 도달량 | 85.91% | 89.71% |

필터 수치는 코드에 입력을 준 이후의 응답이다. 실제 기기·브라우저의 전체 입력 지연을 측정한 값은 아니다. Supra 90km/h 회전 반경 비교의 평균 속도는 89.797→89.736km/h이다.

8종×5속도×좌우 **80개 일반 조향 측정에서 모두 4바퀴 접지**를 유지했다. 별도로 16개 지속 핸드브레이크 측정을 보존했고, 짧은 드리프트·반대 조향·복원은 8종 좌우 16개 시퀀스로 검사했다. 핸드브레이크를 길게 누른 측정을 일반 코너의 안정성 결과에 섞지 않았다.

8종 직선 가속·제동 결과는 직전 운전감 작업의 보존된 기준값과 바이트까지 동일하다. 가속력·브레이크·기어비는 변경하지 않았다.

- `artifacts/steering-five-pass-20261015/`: 수정 전 원본, 96개 전후 측정, 회차별 결과, 각도만 늘린 중간안과 실패, 최종 결과, 빌드·브라우저 증거를 보존한다.

## 실패와 범위

- 새 요구를 담은 최초 회귀 검사 5개 중 4개가 기존 구현에서 실패했다. 짧은 드리프트·복원 시퀀스는 기존에도 통과했다.
- 저속 각도 확인의 최초 시험은 JS 배정밀도와 Rapier 단정밀도를 1e-9로 비교해 실패했다. 물리 결과와 기대 각도를 `Math.fround`로 정확히 비교하도록 고쳤다. 최대 각도·접지 기준은 완화하지 않았다.
- 중간안의 타이어 포화는 실제 전후 측정과 회전 반경 회귀 시험에서 잡았다. 타이어 보강 이후 동일한 5% 이상 반경 개선 기준을 32개 조건 모두 통과했다.
- 실기기 터치·게임패드·핸들 컨트롤러, 사람이 느끼는 조향 선호도, 이번 변경의 FPS·장시간 안정성은 측정하지 않았다. 기존 기록·메달과 다른 작업의 차량·AI·맵 변경은 보존했다.
- 다음은 사용자가 새 로컬 빌드에서 60~100km/h 연속 코너와 짧은 반대 조향을 직접 평가하는 것이다.
