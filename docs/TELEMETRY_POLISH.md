# 주행 기록 폴리시 계획

## 이번 라운드에서 반영한 것

- 완주 시 `avgSpeed`, `maxSpeed`, `driftTime`, `boostTime`을 기록한다.
- 최근 기록은 `mumu-circuit-telemetry` 키로 최대 8개까지 보존한다.
- 결과 화면에는 평균 속도·최고 속도·드리프트 시간이 표시된다.
- 차고지에는 마지막 주행의 코스·차량·속도 요약이 `LAST RUN / TELEMETRY` 배지로 표시된다.
- 기록은 브라우저를 새로고침해도 복원된다.

## 다음 폴리시 순서

1. 차고지 배지에서 최근 3회 기록의 추세(평균 속도, 최고 속도, 기록 단축)를 작은 스파크라인으로 표시한다.
2. 차량별로 마지막 주행 telemetry를 분리해, 차고지에서 선택한 차량의 이전 기록을 우선 노출한다.
3. `SERVICE` 카메라에서 정비 조명과 차량별 컬러 라이트를 조금 더 보강한다.
4. 모바일 폭에서는 telemetry 배지를 접을 수 있도록 해 차량 선택 영역을 우선 보존한다.

## 검증 기준

- 완주 결과와 차고지 복귀 후 `LAST RUN / TELEMETRY` 값이 일치해야 한다.
- 차량 GLB 정규화·Rapier 물리·AI 체크포인트·무료 에셋 검사가 모두 통과해야 한다.

## 쇼룸 폴리시 로그

- 차고지에 최근 3회 주행을 보여주는 `RECENT RUNS` 스트립을 추가했다.
- `RACING DIVISION / 2026` 브랜드 표기를 정리했다.
- 전면 쇼룸 시야를 가리던 우측 조명 프롭을 서비스 영역 바깥으로 이동했다.

## 차고지 구역 배치 로그

- `PIT LANE`: Kenney 공사 배리어와 피트 바닥 라인 배치
- `GRANDSTAND // 04`: 3단 관중석과 좌석 컬러 패턴 배치
- `TYRE WALL`: `wheel-dark.glb` 2단 타이어월 배치
- `SIGN / 07`: 구역 표지와 쇼룸 라벨 배치
- 서비스 카메라 시야에 들어오던 수직 조명·사인 프롭은 제거하거나 외곽으로 이동해 차량과 UI를 가리지 않게 했다.

## 차량별 쇼룸 컬러

- 차량 카탈로그에 `accent` 컬러를 추가했다.
- 선택 차량의 전시 링·스테이지 라이트·차고지 스펙 패널·기록 카드가 같은 색을 공유한다.
- Redline 6(레드), Volt X(시안), Apex GT(레드)로 실제 교체 렌더를 확인했다.

## 선택 차량 telemetry·모바일 검증

- 선택 차량에 기록이 있으면 해당 차량의 `LAST RUN / SELECTED CAR`만 보여준다.
- 선택 차량 기록이 없으면 실제 최근 기록 차량을 `LAST RUN / ALL CARS`로 명확히 표시한다.
- 390×844 모바일에서 차고지·코스 선택·레이스 HUD를 확인했고, 패널 잘림 없이 스크롤 가능한 차량 도크로 정리했다.
