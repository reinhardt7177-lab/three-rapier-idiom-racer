# 돌아오는 불빛 — 첫 해안 운행

2026-09-06 · 로컬 구현. 기존 프롤로그·자유 주행·GT 시험은 보존한다.

테스트 주소: `http://127.0.0.1:5175/`. 작업 중 5173 포트가 다른 프로젝트에 사용되어 서버를 분리했다. 검증 스크립트는 `GARAGE_BASE_URL` 환경 변수로 주소를 받는다.

## 실행과 플레이

차고의 **돌아오는 불빛 시작 →**를 선택한다.

1. 출발 안내: 서진이 바람곶의 옛 신호소 확인을 부탁한다. 출발 버튼을 누르기 전에는 차량 입력을 잠근다.
2. 항만대로 → 해안 굽잇길 → 갈림길 오른쪽으로 주행한다. 긴 대사는 메뉴에, 즉시 필요한 안내만 화면 상단에 둔다.
3. 전망대 회차장 안에서 2km/h 미만·3륜 이상 접지로 연속 2초 정차한다. 방향별 경유 지점을 실제로 통과해야 한다.
4. 정차한 뒤에만 카메라가 차량과 신호소를 함께 비춘다. 유나가 마지막 차의 귀환을 기다리던 불빛의 이야기를 전한다.
5. **신호를 기록하고 항구로 →**를 누르면 회차 후 귀환한다. 시간제한·속도 점수는 없다.
6. 귀환 방향 경유 지점을 거쳐 항구 BAY 01 부근에서 2초 정차한다. 왕복 거리·주행 시간을 확인하고 차고로 돌아가 첫 운행 기록을 남긴다.

목표 길이는 3–5분이다. 정상 저장 경로의 브라우저 키 입력 시험에서 주행 시간 약 196초를 확인했다. 읽는 시간·운전 습관·성능에 따라 실제 플레이 시간은 달라진다.

## 레퍼런스 반영 범위

- 사용자 제공 차고/AFTERLIGHT 이미지의 석재 블록, 짙은 철골, 동관, 크림색 모서리, 작업대·계기함·배수 디테일을 자체 Three.js 코드로 재해석했다.
- 신호소 한 곳에 디테일을 집중했다. 외부 모델·영상·텍스처·폰트는 추가하지 않았다.
- 차분한 해안 팔레트와 차량 디자인은 유지한다. 장면 확인용 정차 구도만 추가하며 주행 카메라를 강제로 빼앗지 않는다.
- 신호소는 기존 난간 바깥의 비주행 배경이다. 사람 하차·문 열기·건물 내부 탐색은 제공하지 않는다.

## 검증 명령과 증거

- `npm run check`: 전체 시험과 빌드. 이번 추가는 이야기 상태/저장/배치 7개이며 총 47개.
- `node scripts/verify-coast.cjs`: 변경 전 기준 왕복 약 196초, 오류/실패 요청 0건.
- `node scripts/verify-journey.cjs`: 새 운행의 실제 키 입력 왕복, 정차 연출, 일시정지·세로 화면, 완료 저장·차고 복귀·새로고침·재시작.
- `JOURNEY_BLOCK_STORAGE=1` 환경 변수로 같은 브라우저 시험을 실행하면 저장 차단 경로를 별도로 검사한다.
- 결과 파일: `artifacts/signal-journey/verification.json`, `artifacts/signal-journey-storage-blocked/verification.json`. 파일의 시각과 실제 실행 범위를 기준으로 판단한다.
- 기존 조향·항구·프롤로그·태블릿 검증은 각 `scripts/verify-*.cjs`와 해당 결과 파일에 기록한다.

## 남은 제한

- 갤럭시 탭 실기기 FPS·발열·손 피로는 미검증이다. 이번 브라우저 시험은 Chrome 소프트웨어 GPU 환경이다.
- Three.js/Rapier 청크 크기 경고가 남는다. 빌드 성공을 빠른 초기 로딩 보장으로 해석하지 않는다.
- 차고와 도로의 출입은 UI 장면 전환이다. 셔터를 운전해 통과하는 연속 월드는 아니다.
- 완료 사실만 로컬 저장한다. 중간 위치 저장, 운행별 상세 일지 목록, 음성 더빙, 교통 AI, 라이벌 레이스는 없다.
- 신호소 외 전체 해안의 디테일 밀도는 차고 수준에 미치지 않는다. 자동 완주가 재미·완성 미술의 증명도 아니다.
- 커밋·푸시·PR 갱신·운영 배포는 이번 작업에 포함하지 않는다.
