# 서킷 품질 라운드 2

이번 라운드는 출발 화면뿐 아니라 실제 코너를 도는 동안에도 코스의 성격이 계속 읽히도록 만드는 데 초점을 맞췄다.

## 적용 내용

- 노면 중앙 라인과 코너 고무 자국을 추가해 주행 경로가 평평한 갈색 면처럼 보이지 않도록 보강했다.
- 25/50/75% 위치에 섹터 핀, 코너 바깥쪽에 발광 chevron을 배치했다.
- `SECTOR 02 / SPLIT` 얇은 아치를 추가했다. 카메라를 가리지 않으면서 랩 중간의 기준점을 제공한다.
- 하버 링: 컨테이너 야적장, 도크 수면, 크레인, `HARBOR SERVICE / 04` 서비스 랜드마크.
- 네온 에이트: 핑크/시안 발광 게이트, 도심 타워, `NIGHT GRID / SECTOR 08` 야간 랜드마크.
- 알파인 스프린트: 눈 둔덕, 암석, 설산 콘, `CLOUD PASS / 03` 랜드마크.
- 알파인 전용 노출값과 눈 색을 낮춰 흰색 오브젝트가 화면을 날리지 않도록 조정했다.

## 검증

| 코스 | 확인 내용 | 결과 |
| --- | --- | --- |
| 하버 링 | 출발 게이트, 컨테이너/서비스 구역, 크루즈 주행 | 통과 |
| 네온 에이트 | 발광 게이트, 야간 타워, 크루즈 주행 | 통과 |
| 알파인 스프린트 | 눈 둔덕·암석·설산, 출발 시 노출, 390×844 | 통과 |

모바일 확인 결과 상단 랩 HUD, 중앙 차량, 하단 `LINE / BRAKE / NITRO / THROTTLE` 조작부가 세로 화면 안에 유지된다.
