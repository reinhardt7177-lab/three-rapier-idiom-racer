# Open-source foundation

- [Rapier](https://rapier.rs/) (Apache-2.0): 동적 강체, 충돌체, CCD, 레이캐스트 차량 컨트롤러.
- [Three.js](https://threejs.org/) (MIT): 3D 렌더링과 GLTF 로딩.
- [pmndrs/racing-game](https://github.com/pmndrs/racing-game) (MIT): 차량 튜닝과 추적 카메라 구조 참고.
- [HexGL](https://github.com/BKcore/HexGL) (MIT): 속도 기반 카메라와 부스트 표현 참고.
- PolyTrack: 모듈 트랙 개념만 참고했으며 소스와 에셋은 복사하지 않음.
- Kenney Car Kit, City Kit Roads, Toy Car Kit (CC0): 차량·도로·레이싱 소품. 원본 라이선스는 각 에셋 폴더의 `LICENSE.txt`에 보존.

게임 코드는 이 저장소에서 새로 작성했으며 레퍼런스 게임의 소스 파일을 복사하지 않았습니다.
