# Race HUD quality round 73

실제 타임어택 게임처럼 플레이어가 다음 코너와 현재 위치를 빠르게 읽을 수 있도록 레이스 HUD를 보강했다.

## 적용 내용

- 런타임에서 섹터 진행률과 별도로 전체 랩 기준 `trackPercent`를 전달한다.
- `TrackMap` SVG가 선택한 트랙의 실제 포인트를 정규화해 그린다.
- 시작점, 현재 차량 위치, 테마 컬러 글로우를 분리해 표시한다.
- AI 3대의 진행률도 붉은 점으로 표시해 라이벌 간격을 즉시 읽을 수 있다.
- 모바일에서는 미니맵을 숨겨 조작 버튼과 속도 HUD의 공간을 보존한다.

## 검증

- `npm.cmd run check` 통과
- 3개 트랙 ID와 10개 Retro Urban GLB 자산 검증 통과
- Vite 프로덕션 빌드 통과
- 로컬 `http://localhost:5173/` 및 런타임 모듈 HTTP 200 확인
