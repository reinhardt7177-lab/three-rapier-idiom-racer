# 실제 여수 도로 코스·빠른 라이벌·일반 교통 차량

## 요청과 현재 문제

2026-10-12 사용자는 실제 여수 지도에 기반한 코스, 더 빠른 AI 5명, 추월을 방해하는 일반 차량, 추가 그래픽 개선을 요청했다. 기존 여수는 임의의 10개 제어점을 연결한 3.54km 트랙이며 실제 도로 좌표를 쓰지 않는다. 현재 보통 AI 최고속도 설정은 225km/h지만 이것이 실제 평균 주행 속도를 보장하지 않는다.

## 구현 계획과 통과 기준

1. **실제 도로 자료:** 공개 OpenStreetMap 도로 노드·way ID를 보존하고 위경도를 미터 좌표로 투영한다. 돌산대교 → 돌산 연결 도로 → 거북선대교 → 원도심 수변 → 이순신광장으로 이어지는 실제 연결을 우선한다. 보행 전용 해양공원·오동도 방파제를 일반 자동차 도로로 표현하지 않는다. 원본 지도와 게임 경로를 같은 평면에 비교해 좌표 변형 범위를 기록한다.
2. **Blender 코스:** 기존 여수 생성기를 실제 지도 경로를 읽는 구조로 바꾼다. 급한 교차로를 레이스용으로 완화하고 폭·교량 고도를 조정한 부분을 수치로 공개한다. 단일 Road_Asphalt, 닫힌 RaceBarrier, Terrain, 지명 표식 규칙을 유지한다. .blend 원본·GLB 25MB 이하·새 충돌 fixture·JSON을 보존한다. 모든 경로 표본 ±7m 지지, 상향 법선, 건물 여유 공간, 폐쇄 루프를 검사한다.
3. **라이벌:** 실제 페달/조향 입력과 목표 속도 제한 원인을 측정한다. 코너 진입 감속·조준·추월 속도 병목을 고치고, 쉬움 < 보통 < 어려움 완주 중간값 및 기존 코스 완주를 확인한다. 거리 보정·순간이동·플레이어에 대한 러버밴딩은 사용하지 않는다.
4. **일반 교통:** 여수에 느린 일반 차량을 배치하고 동일한 Rapier 세계에서 주행·충돌한다. 레이스 순위와 분리하며 라이벌의 회피 계획에 포함한다. 출발 그리드와 교차로 정차를 피하고 종료·재시작·차고 복귀에서 자원을 해제한다. 보통/낮음 품질의 차량 수를 제한한다.
5. **야경:** 실제 교량 위치·항만/장군도 윤곽·수변 조명과 바다 반사를 보강한다. 도로·차선·코너 시야를 우선하며 새 실시간 반사 패스와 무제한 조명을 추가하지 않는다.
6. **검증:** 관련 단위 시험 → 실제 Rapier 레이스 → 전체 npm run check·빌드 → 브라우저 차고/출발/주행/결과/복귀 및 입력 해제 → 네 크기(1280×720,1024×768,844×390,667×375) UI → 같은 조건 프레임 평균/p95/최대/>50ms와 초기 용량. Colab 연결이 끊긴 뒤 사용자가 “연결없이 하셈”이라고 답해 이후 계산을 이 PC에서 실행했다. 실제 휴대폰 검증이라고 주장하지 않는다.

- 구버전 여수 최고 기록/고스트를 새 경로 기록으로 혼용하지 않는다. 기존 진행도와 사용자의 기록은 삭제하지 않는다.

### 실제 지도와 제작물

- 실제 OSM 원본 `assets-sources/yeosu/map/yeosu-osm-20261012.osm`: 9,671,967bytes. 다운로드 주소·시각·SHA256은 `source.json`에 보존했다.
- 차량 통행 가능한 실제 도로45개·중복 없는 노드363개를 연결했다. 돌산대교 way64707298, 거북선대교 북행 way165039247을 포함하며 일방통행을 유지한다(`eventDirectionOverride:false`). 보행 전용 해양공원과 오동도 방파제는 자동차 경로로 쓰지 않는다.
- 원본 연결8,992.94m → 게임 경로8,902.29m, 길이 차이 약1.01%. 커브 완화의 평면 최대 이탈5.24m. 진두 수변을 반드시 경유하는 초안은 같은 노드를 반복하지 않는 합법 연결을 찾지 못해 제외했다.
- 레이스용 폭18~22m, 제작 교량 높이18m, 최대 경사12.675%. 실제 측량 고도/도로 폭이 아니다. 건물은 실제 윤곽을 참고한 간략 외장이며 건물 높이·다리 구조·조명 패턴은 근사한다. 실제 해안 지형의 완전한 육지 면은 미완성이다.
- `scripts/blender/build_yeosu.py` → `.blend`1,476,808bytes / GLB9,632,808bytes / 경로 JSON882,097bytes / 경로4,452지점 / 충돌142개. 25MB GLB 예산 통과.
- 재생성 경로: `fetch-yeosu-map.py` → `build-yeosu-map-route.py` → `blender/yeosu_map_geometry.py` + `blender/build_yeosu.py`. 원본과 파생 지도 데이터는 ODbL 1.0이며 차고에 출처 링크를 표시했다.
- [원본 지도와 게임 경로 비교](../artifacts/yeosu-map-traffic-20261012/source-route-comparison.png). 교차해 보이는 다층 도로는 순서와 제작 고도를 별도로 유지한다.

### 구현한 기능

- 보통/어려움 라이벌의 속도 프로필·접지 설정·니트로 입력을 조정했다. 순간이동·거리 보정은 추가하지 않았다. 같은 옛 여수 코스에 대한 최종 A/B 속도 비교와 모든 기존 코스 회귀는 미완료이므로 “AI 개선 완료”라고 판단하지 않는다.
- 일반 차량은 품질 높음6대/보통4대/낮음2대. 실제 Rapier 차체·바퀴·페달·차량 충돌과 스파크 피드백을 공유하고 순위에서는 제외한다. 바퀴 회전/조향과 헤드·테일램프를 표시하며 최대30개 추가 그리기 호출로 제한했다.
- 고도3m 이상 다른 층의 차량은 전방 막힘 판정에서 제외한다. 추월 접근 간격12m와 실제 아스팔트/차량 점유 검사를 연결했지만 긴 따라가기와 일부 정체 문제는 미해결이다.
- 청남색 하늘·짙은 푸른 바다·따뜻한 건물 창·실제 교량 위치의 조명과 간단한 반사를 적용했다. 새 실시간 반사 패스는0, 야간 그림자 맵0, 지역 조명6개다. 사진 같은 야경 완성/전체 구간 시야 검증으로 표현하지 않는다.
- 새 지도 기록/고스트는 `osm-20261012` 키로 분리했다. 예전 기록과 획득 메달은 삭제하지 않는다. **새 코스 메달 기준은 아직 옛79/81/89초라 잘못된 상태이며 출시 차단 항목이다.**

### 실패와 수정 근거

1. 지도 최초 두 정적 시험에서 촘촘한 교차로 노드의 커브 안쪽이 접혀 지점 간격/아스팔트 지지가 실패했다. 원본을 보존하고0.7m 이내 직선 단순화·거리 기준 커브 완화·3D 재표본화를 적용했다. 기존1.9~2.01m 간격과 ±7m 지지 기준은 바꾸지 않고 최종 통과했다.
2. `smoke-1`: 교통 없이3/6 완주, Porsche약2,482m/GT-R약6,995m에서 멈춤. 새 조향 공식이 실제 Rapier 고속 회전 응답에 맞지 않아 폐기하고 기존 검증된 방향 제어로 복원했다. 진단 전체 상태는 `jam-diagnostic-1.json`에 보존했다.
3. `smoke-2`: 교통 없이6/6 통과, 교통6대에서5/6. Mustang이 결승4m 전에서 막혔다. 헤드리스가 완주 AI를 결승에 바로 주차시키던 차이를 고쳐 제품과 같은50m 실제 주행 후 정차를 연결했다. 완주 시간/진행 기준은 바꾸지 않았다.
4. `smoke-3`: 교통6대에서3/6. 앞차를6m까지 따라붙지만 추월은9m 이상에서만 허용해 재시도를 막는 조건을 발견했다. 접근 간격12m를 유지하도록 수정했다.
5. `smoke-4`: 교통6대에서4/6. 장시간 느린 차량을 따라간 탓에420초 검사 안에서6대 완주를 확인하지 못했다. 마지막 두 차량은 주행 중이지만 실제 완주가 없으므로 통과 처리하지 않았다. 제한 시간을 늘려 성공으로 바꾸는 실험도 하지 않았다. 사용자 중단 규칙을 적용했다.
