# 남악 지명·간판·길찾기 표식 · 2026-10-10

## 결과와 배치

Blender로 방향 안내판8개, 도로·구간 명판7개, 장소 입구 표식7개를 제작했다. 총22개 표식에는 한국어 지명, 작은 영문 보조 표기와 방향 안내가 들어간다. 방향판의 노란 번호01~04는 게임의 도청·상가·수변·공원 구간을 구분한다.

- 도청 구간: 전라남도청·전라남도의회·남악저수지 표식, 후광대로·오룡길 명판.
- 상가 구간: 남악 상가거리 입구 표식, 남악로·남악3로 명판과 수변공원 안내.
- 수변 구간: 남악 수변공원 표식, 영산강 수변길 안내와 공원 방향판.
- 공원 구간: 남악중앙공원·김대중광장/대죽도 표식, 대죽서로 명판과 도청 결승 구간 안내.

표지판 좌표는 **현재 게임의 축약된 순환 트랙과 랜드마크**에 맞춰 배치했다. 실제 도로명과 장소명을 참고했으나 현실의 교차로·표지판 좌표·방향·거리를 실측 복제하지 않았다. `영산강 수변길`, `중앙공원 순환로`, `도청대로`는 게임 구간명이며 공식 도로명으로 주장하지 않는다. 상가거리 역시 일반 구간 표식이다. 기존 가상 상점명을 실재 업체로 바꿔 달지 않았다.

## 편집과 로딩

- `scripts/blender/build_namak_landmarks.py`: 지명/배치 정의와 표식 제작·수출.
- `assets-sources/namak/namak-landmarks.blend`: 개별 안내판의 편집 가능한 Blender 원본.
- `public/assets/rebuild/namak-landmarks.glb`: 실제 표지판·지지대·한글/영문 벡터 글자 메시,766,412바이트(약0.73MiB).
- `public/assets/rebuild/namak-landmarks.json`:22개 이름·게임 좌표·방향·크기 기록.
- `src/rebuild/namakLandmarks.js`: 남악에만 로드한 표식의220m 거리 표시와 반사 글자 마감.

기존 `namak.glb`(19,885,452바이트), 도로·충돌·주행 경로·차량 파일을 재수출하지 않았다. 새 표식을 남악 월드의 자식으로 연결해 오류 경로와 정상 종료에서 함께 해제한다. 지지대·입구 표식·도로명판은 도로 밖에 있다. 큰 방향판은 인도 지지대에서 도로 위로 뻗고 판 아래4.3m 이상의 공간을 확보한다. 물리 충돌체를 추가하지 않는다. 가까운 표식만 표시하고 글자의 그림자 계산은 끈다. 색감 보정과 도로 질감은 이전 변경을 유지한다.

## 검증·발견

- 실제 GLB의 각 표식 제목이 바깥 면을 향하는지, 판 안에 들어오는지, 실제 글자 삼각형을 향한 시선이 판에 가려지지 않는지 검사한다.
- 도로 경로 전체를4점 간격으로 순회하며4개 주행 위치 위4m 공간에 표식 메시가 없는지 검사한다. 숨은 충돌체가 없음을 확인한다.
- 표식 단위 배치가 메시 병합 후에도 남고, 거리/차고 전환으로 사라지고, 공유 재질이 한 번씩 해제되는지 검사한다.
- 처음 가시성 검사에서는 글자 바운딩박스의 가운데를 겨냥해 글자 사이 빈 공간을 표식 반전으로 오판했다. 실제 첫 글자 삼각형의 내부를 겨냥하고, 삼각형 법선 방향과 가장 앞의 교차 결과까지 확인하도록 수정했다. 기준을 약화하지 않았으며 `checks-first.log`를 보존했다.

최종 표식3·남악 폴리싱5·공간 병합6·자원해제5, **관련19개 검사 통과**. 최종 웹 빌드 성공. 기존 큰 JavaScript 번들 경고는 유지된다. 브라우저 검수 결과는 아래에 추가한다.

자료와 화면·로그는 `artifacts/namak-landmarks-20261010/`에 있다. 이전 색감 적용 출발 화면을 `before-grid.png`로 복사해 비교 자료로 보존했다. 별도 공개 배포를 수행하지 않았다.

- 첫 브라우저 접근에서 오른쪽 인도의 방향판이 시야 가장자리로 빠지는 문제를 발견했다. 방향판8개를 도로 위로 뻗는 구조로 바꾸고 지지대는 인도에 유지했다. 원래 배치의GLB·JSON과 주행 화면도 before/ 및 초기 캡처에 보관했다. 커브 진입부의 중앙공원·수변 산책로 화살표를 게임의 진행 방향과 실제 게임 내 접근 지점에 맞춰 수정했다.

### 실제 브라우저 확인

Windows Codex 내장 브라우저, 게임 영역802×451px·픽셀 비율1.25에서 확인했다. 최종 출발·가속 때 안내판22개 중 가까운2개가 표시되었고, 약85km/h 접근 시 전라남도청/남악 상가거리 방향판이 도로 위에서 읽히는 화면을 기록했다. 바퀴 접지4개·가속 입력 해제·메뉴·재시작·운전석 전환·차고 복귀와 남악→해안→남악 선택을 확인했다. 해안에서는 남악 표식 상태가 없고, 남악 차고에서는 표식이 숨겨진다.

첫 레이스 시작·첫 운전석 전환에서 브라우저 명령의3초 응답 대기 한도를 넘긴 경우가 있었다. 최신 화면을 확인한 뒤 정상 시작/재개·복귀했고, 자동화 사이 차가 굴러 안내판을 지나친 초기 화면도 보존했다. 기존 첫 진입·운전석 전환 지연이 해결된 것으로 간주하지 않는다. 다음 검수 우선순위는 초기 렌더링 지연과 휴대폰/전 코스의 표식 가독성이다. 이번 작업에서 실제 휴대폰이나 사람이 전체 코스를 운전한 것으로 주장하지 않는다.

최종 화면은 `civic-cantilever.png`, 운전석은 `civic-cockpit.png`, 동작과 오류 계측은 `browser-flow.json`에 기록한다. 최종 오류 수는 해당 파일의 `errors`를 기준으로 한다.

최종 남악 복귀 후 브라우저 오류0개, 차고에서 표식22개 모두 숨김을 확인했다. 원본/빌드의 도시·표식GLB 해시 일치는 `asset-validation.json`에 기록했다.
