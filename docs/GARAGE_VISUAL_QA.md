# 차고지 그래픽 QA 기록

## 이번 라운드에서 조정한 것

- 차량 영웅 샷 카메라를 전면·오빗·서비스 모두 더 가까운 거리로 재구성했다.
- 정비 베이에 도어 패널, 프레임, 수평 조명선을 추가해 기존 단색 박스 느낌을 줄였다.
- 차고지 중앙 플랫폼에 키 라이트·필 라이트·차량 뒤 림 라이트를 분리해 차량 실루엣을 살렸다.
- Retro Urban 프롭은 외곽 장식으로 제한했다. 서비스 카메라를 가리던 수목·덤프스터·서비스 트럭은 제거했고, 어닝과 벤치만 유지했다.
- 차고지의 건물 모듈은 별도 도시 지구에서 조립할 수 있도록 원본을 `assets-sources/retro-urban/`에 보관한다.

1. 차량별 전용 백라이트 색상과 바닥 반사 강도를 조금씩 차등화한다.
2. Retro Urban 벽 모듈은 차고지가 아닌 별도 `CITY DISTRICT` 맵에서 조립한다.
3. 차량 선택 카드에 작은 실루엣 아이콘을 추가해 차종 식별성을 높인다.
4. 프로덕션 빌드에서 Rapier 청크를 추가 분할해 초기 로딩을 줄인다.
