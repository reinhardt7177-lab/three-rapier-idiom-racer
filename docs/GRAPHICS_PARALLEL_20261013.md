# 맵별 그래픽 개선과 최적화 · 2026-10-13

## 범위와 기준

사용자의 맵별 병렬 작업 요청에 따라 남악·여수·성삼재를 별도 작업자가 맡고, 주 작업자가 해안·공통 렌더링·통합 검증을 담당한다. 같은 작업 브랜치를 사용하며 파일 소유권을 분리한다. 최종 전체 검사가 실행 중일 때는 제품 소스를 고정하고 조사·후보만 별도 artifacts에 준비한다.

- 남악: 밝은 중성 보도, 상가 마감·기단·창 경계, 근거리 가로수. 기존 과도한 채도 누적을 더 증폭하지 않는다.
- 여수: 기존 제작물의 다리/수변 발광 위치와 연결한 길게 분절된 물빛, 작은 광원 코어. 청남색 하늘과 기존 도로 시야를 보존한다.
- 성삼재: 숲바닥·하층 식생·화강암 질감, 근·중거리 식생 군집. 경사·헤어핀·능선 지형을 변경하지 않는다.
- 해안: 수면의 작은 물결과 하늘 반사, 암석·항구 바닥·회벽 질감. 이 코스는 가상의 해안 월드이며 실제 한국 지형의 복제로 설명하지 않는다.

도로/충돌/경로/조향/접지/기록/온라인 프로토콜을 그래픽 변경에 포함하지 않는다. 실제 사진은 위치·재질·색 관계를 읽는 참고 자료이며 제품 텍스처로 무단 복제하지 않는다. 별도 Blender/GLB 재제작을 하지 않는 이번 재질·장식 패스는 기존 편집 원본과 그 해시를 보존한다.

## 최적화와 검증 계획

추가 실시간 그림자/반사 렌더 패스 대신 공유 재질·텍스처, 셀별 인스턴싱, 거리 및 품질 예산을 사용한다. 정적인 월드 변환 반복 계산을 제거할 후보도 비교한다. 낮음 품질은 추가 장식을 제한하며, 주행 도로와 충돌면은 거리로 숨기지 않는다. 각 모듈은 원래 재질/가시성을 복원하고 자신의 자원만 해제할 수 있어야 한다.

관련 단위 시험, 실제 WebGL 셰이더 컴파일·전후 캡처, 같은 세션/해상도/DPR/코스/카메라에서 프레임 평균·p95·최대·50ms 초과와 CPU 제출·드로/삼각형을 비교한다. 격리된 자동 검수용 headless Edge에서 WebGL2/Intel Iris Xe D3D11이 실행됨을 먼저 확인했다. 사용자 인앱 브라우저 연결과 다른 검수 환경이며, 모바일 실기기 검증·사용자 화면 검수로 표현하지 않는다. 화면 검수를 뒤로 미룬 사용자 결정은 유지한다.

최종 `npm run check`를 통과하고 원본/물리 입력 해시를 확인한 결과만 완료로 보고한다. 현재 공개 Pages는 이전 배포이며 새 그래픽이 이미 공개됐다고 주장하지 않는다.

## 선행 회귀 문제

교통 추월 후보의 최종 전체 검사에서 여수 비 쉬움3랩이 1260초 안에 3대만 완주했고, 어려움3랩은 앞선 쉬움의 미완주 때문에 난이도 중간값 검사가 함께 실패했다. 추락/노면 이탈은 없었다. 일반 교통을 위한 새 추월 재판단이 교통0 레이스에도 적용된 범위를 조사한다. 실패 표본과 전체 실행을 보존하고 해당 후보를 격리한 뒤 그래픽 통합을 진행한다. 검사 시간이나 난이도/메달 수치를 바꿔 통과시키지 않는다.
