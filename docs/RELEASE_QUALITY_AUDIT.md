# 출시 품질 재점검 — 2026-09-08

상태: 로컬 수정. GitHub 커밋/푸시·Vercel 배포 없음. ‘AAA급 완성’ 판정이 아니라, 현재 브라우저 프로토타입의 실패 경로를 재현하고 줄이는 작업이다.

## 판단

밝은 해안·정비소의 자체 제작 미술과 차량 물리는 유지할 가치가 있다. 반면 현재 레이싱은 단독 기록 도전 중심이며 상대와의 추격/추월/역전, 차량 선택의 차이, 긴 플레이의 동기는 아직 부족하다. 예외 상황 복구·저장·터치 UI가 불안정하면 콘텐츠를 늘려도 완성도가 쌓이지 않는다.

이번에는 파일 전체 삭제나 물리 수치·최고 속도 변경 없이 **실패 후 복귀, 진행 차단 방어, 저장 신뢰성, GPU 자원 수명, 차고 가시성**을 먼저 수정했다. 차량/입력, 렌더링/자원, 캠페인/저장을 세 개의 독립 코드 검토로 나누고 통합 검증했다. 실제 자동차 디자이너나 실물 삼성 기기를 통한 인증은 아니다.

### 과장하지 않아야 할 부분

- 피니시 고착은 **상태 전이 fixture**에서 재현했다. 실제 Rapier 진입각/횡위치/속도 63개 조합에서는 고착이 없었다. 정상 평탄면 240km/h 자동 제동은 약 5.43초였으며, 이 조건에서 8초 제한은 정상 제동에 여유를 둔다.
- 예외 종료는 잘못된 차량 자세를 순간이동/회전 보정해 정상처럼 보이게 만들지 않는다. 물리를 정지시키고 실패 이유와 재도전 선택을 표시한다.
- 자원 해제 이벤트·단위시험 통과는 실제 GPU 메모리 누수가 전부 사라졌다는 증거가 아니다. 10분 이상 실기기 계측은 남아 있다.
- 프레임 루프 중복은 코드 경로와 예약 관리자 단위시험으로 방어했다. 실제 탭 전환 초기화 타이밍을 모든 기기에서 재현한 것은 아니다.

브라우저는 한 번에 한 검사씩 실행했고 전체 순차 명령이 종료 코드 0으로 완료했다. 최종 안전 종료·저장 차단 연결·프레임 예약은 수정 담당과 별도의 읽기 전용 재검토에서도 새 명백한 P1 회귀를 발견하지 못했다. 이것은 무결점 증명이 아니다.

## 다음 품질 관문

1. **현재 차 한 대와 실제 기록 고스트**: 구간 차이·추격·역전의 의미를 만든다. 기록의 시간축/코스·물리 버전/일시정지·재시도 일치를 확인한 후 2장을 연다.
2. **사람의 재미 검사**: 처음 보는 플레이어가 목적을 이해하고, 제동 지점을 학습하며, 두 번째 도전을 스스로 선택하는지 관찰한다. 자동 운전 33초 완주는 난이도/재미 판정이 아니다.
3. **삼성 기기 10~15분 검사**: 모델/OS/브라우저/화면/그래픽 모드 기록, 두 엄지 입력, 스피커, 중앙 시야, 프레임 시간·발열·복귀 안정성 확인.
4. **기술 부채**: 큰 주행 번들(압축 전 약 2.92MB), 부분 초기화 예외의 자원 회수, 운영 청크 로딩·WebGL context loss 복구는 후속 과제다. 지금 ‘모든 실패 복구’나 ‘60 FPS 보장’으로 표현하지 않는다.
5. **미술**: 한 구간의 근경/중경 밀도와 랜드마크, 차량 실루엣·도장/유리/고무 구분을 실제 주행 카메라로 검수한다. 맵 크기·차량 수·경찰을 동시에 늘리지 않는다.

실제 캡처의 시각 판단: 밝은 차체/짙은 창문/후미등과 아스팔트의 대비, 중앙 주행 시야는 읽힌다. 반면 공도에 상대 차량이 없고 먼 경관의 변화가 적어 긴장감은 제한적이다. 휴대폰 가로 차고는 화면 밖 조작을 해결했지만, 전체 차고 보기에서 차량 비중이 작은 구도는 추가 개선 여지가 있다. 이 판단을 프레임 성능이나 사용자 재미의 계측값으로 표현하지 않는다.

챕터의 상세 목표는 [HORIZON CLUB 계획](HORIZON_CLUB_PLAN.md)을 유지한다. 이번 수정은 게임의 전체 미술을 NFS와 동일하게 바꾸거나 AAA 규모로 완성한 작업이 아니다.
