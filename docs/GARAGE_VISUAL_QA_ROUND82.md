# Garage visual QA round 82

실제 로컬 브라우저에서 데스크톱과 390px 모바일 화면을 확인했다.

- 차고지: 차량 컬렉션, 선택 패널, 프로필·텔레메트리, 쇼룸 카메라 버튼, 피트 서비스 공간이 화면 안에서 계층적으로 보인다.
- 차량 도장: 폴백 차량의 색상·금속 반사를 낮춰 빨강·파랑 등 차종별 악센트가 흰색으로 날아가지 않도록 조정했다.
- 트랙 선택: 실제 트랙 미니맵, 3개 회로 카드, 진입 버튼이 데스크톱·모바일 모두 표시된다.
- 레이스: 스타트 그리드, 연석, 안전 펜스, 트랙 맵, HUD, 모바일 컨트롤이 표시된다.
- 콘솔: 브라우저 `error`/`warn` 로그 없음.

자동 검증: `npm run check` 통과.
