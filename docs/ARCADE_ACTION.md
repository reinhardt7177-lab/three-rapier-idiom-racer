# 액션 주행 1단계 — 드리프트 접지 전환과 니트로

## 범위

밝은 해변 스타일을 유지하면서 운전 액션을 개선하는 첫 시안이다. **차고 → 해안도로 드라이브**에서 적용된다. 기존 테스트·스토리·스프린트·1장은 기존 물리를 사용하므로 최고 기록과 고스트의 비교 조건을 바꾸지 않는다. 라이벌 1대·경쟁 이벤트·결승 연출은 이번 단계에 포함하지 않았다.

## 조작과 설계

- SPACE/핸드브레이크: 3개 이상 바퀴 접지·전진 28.8km/h 이상에서 뒷바퀴 마찰을 점진적으로 낮춘다. 놓으면 약 0.38초 시간상수로 접지력을 회복한다. 차체 방향을 강제로 돌리거나 좌표를 이동시키지 않는다.
- SHIFT/터치 NITRO: 일반 가속도 함께 수행한다. 18km/h 이상·접지 3개 이상에서 추가 구동력이 네 바퀴로 전달된다. 터치에서는 니트로와 조향을 두 손가락으로 사용 가능하다.
- 제동·후진 입력·핸드브레이크·과도한 옆미끄러짐·접지 부족 시 니트로 차단. 100%에서 총 4초 사용, 방출 중 충전하지 않으며 빈 상태로 누르고 있어도 간헐 가속이 발생하지 않는다.
- 버튼을 놓고 전진 주행하면 초당 6% 충전. 실제 0.1~0.65rad 옆미끄러짐과 접지가 확인되면 18% 충전. 버튼만 누르거나 정차해 점수를 얻는 방식이 아니다. 별도 점수·화폐는 없다.
- 일반 최고속 설정 240km/h, 부스트 중 구동력 감소 기준 280km/h. 화면 속도는 실제 수평 속도이며 목표 수치에 강제로 맞추지 않는다. 4초 안에 280km/h 달성을 보장하지 않는다.
- 메뉴·포커스 상실·화면 회전·터치 취소는 기존 공통 입력 해제를 사용한다. 자유 주행 복귀/재시작은 연습용으로 잔량을 초기화한다. 경쟁 모드로 이전하기 전에 리셋/충전 규칙을 별도로 설계해야 한다.
- 엔진 부하·가속 카메라·타이어 피드백은 기존 실제 물리 계측을 따라간다. 니트로 전용 사운드/배기 VFX를 추가했다고 주장하지 않는다.

## 검증

- 자동 시험은 기존 99개에 액션 6개를 더한 105개다. 추가 시험은 소모/빈 트리거, 안전 차단, 부드러운 마찰 복원, 실제 슬립 충전 조건, Rapier 실제 이동 증가와 코너 회복을 검사한다.
- 같은 입력에서 일반 물리는 부스트 입력 유무와 무관하게 완전히 같은 스냅샷을 만든다. 액션 물리는 부스트 사용 후 속도와 이동 거리가 실제로 증가하는지 검사한다.
- 실제 코너 시험: 3.5초 가속 후 최대 조향/핸드브레이크 0.75초에서 최대 슬립 0.447rad, 해제 후 2초 가속 시 슬립 0.000002rad 미만·접지 4개. 이는 특정 입력의 측정이며 모든 속도/코너의 회복을 보장하지 않는다. 최대 조향/핸드브레이크를 2초 유지한 반례에서는 큰 슬립(1.53rad)이 발생했다. 스핀 방지 보조는 후속 튜닝 대상이다.
- `scripts/verify-arcade.cjs` 통과: 실제 SHIFT 가속/잔량 소모, 메뉴 입력 해제, 네이티브 터치 니트로/취소, 스프린트에 액션 UI가 없는 것을 확인했다. 오류 0건. `artifacts/arcade-action/verification.json`.
- `scripts/verify-tablet-hud.cjs` 재검증 통과: 6개 화면 크기, 중앙 도로 보호 영역, 버튼 겹침/크기, 두 손가락 조작, 메뉴/회전/점검/설정 유지. 오류·요청 실패 0건. 초기 검사는 캔버스 리사이즈가 늦게 반영되어 안전 메뉴가 열린 상태를 읽었다. 실제 리사이즈 완료 후 재개하도록 수정했고 기준은 완화하지 않았다. `artifacts/arcade-action-recheck/tablet-hud/verification.json`, `640x400.jpg` 시각 확인.

## 비판적 판단과 다음 단계

이것만으로 NFS급 재미나 완성도를 달성한 것은 아니다. 실제 사람이 S커브 진입→핸드브레이크 해제→카운터 조향→탈출 니트로를 반복하며 스핀 빈도, 제동 거리, 엄지 이동 부담을 평가해야 한다. 자동 시험은 손맛을 판정하지 못한다. 삼성 실기기의 GPU·발열·10분 주행과 기존 대형 번들 로딩 위험은 남아 있다.

다음은 이 튜닝을 조정한 뒤 **라이벌 1대가 있는 짧은 액션 이벤트**를 별도 기록 규격으로 만드는 것이다. 기존 스프린트 기록을 몰래 새로운 물리와 섞지 않는다. 기존 최고 기록/고스트/라이선스는 삭제하지 않는다.
