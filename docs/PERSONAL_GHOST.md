# 내 기록 고스트 — 2026-09-08

## 목적과 범위

혼자 달리는 기록전에 비교 대상을 추가한다. 실제 유효 완주의 위치·차체 회전·바퀴 움직임을 녹화해 다음 도전에서 재생한다. AI 상대를 만든 것이 아니며 2장 스토리·보상은 아직 미구현이다. 기존 해변 미술, 차량 물리, 캠페인 보상 및 숫자 최고 기록은 변경하지 않는다.

## 이용 방법

1. 차고 → **해안 스프린트**, 또는 **챕터 선택 → 1장**으로 출발한다.
2. 3분 이내에 복귀 기능 없이 세 게이트를 순서대로 통과하고 유효 완주한다.
3. **바로 재도전**하면 녹화한 최고 기록이 청록색 반투명 차로 재생된다.
4. 게이트 통과 때 내 기록 고스트 대비 앞섬/뒤처짐을 표시한다. 메뉴에서 고스트를 숨길 수 있다.

첫 녹화 전에는 고스트가 없다. 이전 숫자 기록만으로 경로를 복원하지 않는다. 따라서 기존 개인 최고와 **녹화된 최고**가 다를 수 있다. 같은 브라우저의 저장된 녹화가 있으면 다음 접속에도 불러온다. 동기화·온라인 랭킹은 없다.

## 정확성과 방어 설계

- 물리 시뮬레이션 시간으로 약 20Hz 샘플을 수집한다. 마지막 부분 스텝은 실제 결승 통과 시점까지 보간한다.
- 재생은 누적 프레임 이동이 아닌 절대 경과 시간 검색, 위치/바퀴 선형 보간, 쿼터니언 구면 보간이다. 일시정지 시 같은 시계가 멈춘다.
- 한 도전 중 비교 기록은 고정한다. 새 기록은 다음 재도전부터 적용한다.
- 플레이어와 겹치면 흐려지고, 충돌체·물리 차체·그림자·소리·타이어 자국은 만들지 않는다. 원본 차량 지오메트리를 공유하되 고스트 재질만 별도로 사용한다.
- 도로 복귀로 무효화한 주행·미완주·180초 초과는 녹화 기록으로 채택하지 않는다. 가장 빠른 유효 녹화만 저장한다.
- `mumu.coast.ghost.v1`: 최대 3,602행, 직렬화 길이 1,200,000 제한. 유한 수, 좌표 범위, 시간 순서, 샘플 간격, 회전 정규성, 순간이동을 검사한다.
- 읽기/쓰기 실패와 알 수 없는 미래 버전은 덮어쓰지 않는다. 쓰기 후 재확인하며 실패하면 현재 주행 화면의 재도전에만 메모리 기록을 유지한다고 안내한다. 차고 이동/새로고침까지 보존된다고 보장하지 않는다.
- 차량·조향·코스 튜닝 변경 시 `GHOST_PHYSICS`를 반드시 올린다. 호환되지 않는 녹화와 경쟁하지 않으며 기존 데이터는 삭제하지 않는다.

## 남은 위험과 다음 단계

- Headless Chrome/소프트웨어 GPU 검증은 실제 삼성 기기의 성능·발열·손 조작 검증이 아니다.
- 고스트는 차량 렌더링 비용을 추가한다. 실기기에서 경량/표준 모드 비교가 필요하다. 빌드는 기존 대형 청크 경고가 남는다.
- 숨김 선택은 해당 주행 화면에 한정한다. 앞섬/뒤처짐은 게이트별 비교이며 실시간 거리 환산이 아니다.
- 다음은 실제 사람의 재도전 평가 후 2장의 목표·도입·보상을 연결하는 것이다. 맵과 AI를 동시에 확장하지 않는다.
