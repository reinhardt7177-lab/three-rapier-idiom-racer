# 다른 맵 최적화·연속 커브 안내 재개

사용자 결정(2026-11-04): 보류했던 다른 맵 최적화와 게임성 개선을 재개한다. 이전 여수 성능 악화 후보 전체를 복원하지 않고, 원인이 다른 변경을 하나씩 검증한다. 안정 물리·AI·메달·경로·충돌·모델은 유지한다. 이번 범위는 로컬 구현과 검증이며 새 커밋/푸시/PR/main/배포는 하지 않는다.

## 설계와 완료 기준

- 성삼재: 정적인 산 능선 경계 구를 생성 시 계산해 프레임마다 재생성하지 않는다. 장식 선택·가시성은 동일해야 한다.
- 남악: 0.2초 장식 갱신의 임시 구·정렬 배열·후보 포장 객체를 재사용한다. 거리·동률 정렬·품질별 예산·처분 결과를 유지한다.
- 공통(해안·여수 포함): 무한 거리인 높은 품질에서는 의미 없는 거리 계산을 생략하되, 유한 거리와 비정상 카메라 입력의 기존 가시성 규칙을 보존한다.
- 게임성: 실제 경로의 다음 독립 커브를 짧게 예고한다. 같은 커브의 연속 샘플을 다음 커브로 잘못 안내하지 않으며 마지막 결승·다중 랩·좌우 의미를 보존한다. 속도에 맞춘 예고 거리와 급커브 경고를 추가하되 물리에 관여하지 않는다.
- 각 변경은 관련 실패 시험→최소 구현→관련 시험으로 진행한다. 고정 IAB 1280×720/동일 DPR·품질·카메라·QA 주행에서 30초 A/B/A를 측정한다. 원시 평균/p95/최대/>50ms/CPU/진행 거리를 남기고 실패 표본도 보존한다. 기준 구간이 달라지거나 기준본 편차가 크면 효과 확정으로 보고하지 않는다.
- 새 기능이 기존 해안/남악 p95를 2ms 넘게 악화시키면 원복하거나 품질 설정 뒤로 숨긴다. 같은 문제 4번째 실패·완주/안정성 악화·범위 결정 필요 시 해당 확장을 중단한다.
