# 8종 차량 · 안정적인 차체 · 그래픽 검수

작업일: 2026-10-09. Three.js + Rapier 로컬 웹 제작본. 현재 실행 주소: <http://127.0.0.1:5191/>.

## 사용자 문제와 변경

이전의 회전 감쇠만으로는 차체 꿀렁임을 충분히 없애지 못했다. 이번에는 접지 중 네 개의 독립 스프링이 차체를 반복해서 흔드는 구조를 바꿨다.

- `activeRide.js`: 바퀴 접촉점과 법선으로 실제 도로 경사를 얻는다. 세 바퀴 이상 지지될 때 차체 앞뒤·좌우 회전을 제한하고 경사에 맞춘다. 높이는 하나의 임계 감쇠 지지로 제어한다.
- 렌더링용 차만 따로 고정하지 않는다. 실제 Rapier 차체와 그 충돌체가 동일한 자세를 사용한다. 바퀴별 주행 거리, 조향, 서스펜션 이동과 타이어 접촉은 계속 Rapier 컨트롤러에서 계산한다.
- 수평 충돌 속도와 조향 회전은 보존한다. 지지가 사라지거나 도로 상승 속도보다 훨씬 빠르게 위로 튀면 제한을 해제한다. 경사로 고속 상승을 점프로 오인하지 않는다.
- 차체가 접지 중 크게 기울어지는 충돌 표현은 억제되는 **안정성 우선 아케이드 방식**이다. 제조사 차량의 정확한 동역학 모사를 뜻하지 않는다.

평지 가속 시험에서는 8종 모두 차체 높이 변화가 0.1mm 미만이고 앞뒤·좌우 회전이 0.000001 이하였다. 이전처럼 가속 때 차체가 숙여져야 한다는 시험은 사용자의 ‘꿀렁임 제거’ 요구에 맞춰 흔들리지 않아야 한다는 기준으로 바꿨다. 바퀴 회전 거리, 가속 시간, 제동 거리와 충돌 검증은 유지했다.

## 총 8종

| 차량 | 외형 특징 | 배기 연결 |
| --- | --- | --- |
| GR Supra | 기존 곡면 쿠페·덕테일·새틴 도장 | 2개 |
| SLK Roadster | 기존 오픈탑·좌석·롤오버 후프 | 2개 |
| Mustang GT | 기존 긴 보닛·3줄 후미등 | 2개 |
| Porsche 911 | 둥근 헤드램프·펜더·뒤로 흐르는 지붕 | 2개 |
| Nissan GT-R | 넓은 차체·4개 원형 후미등·리어 윙 | 4개 |
| Mazda RX-7 | 팝업 램프·낮은 쿠페·리어 윙 | 2개 |
| BMW M3 | 4문 차체·분리된 전면 그릴·후면 도어 | 4개 |
| Lamborghini Huracán | 낮은 캐노피·각진 램프·측면 흡기 | 2개 |

실차 특징을 참고해 Blender에서 직접 제작한 게임용 해석이다. 제조사 CAD나 정식 실차 자산으로 표현하지 않는다. 기존 세 차는 하부 보완 모델을 보존하면서 도장 마감을 다듬었고, 다섯 차를 새 메시로 추가했다.

8종 모두 `Chassis_Rig → Suspension_* → Steering_* → Wheel_*` 기계식 리그를 갖는다. 브레이크 캘리퍼는 조향과 서스펜션을 따르고, 디스크와 휠은 함께 회전한다. 새 차의 휠 개구부는 좌우 바깥 패널만 잘라 중앙 바닥을 관통하지 않게 했다. 램프와 윙 지지대의 차체 연결도 브라우저 렌더링으로 보정했다.

원본은 `assets-sources/vehicles-v5/`의 8개 `.blend`, 게임 파일은 `public/assets/rebuild/`의 8개 `.glb`다. 이전 v4와 하부 보완 원본은 보존한다. Draco 압축된 차량 8종의 합은 약 3.3MB이며 월드·물리 엔진은 별도다.

## 그래픽과 UI

- 차고에는 실내 반사를, 주행에는 별도 대기 하늘 반사를 사용한다. 첫 야외 조명 시안이 지나치게 밝은 것을 실제 화면에서 발견해 반사 강도와 노출을 낮췄다.
- 도장 거칠기와 코팅을 조정해 과한 반사 번짐을 줄였다. 새 차량의 둥근 가공 부품에는 면 법선을 정리했다.
- 8종 차량 선택을 두 줄로 배치했다. 선택 후 플레이어와 다른 차종 5대가 라이벌로 출발한다. 레이스 규모는 계속 플레이어 1대 + AI 5대다.
- 속도·타이머·도로 정보를 읽기 쉬운 배경으로 보완했다. RX-7/Huracán의 다른 RPM 상한도 계기판에 반영한다.
- 375×812 세로 화면과 844×390 가로 화면에서 차고 버튼·차량 시야와 주행 버튼을 점검했다. 화면 크기 에뮬레이션이며 실제 휴대폰 검증은 아니다.

## 재현 방법

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python scripts/blender/build_fleet_eight.py
npm run check:rebuild
```

부분 제작은 `-- --only porsche911,huracan`을 사용한다. 저장된 원본만 다시 내보내려면 `scripts/blender/export_fleet_eight.py`를 실행한다. Blender 5.2에서 이전 가져오기 자산의 시스템 extras가 사용자 속성을 덮는 문제가 있어 현재 리그 속성과 동기화한다. 원본 리비전 5와 GLB 리비전 4가 달라 생긴 첫 시험 실패도 보존했다.

## 검증과 한계

- 관련 자동시험 97개 및 웹 빌드 통과: 8종 자산·리그·회전 거리·가속·제동·고속 평지 안정성, 고속 경사/뱅크, 공중 운동, 차량 간 충돌·230km/h 벽 충돌 후 재출발, 복귀·입력·VFX·리소스 회귀.
- 복원한 160개 충돌 메시 위에서 6대 경주와 추가 M3/Huracán을 자동 운전해 **8종 모두 전체 6.84km 코스 완주**를 확인했다. 자동 운전 결과이며 사람이 8종으로 전 코스를 운전한 검수와 구분한다.
- 실제 브라우저에서 8종 각각의 선택과 렌더링, 출발, 가속, 제동, 복귀, 메뉴와 작은 화면을 확인했다. 최종 75km/h 도로 계측에서 4륜 접지·차체 앞뒤/좌우 회전 속도 약 0을 확인했고, 복귀 후 0km/h·4륜 접지·입력 해제 상태를 확인했다. 터치 가속을 놓으면 입력이 해제됐고 브라우저 오류 로그는 없었다. 제작 중 실패 로그, 모델 제작 보고, 화면 증거는 `artifacts/fleet-eight-20261009/`에 있다.
- 맵의 기존 저해상도 장식은 남아 있다. 이번 작업은 조명·차량·HUD 폴리싱이며 모든 건물/식생의 재제작은 아니다. 실제 모바일 성능·장시간 사람 운전·모든 충돌 조합은 아직 검증하지 않았다.
- 로컬 제작본만 갱신했다. 기존 GitHub Pages Unity v53 배포는 이 제작본으로 바꾸지 않았다.
