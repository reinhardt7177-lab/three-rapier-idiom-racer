# 남악 시티 건축 고도화 1차 · 2026-10-13

현재 남악 2.93km 코스의 사진 기반 건축 디테일을 보강했다. 기존 색·판석·가로수 셰이더 패스 다음 단계이며, 위성 및 실제 사진을 확인해 청사·주거·상가·수변을 구분했다. 도시 전체의 측량 복제나 실사 수준 완성을 뜻하지 않는다.

## 조사 근거

실제 확인한 출처 5개와 브라우저 캡처 9개는 [조사 기록](../artifacts/namak-highdetail-20261013/references/RESULT.md)에 있다. 사진·위성 화면은 조사 자료이며 제품 텍스처로 사용하지 않았다.

- [VWorld 위성지도](https://map.vworld.kr/map/dtkmap.do?mode=MAPW201): 도청 북쪽 산림·남쪽 광장·서쪽 주차장·동쪽 호수와 도시 남단 영산강의 관계.
- [공식 청사 사진](https://www.jeonnam-gwangju.go.kr/contentsView.do?pageId=jngj93), [KBC 도청 사진](https://news.ikbc.co.kr/article/view/kbc202306080011): 타워의 빈 흰 크라운, 직선형 저층 청사, 별도 곡면 의회동. 초기 곡면을 긴 청사 전체에 붙이는 해석은 사진 확인 후 수정했다.
- [관광공사 남악수변공원](https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=79831759-c3fd-407e-b0ef-440ecce2c4de): 열린 정자·목재 데크·갈대 군집과 아파트 원경.
- 공식 중앙공원 사진: 넓은 판석·잔디·관목·소나무의 공간 구분. 촬영 계절을 게임 전체에 강제로 적용하지 않았다.

## 구현

- 도청 타워 커튼월의 세로/가로 프레임, 빈 상부 크라운, 저층청사 창틀, 분리된 의회동 곡면 유리와 기둥.
- 광장 반사 수면·돌 테두리·낮은 화단·퍼골라와 저수지 둘레 목재 산책길.
- 기존 아파트의 측벽 계단실 창·색 띠·수직 베이·옥상 코어를 추가해 큰 빈 측벽과 반복 실루엣을 완화.
- 상가별 문틀·출입 손잡이·차양·간판 바탕·옥상 설비를 분할.
- 수변 낮은 호안·계단·전망데크 퍼골라.

물리 도로·충돌체·경로·차량 튜닝은 변경하지 않았다. 도로 밖 건축 디테일은 시각 레이어다. 기존 본체를 바꾸는 건물 전체 재모델링은 이후 단계다.

## 파일·예산

| 파일 | 역할 |
|---|---|
| `assets-sources/namak/namak.blend` | 보존한 원본 |
| `assets-sources/namak/namak-highdetail.blend` | 원본과 새 건축 컬렉션이 함께 있는 편집본 |
| `public/assets/rebuild/namak-architecture.glb` | 새 컬렉션만 내보낸 게임용 레이어 |
| `scripts/blender/polish_namak_architecture.py` | 현재 저장 원본을 읽어 별도 편집본/GLB 생성 |
| `src/rebuild/namakArchitecture.js` | 품질·거리별 가시성과 자원 소유 |
| `scripts/namak-architecture.test.mjs` | 실제 내보낸 기하·접근 공간·원본 보존 검사 |

GLB **1,338,284바이트**, **29개 메시 / 24,386개 삼각형**. 구역·재질별로 묶었고 얇은 유리는 앞뒤 패널로 만들어 숨은 면을 줄였다. 추가 실시간 광원과 사진 텍스처는 없다. 기존 남악 GLB의 20MB 제한은 그대로 유지한다. 새 레이어는 별도 파일로 추가 다운로드된다.

높음 340m·보통 200m 범위의 새 디테일을 표시하며 낮음은 새 레이어를 숨긴다. 새 디테일은 그림자를 직접 추가 렌더하지 않는다. 이 정책은 비용 상한을 위한 구현이며 실제 FPS 개선을 뜻하지 않는다.

생성기를 실행하면 **별도 편집본과 새 레이어**가 재생성된다. 그 편집본을 수작업으로 고치면 다른 이름으로 저장해 재생성 덮어쓰기를 피한다.

## 검증·발견·한계

- 기존 남악 관련 24개 시험 통과: 실제 6대 물리 완주, 정차 차량을 지나가는 라이벌, 원본 도로 접지, 차량 공간, 셰이더/자원 회귀 포함.
- 최종 `npm run check:namak-art`로 신규/기존 총 31개 시험과 웹 빌드를 함께 재실행해 통과했다. 전체 391개 회귀 재실행과 실제 WebGL 성능 검수는 포함하지 않았다.
- 신규 7개 시험 통과: 29개 메시의 예산·충돌 속성 부재·면 방향, 전체 1,464개 경로점의 8개 차선 차량 공간, 품질 거리·세계 숨김·배칭·자원 해제, 원본 SHA 5개 보존 확인.
- 신규 내보낸 모델 검사에서 저수지 데크 링의 면 방향 반전을 발견했다. 위·아래·내외벽 면 방향을 고치고 같은 검사로 재검증해 통과했다. 초기 실패 로그는 보존했다.
- Blender Workbench 전후 렌더는 건축 형태 검수이며 실제 웹 게임 화면/성능 측정으로 표현하지 않는다.
- 브라우저 자동 검수는 Windows의 현재 주소를 확실히 식별하지 못하는 정책 차단으로 중단됐다. 다른 방식의 UI 자동화로 우회하지 않았다. 실제 게임 내 최종 셰이더·전 구간 수동 운전·프레임 비용은 추가 검수가 필요하다.
- Colab 상태 확인·연결 요청은 했지만 브라우저 연결이 없었다. 원격 CPU/GPU 계산을 수행했다고 보고하지 않는다. 이번 짧은 관련 시험과 자산 검사는 로컬에서 수행했다. 전체 391개 회귀의 과거 결과는 이번 변경의 재시험 결과가 아니다.
- 작업 중 다른 맵의 roadscape/runtime/tracks/package 변경이 함께 발생했다. 그 변경은 보존하며 이번 남악 결과와 구분한다.

다음은 아파트 단지 전체 매스와 배치, 갈대 군집, 오룡산의 타원체 능선, 실제 게임에서 보이는 거리 전환을 다듬는 단계다. 새 배포·커밋·푸시는 하지 않았다.
