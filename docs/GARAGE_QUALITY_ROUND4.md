# Garage Quality Round 4

이번 라운드는 차고지가 실제 게임의 시작 화면처럼 느껴지는지를 기준으로 점검했다.

## 반영한 항목

- 차량 GLB 로딩이 늦어도 2.2초 이후에는 절차 생성 쇼룸 바디로 진입할 수 있도록 로딩 게이트를 완화했다. GLB가 준비되면 같은 그룹 안에서 정규화된 차량으로 교체된다.
- 쇼룸 카메라 FRONT / ORBIT / SERVICE 전환을 유지하고, 차량을 가리는 원형 링은 숨겨 시선이 차량에 먼저 머물도록 했다.
- 정비 신호등, 피트 카트, SERVICE GRID, Retro Urban 벽면과 관중석을 함께 배치해 차고지의 깊이와 작업 구역을 강화했다.
- 차량 주변에 색상별 피트 크루 3명을 배치하고 헬멧·반사 조끼·렌치를 분리해, 대기 중에도 미세한 바운스와 공구 움직임이 보이도록 했다.
- 모바일 폭에서는 차량 선택 카드와 쇼룸 카메라 컨트롤의 높이를 줄여 차량 실루엣이 가려지지 않도록 조정했다.

## 검증 기준

- 데스크톱 차고지에서 APEX GT와 VOLT X를 교체했을 때 차체와 바퀴가 함께 보이는지 확인
- 모바일 390×844에서 프로필·차량 스펙·쇼룸 컨트롤·차량 목록이 겹치지 않는지 확인
- 차고지 → 서킷 선택 → 레이스 진입 시 HUD와 출발 게이트가 유지되는지 확인
- 새로고침 후 브라우저 콘솔 오류가 없는지 확인

## 남은 최적화 후보

Rapier WASM 청크는 현재 프로덕션 빌드에서 가장 큰 파일이다. 다음 라운드에서 레이스 진입 시점 동적 로딩과 캐시 전략을 별도로 점검한다.
