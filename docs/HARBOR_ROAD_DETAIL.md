# 항구 도로 디테일 — 차고 품질 기준의 첫 적용

작성일: 2026-09-05  
상태: 로컬 구현 / 출발부 400m 품질 시안 / 전체 서킷 미완성

## 이번 요청의 기준

사용자가 좋아한 차고의 벽돌 깊이, 철골·배관, 바닥 줄눈·배수구, 서로 다른 재질과 사용 흔적을 도로의 최소 미술 기준으로 삼는다. 협곡 테마로 변경하지 않는다. 기존 레이싱 체감·연출 계획도 유지한다.

속도 때문에 보이지 않는 작은 장식을 무한히 추가하지 않는다. 가까운 보도·연석·벽은 형태와 재질을 만들고, 중거리 창고는 문/창/철골의 반복 구조, 먼 바다는 수평선과 크레인 실루엣으로 구분한다.

## 실제 반영

- 범위: 주행 좌표 z=-790~-390, 출발점 z=-720. 이후 고속 계측 구간은 기존 단순 시험장으로 남는다.
- 방파제: 네 줄 높이의 개별 석재, 엇갈린 줄눈, 상단 덮개돌, 철제 보강 기둥. 양쪽 경계는 실제 Rapier 충돌체와 공유 명세 사용.
- 노면 경계: 1m 단위 보도 타일, 연석, 금속 배수 그레이팅·볼트, 제한된 균열 데칼. 연석과 보도에도 충돌체 추가.
- 창고 7동: 청록 셔터, 어두운 철골, 구리색 배관과 체결부, 분할 창문, 지붕 리브, BAY 표지, 외부 작업등, 팔레트·드럼.
- 항구: 주행로 옆 바다 노출, 방파제 바깥 계류 장치/펜더, 원경 소규모 크레인과 부두.
- 조명: 차고와 가까운 녹회색 주변광·따뜻한 주광으로 조정. 가로등은 발광 재질이며 추가 그림자 광원을 무한히 만들지 않음.
- 반복 석재/타일/금속은 인스턴싱, 정적 창고 부품은 재질별 병합. 새로운 외부 모델·텍스처 다운로드 없음.
- 기존 GT·가감속/조향 계수·232km/h 성능·카메라·음소거 기본 정책·차고는 보존.

## 검사 결과

- `npm run check`: 총 15개 테스트와 빌드 통과.
- 추가 시험: 양쪽 항구 벽 충돌 정지, 중앙 주행로 230km/h 이상 유지.
- 실제 Chrome: 항구 렌더, 220km/h 이상, 390px 모바일 가로 넘침 없음, 차고 복귀 후 아이보리 색상 유지, 콘솔/네트워크 오류 없음.
- 별도 헤드리스 Chrome의 8.006초 표본: 게임 시간 8.000초, 평균 약 60FPS, 프레임 간격 p95 약 16.9ms, 100ms 초과 프레임 0개, 해당 측정 시 드로콜 193.
- 위 수치는 사용자의 인앱 브라우저 계측이나 모든 기기의 60FPS 보장이 아니다. 미술 품질 일치 여부도 사용자의 실제 주행 검수로 확정한다.
- 브라우저 스킬 절차에 따라 정지/고속/모바일 캡처를 검수했다. agent-browser 미설치 환경이므로 기존 Playwright+Chrome을 사용했다.

검증: `scripts/verify-harbor-road.cjs`, `scripts/verify-driving.cjs`.  
증거: `artifacts/harbor-road/harbor-start.png`, `harbor-fast.jpg`, `harbor-mobile.jpg`, `verification.json`.

대규모 전체 맵/AI/레이스 규칙은 아직 구현하지 않았다. GitHub push나 Vercel 배포도 하지 않았다.

## 모델 운용 안내

추천은 작업 단위별로 적용하며 모델을 바꿨다고 결과 품질이 자동으로 보장되는 것은 아니다.

| 작업 | 추천 |
|---|---|
| 미술 방향 + 3D 구조 + 물리/성능의 복합 판단, 최종 시각 검수 | Astra / High 또는 Extra High |
| 규격이 정해진 모듈 구현과 리팩터링 | Sol / Medium |
| 범위가 좁은 데이터·UI·테스트 수정 | Terra / Medium |

공식 안내는 복잡한 종단 작업에 Astra, 깊이와 판단이 필요한 작업에 Sol, 일상 구현에 Terra를 구분한다. 입력창 아래 모델 선택기에서 모델/추론 강도를 선택할 수 있으며 실제 표시 옵션은 계정/배포 상태에 따라 다르다. [공식 모델 안내](https://learn.chatgpt.com/docs/models)

이 작업에서는 모델을 변경하지 않았다. 에이전트가 현재 실행 중인 자신의 모델을 직접 교체하는 도구는 없으며, 사용자가 같은 작업의 선택기에서 변경하는 방식이다. 난이도별 전환 시점과 인계 기록은 안내할 수 있다. 별도 작업/하위 에이전트를 임의로 만들거나 사용량을 자동 분산하는 설정은 이번 범위에 없다.
