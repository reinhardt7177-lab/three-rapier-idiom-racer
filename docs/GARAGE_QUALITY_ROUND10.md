# Garage Quality Round 10

## 이번 라운드 결과

- 화면 상태와 Three.js 런타임 메뉴 모드가 따로 놀던 문제를 수정했다.
- `garage → tracks → garage`와 실제 `race → result → garage` 흐름에서 `setMenuMode(screen)`가 실행되도록 화면 상태 동기화 효과를 추가했다.
- 복귀 시 레이스 카메라가 트랙 월드에 남지 않고 쇼룸 카메라·스테이지 링·선택 차량으로 돌아온다.
- 완주 결과에서 갱신된 골드, 승리 수, 선택 차량, 마지막 주행 배지가 차고지에 이어지는 것을 확인했다.

## 검증 기준

1. `RETURN TO GARAGE` 후 3D 카메라는 차고지 쇼룸 위치를 사용한다.
2. 선택 차량과 마지막 주행 기록이 유지된다.
3. 복귀 후 콘솔 오류·경고가 없다.
4. 크루즈 완주 결과 화면은 P1, 기록, 보상, 평균/최고 속도, 재경기·복귀 버튼을 모두 표시한다.

## 다음 라운드

- 결과 화면의 배경 카메라를 결승선 근접 컷으로 바꿔 보상 화면의 감정을 강화한다.
- 차고지 복귀 시 마지막 주행 기록을 1회 강조하는 짧은 UI 모션을 추가한다.
- 장거리 크루즈에서도 트랙 장식 지연 로딩이 프레임을 막지 않는지 성능을 측정한다.
