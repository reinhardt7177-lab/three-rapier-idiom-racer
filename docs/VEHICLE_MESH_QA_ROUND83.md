# Vehicle mesh QA round 83

차량 GLB를 브라우저와 직접 파싱해 씬 구조를 확인했다.

- `race.glb`, `police.glb`, `kart-oobi.glb` 모두 씬이 표시 상태이며 메시 5~6개와 바퀴 4개를 가진다.
- 런타임에서 GLB 루트와 하위 메시를 명시적으로 `visible=true`로 복구해 exporter별 가시성 플래그에 안전하게 대응한다.
- 폴백 차체는 GLB 로딩 실패·재질 문제 때 화면이 비지 않도록 유지하고, 색상·조명 예산을 낮춰 차종별 악센트를 보존한다.
- 서비스 카메라의 리프트 데크와 조명도 함께 확인했다.

검증: 브라우저 캡처·콘솔 점검·`npm run check` 통과.
