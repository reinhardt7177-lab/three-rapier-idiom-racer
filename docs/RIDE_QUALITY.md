# 주행 중 차체·카메라 흔들림 보정 · 2026-10-09

사용자가 주행 중 차가 덜컹거린다고 보고했다. 표면 울퉁불퉁함이 아니라 주행 움직임 문제라고 확인했다. 현재 Blender v4 차량과 Three.js / Rapier 웹 제작본을 수정했으며 차량 메시·맵·충돌체를 변경하지 않았다.

## 조사와 수정

수프라의 평지 32초 가속 계측에서는 네 바퀴 접지를 유지했고 차체 높이 변화는 속도 구간별 약2~5mm였다. 실제 항구 도로에서는 경사·코너에 따른 높이와 회전 변화가 더 컸다. 따라서 도로 관통이나 반복 접지 상실이 이번 조건의 주원인이라는 증거는 없었다.

기존 카메라는 차체의 수직 이동을 그대로 따라갔다. 작은 노면 충격도 화면 전체의 움직임으로 전달되는 경로를 확인했다. 수평 이동은 그대로 즉시 따라가고 높이만 0.14초 응답으로 안정화한다. 경사·낙하에서는 높이 차이를 최대22cm로 제한하며 도로 복귀 때 즉시 새 위치로 맞춘다. 실제 차체·바퀴의 물리 위치는 필터링하거나 고정하지 않는다.

수프라·SLK는 서스펜션 압축 감쇠를4.4→7, 복원 감쇠를5.2→8로 보강했다. 머스탱에 같은 설정을 적용하면 강한 회전 충격에서 접지를 잃는 구간이18→20물리 스텝으로 늘어 기존 설정을 유지했다. 테스트 기준을 완화해 이 변경을 통과시키지 않았다. 그림자 광원도 화면에 보이는 차체와 같은 보간 위치를 사용한다.

감쇠가 스프링의 움직임을 제어하고 바퀴 접촉 상태를 읽어 표현하는 방식은 [Rapier 차량 제어기 공식 문서](https://rapier.rs/docs/user_guides/javascript/vehicle_controller/)를 참고했다. 실제 적용값은 게임의 차종별 계측으로 결정했다.

## 검증

- `npm run check:rebuild`: **38개 시험·웹 빌드 통과**. 검사 파일을 순차 실행해 여러 물리 시험이 동시에 메모리를 사용하는 부담을 줄였다.
- 기존 여섯 차의 실제 6.84km 전체 코스, 차량 간 충돌·230km/h 벽 충돌·후진 탈출·제동·바퀴 회전·입력 해제 검사를 다시 통과했다.
- 작은 회전 충격에서 수프라의 최대 각도 변화는0.01115→0.00812rad(약27% 감소), SLK는0.01031→0.00739rad(약28% 감소)였다. 네 바퀴 접지를 유지했다.
- 큰 충격에서도 수정한 수프라·SLK의 접지 상실 기간은 증가하지 않았고 최종 네 바퀴 접지를 회복했다. 머스탱은 기존 감쇠를 그대로 유지하는 검사로 보호했다.
- 세 차량의 24초 평지 가속에서는 네 바퀴 접지를 유지하고218km/h 이상 도달했다. 높이 변화 범위는 약4~9.2mm였다.
- 카메라 시험에서3cm 폭·6Hz 상하 입력은30/60/120FPS 모두 약5.6mm 폭으로 줄었다(약81% 감소). 230km/h 수평 추적에서 추가 지연은 없었고 경사·정지·도로 복귀도 통과했다.

증거와 실패 기록: `artifacts/ride-polish-20261009/`. 최종 통과 로그는 `final-recheck.log`, 그 전 머스탱 감쇠 비교 실패는 `final-check.log`에 남겼다. `road-before.json`·`flat-before.json`은 물리 진단값이다.

## 브라우저 검수와 한계

수정 전 로컬 제작본의 짧은 실제 출발은56km/h·네 바퀴 접지·충돌0회·표시41FPS였다. 물리 검사 실행 중 개발본 검수에서는 브라우저 렌더링이 매우 느려 출발 카운트가 정상 속도로 진행되지 않았다. 해당 `browser-after.json`은 주행 개선 증거로 사용하지 않는다.

검사 종료 뒤 최신 배포 빌드에서 다시 출발했다. 1280×720 인앱 브라우저의 짧은 출발 검수에서56km/h·네 바퀴 접지·충돌0회·표시43FPS였고 제동/후진 입력·도로 복귀·메뉴 클릭 후 ESC 재개·입력 해제를 확인했다. 증거는 `production-after.json`·`production-flow.json`·`production-after.png`다. 이는 장시간 FPS나 프레임 간격 비교가 아니므로 성능 개선을 주장하지 않는다. 자동 계측의 진동 감소와 프레임 저하를 구분한다.

현재 서버는 [최신 웹 빌드](http://127.0.0.1:5191/)를 제공한다. 기존 페이지에는 새로고침이 필요하다. 사람의 코너·노면 체감 평가와 실제 모바일 장시간 성능 검증은 남아 있다. 공개 GitHub Pages는 이번 변경을 배포하지 않았다.
