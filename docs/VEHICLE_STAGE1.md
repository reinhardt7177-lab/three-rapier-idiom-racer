# 차량 1대 주행 기반 — 2026-09-05

## 범위

기존 항구 차고를 유지하고 별도 `GT 테스트 주행` 모드를 추가했다. 현재 공간은 완성 서킷이 아닌 **1.8km 직선 + 넓은 조작 시험장**이다. 운영 서버 배포는 하지 않았다.

## 구현

- 차고 GT 모델과 선택 색상을 재사용. 바퀴 조향·회전·서스펜션을 실제 물리 상태에 연결.
- Rapier 동적 차체, 네 바퀴 레이캐스트 서스펜션, 차체/지붕/바닥/배리어 충돌체, 고속 CCD.
- 1 unit = 1m. 120Hz 고정 물리 스텝 + 화면 위치 보간. 실제 수평 속도(m/s) × 3.6으로 계기판 표시.
- 네 바퀴 구동, 항력·구름저항, 가속, 제동, 정지 후 후진(30km/h 제한), 속도별 조향각 축소.
- 핸드브레이크는 후륜 제동과 접지력 감소로 구현. 완성된 드리프트 점수/보조 시스템은 아님.
- 평평한 테스트 공간용 기본 추격 카메라. 자동차 앞은 +Z, 뒤는 -Z. 카메라는 후방에서 따라간다.
- 키보드/포인터 조작, 일시정지, 창 이탈 시 입력 초기화와 일시정지, 시작점 복귀, 차고 복귀.
- Rapier 주행 모듈은 차고 진입 시가 아니라 주행 버튼 클릭 후 지연 로딩.

## 조작

| 입력 | 동작 |
|---|---|
| W / ↑ | 가속, 후진 중에는 제동 |
| S / ↓ | 전진 중 제동 → 저속에서 후진 |
| A D / ← → | 조향 |
| B | 제동 전용, 후진하지 않음 |
| Space | 핸드브레이크 |
| R | 시작점 복귀 |
| Esc | 일시정지 / 재개 |

터치 버튼은 누르고 있는 동안만 동작하며 포인터 해제/취소 및 창 전환 시 입력을 해제한다.

## 검증 기록

### 좌우 조향 수정

사용자 실기에서 좌우 반전이 확인됐다. 초기 테스트는 세계 좌표 +X를 우회전으로 가정했으나, +Z 전방/+Y 위쪽인 차량을 뒤에서 바라보는 카메라의 오른쪽은 -X다. 조향 입력은 +1=운전자 오른쪽 의미를 유지하고 Rapier 조향각으로 바꿀 때 부호를 반전했다. 앞바퀴 렌더링도 같은 물리 각도를 사용한다.

이전 기록의 '우회전 확인'은 세계 좌표만 확인한 잘못된 판정이었다. 이를 대체하여 실제 Three.js 카메라 투영으로 3개 진행 방향에서 좌/우를 검증하는 회귀 테스트를 추가했다. 브라우저 검증도 D뿐 아니라 A/D·양쪽 화살표·양쪽 포인터 조향 버튼을 검사하도록 확장했다.

### 최초 검증 기록 (조향 판정은 위 수정으로 대체)

- Node 실제 Rapier: 정지 접지 4/4, 18초 가속 후 **232.2km/h**, 전진 방향과 이동거리, 제동 정지, 후진, 우회전, 리셋, 210km/h 배리어 충돌 관통 방지.
- 추가 회귀: 고속 조향 시 차체 직립, 후륜 핸드브레이크 접지 감소, 타력 감속, 공중 가속 방지.
- Chrome 실제 키 입력: **201.3km/h** 도달 후 정지 **0.06km/h**, 실제 좌표 감소로 후진 확인, 우회전 확인.
- 모바일 포인터 가속, 일시정지 좌표 불변, blur 입력 해제, 차고 색상 유지, 재진입 canvas 1개 확인.
- 스크린샷 검사 후 모바일 계기판을 위쪽으로 옮기고 추격 거리를 늘려 차량 가림 개선.
- `agent-browser` 미설치로 기존 Playwright + Chrome 검증으로 대체.

실행: `npm run check`. 브라우저 검증: `node scripts/verify-driving.cjs` (기존 Playwright/Chrome 환경 필요).
증거: `artifacts/vehicle-stage1/verification.json`, `test-drive.png`, `mobile.jpg`.

## 아직 하지 않은 것

현재 회색 직선·단순 나무·균일한 조명은 물리 검증용 임시 구성이다. AFTERLIGHT 레퍼런스의 조명 대비·재질 밀도·공간 구성을 적용한 최종 미술 시안이 아니다. 차고의 시각 방향은 유지하며, 향후 짧은 해안 구간에 목표 미술을 먼저 적용해 확인한 뒤 서킷으로 확장한다.

해안 순환 코스, 랩/체크포인트, AI, 사운드, 수동 변속기, 타이어 개별 강체, 차체 손상, 코스 전용 카메라 충돌회피는 다음 단계다. 콘과 나무는 시각 가이드이며 충돌 장애물이 아니다. 계기판 단수는 속도 기반 표시이며 실제 기어박스 모델이 아니다.

이는 조정 가능한 아케이드 주행 기반이다. 기기별 60FPS 보장이나 차량 시뮬레이터 수준의 타이어 모델을 의미하지 않는다. 프레임 간격이 100ms를 넘는 환경에서는 물리 누적 시간을 제한하여 폭주를 막으므로 시뮬레이션이 실시간보다 느려질 수 있다. Rapier WASM 포함 주행 청크가 커서 최초 주행 로딩 최적화는 후속 작업이다.
