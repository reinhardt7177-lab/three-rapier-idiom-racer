# 항구 차고 발전 방향 — 디자이너 관점의 2차 수정

2026-09-05. 사용자가 첫 자체 제작 시안을 긍정적으로 평가한 뒤 요청한 계획과 수정.

## 지킬 것

현재의 디오라마 구도, 청록 GT, 차분한 팔레트, 실제 크기에 가까운 정비 소품, 외부 모델/텍스처 없는 코드 제작 방식을 유지한다. 원작 UI나 건물을 그대로 복제하지 않는다. 자동차는 이번에 전면 교체하지 않는다.

## 디자인 판단

| 관점 | 첫 시안의 빈 곳 | 이번 변경 |
|---|---|---|
| 그래픽/공간 | 두 벽 안에서 끝나는 전시 모형 | 뒤쪽 셔터와 외부 부두·바다·크레인으로 근경/중경/원경 연결 |
| 그래픽/재질 | 벽과 바닥이 새것처럼 균일 | 모서리·벽 하단 음영, 빗물 흔적, 벽 상단 부재와 환기팬으로 시간감 |
| 그래픽/구도 | 중앙은 좋지만 배경 설비가 평면적 | 타이어 랙을 옮겨 출입구를 확보, 지붕은 전부 덮지 않고 단면 구조 유지 |
| 게임/행동 | 설정을 바꿔도 다시 열면 사라짐 | 별도 버전 키로 차체 색상·환경 설정을 로컬 저장 |
| 게임/감상 | 화면 요소가 항상 남음 | 포토 모드와 복귀 버튼/Esc, 차량/공간 카메라 프리셋 |
| 게임/연결 | 서킷이 없는데 출전 버튼을 만들 위험 | 실제 동작하는 셔터 열기/닫기만 구현. 주행 미구현 명시 |

## 이번 완료 범위

- 셔터를 열면 항구가 보이고 닫으면 차고 내부의 분위기가 강조되는 장면.
- 과한 안개/블룸 없이 장비·표면·접지 디테일 추가, 기존 약한 반사는 유지.
- 소형 환기팬과 물 표면 움직임. 움직임 줄이기 설정에서는 장식 애니메이션 정지.
- 색상과 분위기 설정 보존. 잘못된 저장값·저장 차단에도 기본 화면은 실행.
- 실제 차고 감상용 포토 모드. 사진 저장/공유·온라인 업로드 기능은 포함하지 않음.
- 브라우저 버튼·저장 복원·포토 모드 탈출·모바일 UI·오류·외부 에셋 요청 검증.

새 설정은 mumu.garage.preferences.v1 하나에만 저장한다. 기존 레이싱/사용자 저장 키를 삭제하지 않는다. 카메라 임의 조작과 포토 모드는 다음 방문에 강제 적용하지 않는다.

## 이후 순서

1. 이번 공간과 사용 흐름에 대한 사용자 의견 반영.
2. 동일 GT의 주행 시험장과 물리 컨트롤러 작성.
3. 실제 서킷이 완주 가능해진 다음 차고 출전/결과 복귀 연결.
4. 차량 모델/장비 커스터마이즈는 이후 선택. 장식 수집·경제·수리 미니게임은 아직 추가하지 않음.

품질은 소품 개수가 아니라 차량 가독성, 출입구 시야, 레퍼런스의 명암/재질 인상, 입력·저장 안정성으로 평가한다. 60FPS 달성이나 게임 완성을 시안 결과로 주장하지 않는다.

## 이번 반영 결과와 검증

- [x] 뒤쪽 창을 실제 출입 가능한 크기의 셔터 공간으로 변경. 열기/닫기 애니메이션과 즉시 전환 지원.
- [x] 타이어 랙을 왼쪽으로 이동해 셔터 앞을 비움. 부두·바다·소형 크레인·화물 배경을 코드로 생성.
- [x] 벽 상단 덮개석, 철골 브래킷, 빗물 흔적, 접지 음영, 환기팬 추가.
- [x] 변경한 색상/환경 설정을 버전 키 하나에 저장. 카메라와 포토 모드는 저장하지 않음.
- [x] 포토 모드와 버튼/Esc 복귀, 별도 환경 설정 패널, 항구 카메라 추가.
- [x] 움직임 줄이기, 숨겨진 탭의 렌더 중지/복귀, 정적 불투명 소품 메시 병합 적용.
- [x] 실제 캡처를 보고 너무 넓고 밝았던 외부 부두를 줄이고 크레인을 배경 크기로 보정.

`npm run check`에서 설정 시험 4개와 빌드 통과. 값 허용 목록, 잘못된 버전/데이터, 저장 예외, 기존 다른 키 보존을 검사했다. 단일 JS 번들의 500kB 초과 안내는 남아 있으며, 성능 목표 달성으로 처리하지 않았다.

번들 Playwright + 설치된 Chrome으로 실제 브라우저 검증을 두 차례 실행했다. 현재 환경에 agent-browser CLI가 없어 검증 스킬의 화면/입력/오류 확인 절차를 대체 도구로 수행했다. JS/콘솔 오류 0, 실패 요청 0, 외부 요청 0, 모델/텍스처 파일 요청 0을 확인했다.

검증 항목: 차체 색상, 카메라 4개, 셔터, 조명, 바닥 반사, 움직임 줄이기, 포토 모드의 Esc/버튼 복귀, 390×844 버튼 경계·가로 넘침, 새로고침 후 설정 복원, localStorage 접근이 차단된 페이지의 실행.

증거는 `artifacts/garage-evolution/`의 garage-overview.png, shutter-closed.png, harbor-view.jpg, car-closeup.png, photo-mode.png, mobile-layout.png, verification.json이다. 전체·항구·모바일 캡처를 직접 확인했고, 구도 보정 후 전체 화면을 다시 확인했다.

수치는 테스트용 헤드리스 브라우저 결과이며 사용자의 실제 GPU 성능을 보장하지 않는다. 주행·서킷·경쟁 AI·차량 성능 업그레이드·사진 저장은 아직 구현하지 않았다. GitHub push/운영 배포는 하지 않았다.
