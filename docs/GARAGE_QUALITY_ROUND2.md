# 차고지 품질 라운드 2

## 적용 내용

- 메인 차량을 중앙 턴테이블에 두고, 카메라 기본 구도를 차량 중심의 3/4 히어로 샷으로 조정했다.
- 바닥에 피트 라인, 서비스 그리드, LED 유도선을 추가해 깊이와 구역 분리를 강화했다.
- 서비스 그리드, PIT CART, 이중 작업등, 벤치·어닝을 추가해 차고지가 빈 배경이 아니라 운영 중인 팀 허브로 보이게 했다.
- 차량 에셋이 로딩되는 동안에도 포뮬러형 플레이스홀더가 보이도록 했고, 실제 GLB가 준비될 때까지 `BOOTING CIRCUIT` 로딩 화면을 유지한다.
- 실제 GLB 차량은 기존 자동 스케일·피벗·휠 탐색 검증을 거친 뒤 히어로 무대에 교체된다.
- 차량별 accent 색이 스펙 패널·무대 조명·선택 카드에 함께 반영된다.
- 모바일에서는 최근 주행 배지를 접고 차량 스펙과 카메라 컨트롤을 우선해 차량이 화면에 남도록 조정했다.
