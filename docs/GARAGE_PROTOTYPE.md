# 자체 코드 차고 — 첫 미술 시안

2026-09-05. 사용자의 “간단히 만들어서 봅시다” 요청에 따른 소규모 구현.

## 구현 범위

- 외부 GLB/FBX·이미지 텍스처·폰트 파일 로딩 없음. 기존 보존 에셋은 삭제하지 않고 사용하지 않음.
- GT 차체 곡면, 휠 아치, 휠/스포크, 유리, 범퍼, 헤드램프, 후미등, 스포일러를 Three.js 형상으로 구성.
- 벽돌/포장 타일은 인스턴싱, 철골·배관·작업대·공구함·타이어 랙·압축기·작은 식물은 자체 부품 조합.
- 바닥 무늬와 간판은 CanvasTexture로 코드 생성. 조명 환경도 Three.js RoomEnvironment에서 생성.
- 부분적인 바닥 반사는 Three.js Reflector를 이용하되 바닥이 보이도록 낮은 불투명도·간단한 흐림 적용.
- 차체 4색, 카메라 3구도, 정비등/중립 조명, 반사 켜기/끄기, 드래그/휠 조작.
- 장면 해제 시 루프·컨트롤·이벤트·GPU 자원 정리. 독립적인 실제 주행이나 물리 검증은 아직 없음.

자체 코드 콘텐츠라는 뜻이며 Three.js·React 등 기반 라이브러리까지 자체 제작했다는 뜻은 아니다. 레퍼런스의 완성품 재현이나 전체 해안 서킷 완성을 주장하지 않는다.

## 실행

프로젝트에서 npm run dev로 실행한다. 이번 로컬 확인 서버는 http://127.0.0.1:5173/ 이다. 외부 접속을 열지 않았고 GitHub push/Vercel 배포는 하지 않았다.

## 검증

- npm run check: 프로덕션 빌드. 첫 빌드는 통과했고 단일 번들 500kB 초과 안내가 있음. 현재 check는 게임 동역학 검사가 아님.
- scripts/verify-garage.cjs: Playwright를 사용할 수 있는 환경에서 실행. 필요하면 NODE_PATH에 설치된 패키지 경로, GARAGE_BROWSER_PATH에 Chrome 실행 파일 경로를 지정한다.
- 이번 환경에서 agent-browser 미설치 때문에 번들 Playwright + 설치된 Chrome으로 대체했다.
- 실브라우저 JS/콘솔 오류 0, 실패 요청 0, 외부 요청 0, 외부 모델/텍스처 요청 0.
- 색상·카메라·조명·반사 UI 상태 전환, 390×844 화면 버튼 경계/가로 넘침, 새로고침 후 단일 캔버스를 확인했다.
- 실제 전체/근접/모바일 캡처를 생성했고 전체/근접 화면을 눈으로 확인했다. 벽의 과한 밝기와 강한 검은 반사를 수정하고 재검증했다.
- 검증 브라우저의 소프트웨어 렌더링 가능성이 있어 FPS 결과를 사용자 GPU 성능이나 60FPS 달성으로 보고하지 않는다.

증거: artifacts/garage-prototype/garage-overview.png, car-closeup.png, material-comparison.png, mobile-layout.png, verification.json. JPEG는 동일 화면의 경량 검수 캡처다.

## 아직 하지 않은 것

해안 원경·셔터·천장 상세, 대표 차량의 최종 모델링, 실제 가속/조향/충돌, 랩·AI·기록·저장, 접근성 전체 검수, 실제 모바일 GPU 성능 측정, 장시간 누수 측정은 후속 범위다. 우선 사용자가 이 자체 제작 방식의 모양과 분위기를 판단하기 위한 시안이다.
