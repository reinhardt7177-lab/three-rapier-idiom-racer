# 차고지 품질 라운드 6

## 이번 라운드 목표

차고지의 정적 화면 품질을 넘어, 프리셋 전환과 초기 부팅이 실제 게임 메뉴처럼 느껴지도록 다듬었다.

## 반영 내용

- FRONT·ORBIT·SERVICE 프리셋 전환을 즉시 컷에서 0.72초 보간 카메라로 변경
- 프리셋 전환 중 FOV와 카메라 위치를 함께 보간해 차량이 튀지 않도록 조정
- 차고 장식용 GLB를 첫 프레임에 모두 파싱하지 않고 브라우저 유휴 시점에 지연 배치
- 지연 배치 콜백에 런타임 생명주기 가드를 추가해 차량 교체·화면 전환 뒤 유령 오브젝트가 남지 않도록 처리
- 물리 엔진은 기존처럼 레이스 시작 시 동적 import되며 차고지 첫 화면에는 Rapier를 로드하지 않음

## 검증 기준

| 항목 | 결과 |
|---|---|
| 차고 콜드 로딩 3초 시점 | 로딩 오버레이 없이 쇼룸 화면 표시 |
| 카메라 전환 | SERVICE 중간 프레임에서도 차량이 끊기지 않고 이동 |
| 지연 장식 로딩 | 배치 완료 후 콘솔 오류 없음 |
| 레이스 진입 | Rapier 동적 로드 후 카운트다운 정상 |
| 런타임 수명 | 재시작·차량 교체 뒤 지연 에셋 중복 방지 |
