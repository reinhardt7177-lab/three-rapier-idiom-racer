# 다음 작업과 품질 통과 기준

작성 기준: 2026-09-06. 원칙은 [AGENTS.md](../AGENTS.md)를 따른다.

**후속 구현:** 사용자가 주행 검증과 완결된 플레이 제작을 요청해 [돌아오는 불빛](SIGNAL_JOURNEY.md)을 추가했다. 아래는 작업 전 기준과 품질 기준이며, 현재 실행 결과와 제한은 후속 문서를 우선한다. 삼성 태블릿 실기기 검증은 여전히 남아 있다.

## 현재 판단

차고의 미술 방향과 차량·공도·첫 의뢰의 기반은 있다. 하지만 이를 완성된 게임으로 판단하기에는 실기기 검증과 이어지는 플레이 경험이 부족하다. 다음 작업은 맵이나 차량 수 확대가 아니라 **현재 한 구간의 조작·가시성·안정성 검증**이다.

- 최근 기록: `npm run check` 40개 시험과 빌드 통과. 태블릿 HUD 6개 화면 크기, 첫 의뢰, 차량 주행, 속도감 브라우저 검증 통과.
- 한계: 브라우저 화면 크기/터치 검증은 실제 갤럭시 탭의 GPU 성능·발열·손 조작 검증이 아니다.
- 새 HUD 반영 후 해안도로 장거리 왕복 브라우저 검증은 아직 재실행하지 않았다.
- 현재 태블릿 HUD 변경은 로컬 작업이다. 이전 PR과 운영 배포에 반영되었다고 가정하지 않는다.
- 통행 AI, 다음 스토리 챕터, 전체 공도의 동일한 미술 완성도는 아직 없다. 이는 미구현 범위이지 이미 발견된 버그와 같지 않다.

세부 증거와 제한: [태블릿 HUD 기록](TABLET_DRIVING_HUD.md).

## 1순위 — 현재 버전의 주행 품질 검증

### 개발 환경에서 먼저

1. 현재 코드로 `npm run check`와 해안도로 왕복 검증을 실행한다. HUD 변경 영향을 받은 조향·항구 충돌 검증도 재실행한다.
2. 차고 → 공도 → 갈림길 → 전망대 정차 → 회차 → 차고 복귀 → 재출발을 확인한다. 첫 의뢰 흐름도 별도로 확인한다.
3. 메뉴·회전·앱 전환·터치 취소 중 입력과 시간이 안전하게 멈추는지, 재개 시 가속이 붙어 있지 않은지 점검한다.
4. 코너 진입, 도로 가장자리, 목적지 안내가 실제 주행 카메라에서 보이는지 확인한다. 중앙 사각형 겹침 시험은 보조 지표이며 전체 가시성의 증명이 아니다.
5. 번들 크기와 첫 진입 로딩을 계측한다. 빌드 성공만으로 태블릿 로딩 품질을 통과 처리하지 않는다.

### 실제 삼성 태블릿에서

정확한 모델을 확보하면 모델명·OS·Chrome/Samsung Internet 버전·화면 방향·그래픽 설정을 함께 기록한다. 기기 접근이 없으면 사용자의 테스트 결과를 요청하고 미검증 항목을 유지한다.

- 경량/표준 각각 최소 10분 주행: 프레임 시간의 중앙값·95백분위·긴 멈춤, 시간 경과에 따른 성능 저하와 발열 체감을 기록한다.
- 경량 모드에서 안정적인 30FPS 이상을 초기 목표로 둔다. 이는 측정 전 보장 수치가 아니며, 실제 지원 범위는 결과로 결정한다.
- 두 엄지로 가속+조향, 제동 전환, 핸드브레이크를 사용해 버튼 간격·손 피로·의도치 않은 입력을 확인한다.
- 가로/세로 전환, 주소창 변화, 앱 전환과 복귀, 소리 켜기, 차고 재진입을 확인한다.
- 입력 고착·진행 차단이 없어야 한다. 시야 방해와 성능 문제가 남으면 심각도와 허용 여부를 명시하고 관련 확장을 보류한다.

검증용 배포가 필요하면 별도 승인을 받아 PR/미리보기를 갱신한다. 이 계획 작성으로 자동 푸시·운영 배포하지 않는다.

## 2순위 — 3~5분짜리 하나의 완결된 경험

1순위의 중대한 문제가 해소된 뒤 진행한다.

- 차고에서 목적을 이해하고 출발 → 해안 구간의 작은 사건 → 목적지 정차 → 결과와 차고 복귀로 연결한다.
- 기존 첫 의뢰와 자유 주행의 연결 방식을 먼저 설계한다. 새 기능을 여러 개 넣기보다 한 번 끝까지 플레이할 이유와 완료 피드백을 만든다.
- 공도의 목적은 무조건 최고속도 유지가 아니다. 직선 가속·코너 감속·전망 구간의 완급과 안전하게 읽히는 도로를 만든다.
- 안내를 읽느라 전방을 놓치지 않는지, 처음 하는 사람도 외부 설명 없이 끝낼 수 있는지 플레이 테스트한다.

## 3순위 — 검증된 구간의 미술과 연출 완성

- 차고의 석재·철골·동관·차분한 해안 색감을 공도의 대표 구간에 일관되게 적용한다.
- 가까운 도로 디테일, 코너 표식, 가로등·난간의 간격, 원경 랜드마크로 공간과 속도를 읽게 한다.
- 연출을 늘릴 때마다 시야·멀미·드로 콜·프레임 시간 회귀를 확인한다. 과한 블룸이나 흔들림으로 속도감을 대신하지 않는다.
- 위 흐름이 재미있고 안정적이라는 근거가 생긴 뒤 통행 AI·추가 사건·차량 컬렉션·맵 확장을 검토한다.

## 검증 기록 형식

각 문제를 `재현 조건 / 기대 동작 / 실제 동작 / 심각도 / 증거 / 수정 / 재검증 / 남은 제한`으로 남긴다. 완료 보고에서는 통과한 범위와 미검증 범위를 함께 적는다.
