## 범위와 현재 상태

사용자가 요청한 Game Studio 점검으로 그래픽·차량 표현·입력을 검토했다. 새 접지/드리프트 후보는 여수 교통 완주를 악화시켰다. 사용자의 **‘안정 물리를 유지하고 표현·입력 검수 마무리’** 결정에 따라 후보를 보류하고 기존 물리를 유지했다. **최종 npm run check 526/526·웹 빌드 통과, 핵심41레이스246대 전원 완주·추락/이탈0.** 이번 결과는 로컬 반영이며 새 커밋·푸시·PR·main 병합·운영 배포는 없다.

브랜치: `codex/korea-circuits-progression-20261011`, 시작 HEAD `26fd4d50fba4b5174a97d93920b2b48ca0a07aa8`. 수정 전 파일, 실패 로그, 후보는 `artifacts/game-studio-20261103/`에 보존했다. Colab과 Kiro는 사용하지 않았다.

## 적용한 변경

- **여수 차량 반사:** 차고 조명 대신 청색 수평선·작은 호박색 항구 조명으로 별도 환경을 굽는다. 기존 PMREM 두 개 예산을 유지하며 실시간 조명을 추가하지 않는다. 실제 도시 위치를 반사하는 SSR/레이 트레이싱은 아니다.
- **노면:** 공용 64px 그레인을 재사용해 네 코스의 표면 법선과 미세 거칠기를 보완했다. 경사·축소 시 강도를 줄이며 젖은 노면의 기존 거칠기를 보존한다. 새 텍스처·기하·드로 패스는 없지만 남악 이외 코스에는 픽셀당 텍스처 조회가 하나 추가된다. 비용은 별도 측정한다.
- **야간 배기:** 낮의 흰 입자를 그대로 빛내던 색을 어두운 청회색으로 조정했다. 배기 위치·수명·입자 96개 상한·타이어 연기는 유지한다.
- **복귀 안전성:** 복귀 위치 탐색이 라이벌뿐 아니라 일반 교통 차량의 현재/예측 위치도 피한다. 기존 뒤쪽 탐색·아스팔트 확인·간격 기준을 유지한다.
- **터치 드리프트:** 키보드 Shift와 같은 입력을 터치 DRIFT에도 연결했다. 일곱 필수 버튼은 작은 가로 화면에서 두 줄로 재배치한다. 포인터 소유권·취소·메뉴 해제 규칙을 재사용한다.
- **메뉴 키보드:** 대화상자 진입 시 활성 조작에 초점을 두고 Tab 순환을 메뉴 안에 유지한다. 화면 재배치/온라인 오류로 기본 버튼을 못 쓰는 경우 보이는 활성 버튼을 선택한다.

물리 자세 고정, 차체 충돌체, 조향/접지 계수, AI 튜닝, 온라인 동기화, 메달 기준, 경로/도로 기하는 바꾸지 않았다. 기존 차체 스프링 표현·바퀴·1/3인칭은 회귀 검수 대상으로 유지했다.

## 발견·수정과 남은 위험

1. 독립 읽기 전용 코드 검토에서 젖은 도로의 거칠기를 0.65로 강제하던 새 shader 오류를 발견했다. 실제 식을 평가하는 실패 시험으로 재현하고 비의 0.48 기준을 유지하도록 수정했다.
2. 미분으로 만든 축소 계수를 다시 미분하던 이식성 위험을 제거했다. 높이의 1차 미분 뒤 강도를 곱하며, 퇴화 표면 분모를 보호한다. 관련 시험과 실제 WebGL 화면을 확인한다.
3. 기존 복귀 탐색의 일반차 누락·터치 드리프트 부재·메뉴 초점 문제를 재현하고 수정했다. 새 320px 버튼 잘림도 수정했다.
   첫 최종 전체 검사는 526개 중 525개가 통과했다. 바뀌지 않은 비남악 지형의 캐시 키까지 v2로 올려 성삼재의 기존 연결 계약 한 건이 실패했다. 단일 시험으로 같은 실패를 다시 확인하고, 변경된 도로 키만 v2로 올리도록 수정했다. 기존 시험을 변경하지 않고 관련 23/23 통과했다. 첫 전체 실패 로그는 `npm-check-cache-failure.log`에 보존했다.
4. 기존 접지/드리프트 체감 한계는 남는다. 후보의 좋은 평지 수치로 기존 완주 악화를 덮지 않았다. 다음 물리 재작업은 별도 사용자 결정과 여수 교통 통과가 필요하다.
5. 실제 두 기기/다른 네트워크 1:1, 휴대폰/태블릿 동시 터치·노치·발열, 높은 품질 장시간 측정, 카메라 벽 가림 재현은 이번에 지원 완료로 주장하지 않는다. 카메라 가림은 코드상 위험이며 확정 재현 결함과 구분한다.
