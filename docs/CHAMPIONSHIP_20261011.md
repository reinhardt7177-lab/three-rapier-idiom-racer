## 구현과 현재 검증

남악 시티 → 여수 밤바다 → 지리산 성삼재를 같은 차량·난이도·랩 설정으로 달린다. 순위별10/6/4/3/2/1점을 합산한다. 차량·난이도·랩은 시리즈 중 고정하며 종료 후 다시 선택한다. 코스 이동은 현재 라운드의6대 실제 완주 시간이 모두 확인된 뒤 열린다. 플레이어가 먼저 완주해도 남은 라이벌을 멈추지 않는다.

- 진행 체크포인트는 해당 탭의 sessionStorage, 난이도/랩별 시리즈 최고 기록은 localStorage에 저장한다. 클라우드 계정·브라우저 간 동기화가 아니다.
- 동점은 승리 횟수 → 실제 완주 시간 합계 → 동일한 경우 고정 참가자 순서로 정한다. 최고 기록도 점수를 시간보다 먼저 비교한다.
- 순서가 다른 코스·중복 라운드·중복/누락 참가자·완주하지 않은 차량·잘못된 시간은 점수로 확정하지 않는다. 손상된 체크포인트는 재사용하지 않는다.
- 저장을 사용할 수 없으면 시리즈 시작/이동을 막고 이유를 표시한다. 싱글 레이스는 유지한다. 최고 기록 저장 실패는 완주 결과를 지우지 않는다.
- 결과 뒤 R키로 이미 점수를 확정한 라운드를 몰래 다시 시작하지 않는다. 화면의 다음 코스/차고 버튼으로 이동한다. 주행 중 R 재시작은 유지한다.

## 남은 위험과 다음 기능

이 기능이 마무리돼도 요청 전체 완료가 아니다. 메달 해금·라이벌 성격·다른 코스 야간은 아직 구현하지 않았다. 기존 런타임 라이벌의 자동 복귀는 다음 성격 작업에서 제거하고 페달을 통한 탈출과 모든 코스의 완주를 확인해야 한다. 실제 두 손가락·브라우저 포커스/포인터 취소의 모든 조합도 확인하지 않았다.

PR 생성/병합·Vercel 배포는 하지 않는다. 테스트 기준 완화나 성능 수치를 가리는 작업은 하지 않았다.
