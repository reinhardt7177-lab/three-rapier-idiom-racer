## 남악 성능: 세 실험과 한계

같은 IAB 세션, 1280×720, DPR 1.25, 보통 난이도, 수프라, 3인칭, 출발 후 30초 구간에서 A/B/A를 실행했다. 검수용 운전기는 실제 조향·페달을 입력한다. 시간을 대체하거나 차량/진행 거리를 이동시키지 않는다. 각 조건은 30,000ms 이상이며 전체 프레임과 CPU 제출 표본을 보존했다.

고스트 표시와 양면 투명 재질의 CPU 비용은 관측했으나, 챔피언십 전후의 9.74→19.66ms 증가 원인을 하나로 **확정하지 못했다**. A로 돌아온 뒤에도 비용이 달라지는 PC/브라우저 변동이 있다. 850ms 지연과 그때 발생한 시뮬레이션 시간 손실 0.60초를 삭제하지 않았다. 그 조건의 구간 끝은 약 916m, 다른 조건은 약 940m이므로 완전히 같은 경로 지점별 비교라고 주장하지 않는다.

`frozenComparison`은 일시정지한 정지 화면을 검사하는 장치다. 이번 실제 주행 비교에서는 계속 비활성이었고, 세 번째 실험은 GPU 타이머와 프로파일 훅만 켰다. 따라서 frozenComparison 자체의 별도 A/B는 미검증이다. 세 실험 제한을 넘겨 재진단하지 않는다.

FrontSide 시험에서 뒤쪽 외관 캡처(`ghost-material-1.png`)를 남겼다. 유리 내부·앞면의 모든 각도를 검증하지 않았으므로 제품 고스트 재질은 기존 양면을 유지한다. 낮음 품질은 고스트를 표시하지 않는다.

원본: `experiment-1-ghost.json`, `experiment-2-material.json`, `experiment-3-instrumentation.json`. 결과와 원본 표본은 모두 `artifacts/content-resume-20261011/`에 있다.

### UI·오류 검증

1280×720, 1024×768, 844×390, 667×375의 실제 iframe 내용 창에서 차고와 품질 메뉴의 경계 및 겹침을 측정했다. 네 크기 모두 최종 잘림·겹침 0건이다. `quality-ui-<폭>.json`, `quality-actual-*.png`에 경계와 화면을 남겼다. 휴대폰 실기기 검증이 아니다.

첫 브라우저 viewport 도구 요청은 실제 크기를 바꾸지 못했다(네 요청 모두 1280×720). 그 결과는 `quality-ui.json`으로 보존하고 통과 판단에 사용하지 않았다. 실제 iframe 검증으로 전환했다. 차고 코스 버튼과 제목이 13px 겹치는 문제를 발견해 제목을 아래로 옮겼고 네 크기에서 재검사했다. 개발 HMR 중 ResizeObserver가 이미 해제된 ref를 읽는 오류도 방어했다.

첫 품질 측정은 선택 적용을 확인하기 전에 시작했고 개발 갱신으로 초기화됐다. `quality-attempt-1.json`으로 보존했으며 성공 표본에서 제외했다. 낮음 선택·실제 DPR 0.75를 확인한 뒤 유효한 30초 표본을 수집했다.

### 전체 검사

- 성능 계측 변경: Colab CPU `npm run check`, **259/259 + 빌드 통과**, 200.38초, 로컬/원격 144개 입력 해시 일치.
- 첫 실행은 259 시험 통과 후 빌드가 실패했다. 원인은 원격 복사 과정에서 Vite 실행 심볼릭 링크가 일반 파일로 바뀐 것이다. 해당 작업용 폴더의 링크를 복원하고 전체 명령을 재실행했다. 실패 로그도 보존했다.
- 품질 변경: Colab CPU `npm run check`, **261/261 + 빌드 통과**, 256.96초, 152개 입력 해시 일치. 마지막 제목 CSS 수정까지 포함한 최종 재검사도 **261/261 + 빌드 통과**, 200.60초, 154개 입력 해시 일치다. 로컬 최종 빌드 파일명도 Colab 빌드와 일치했다.

콘텐츠 전 추가 30초 표본(같은 1280×720/3인칭/계측 끔): 해안 낮음 평균 28.38/p95 83.20/최대 133.40ms/>50ms 101회, 해안 높음 27.22/33.50/83.40ms/12회, 남악 높음 27.21/50.00/166.60ms/30회. 나쁜 표본도 보존했다. 높음 남악의 p95가 같은 코드에서 33.5→50ms로 변동하므로 이 PC에서 실행별 변동이 크다는 제한을 남긴다. 낮음의 남악 통과 결과를 모든 코스/구간으로 확대하지 않는다.

해안 최초 로딩 관측은 DEV/캐시 혼합이다: encoded 30,798,201 bytes, transfer 23,332,050 bytes, 재검증 87건. 콜드 제품 다운로드 수치라고 주장하지 않는다. GLB·오디오 추가 없이 품질 변경 제품 JS는 gzip 82.59kB, CSS 6.23kB이다(성능 계측 단계 JS 81.36/CSS 5.99kB).

원격 브리지 재연결 중에는 검증 완료로 처리하지 않았다. 기존 원격 작업을 다시 실행하지 않고 저장된 결과부터 회수했다. 브라우저의 기존 AX 경로가 응답하지 않은 뒤 정상적인 DOM 검사 API로 화면 제어를 복구했다.

계산은 실제 Colab CPU에서 실행했다. GPU 계산을 했다고 주장하지 않는다. 노트북의 다른 프로젝트 셀과 파일은 보존했다.

## 메달 해금 · 검증

처음에는 차량5종과 코스3개를 제공한다. RX-7·성삼재는 메달1개, M3는2개, Huracán은4개로 열린다. 코스와1/3랩 조합마다 메달1개이며 같은 레이스의 색을 올려도 개수가 늘지 않는다. 기존 최고 기록에서 복원하며 진행 중인 기존 챔피언십의 차량도 보존한다. 잠긴 코스의 직접 URL에서도 출발을 차단한다.

- 실제 Colab CPU 전체 검사264/264+빌드 통과. 첫208.80초, 작은 화면 메달 표시 수정까지 포함한 최종209.60초, 로컬/원격157입력 해시 일치.
- 실제 헤드리스 남악6대 완주84.15~87.04초, 플레이어84.69초, 노면 상대 최저 높이0.51m 이상. 메달 저장 후 성삼재가 열린다.
- 브라우저 새 검수 origin에서 남악84.46초·은메달·6대 완주 → RX-7/성삼재 해금 → 차고 복귀 → RX-7 선택을 확인했다. 이어 여수85.28초·동메달·6대 완주 → M3 해금을 확인했다. 기존 사용 origin의 기록은 삭제하지 않았다.
- 네 실제 내용 창에서 차고와 새 해금 안내가 있는 결과 화면 잘림·겹침0건. 작은 화면에서 진행도/잠금 조건이 숨겨지는 문제를 발견해 표시 영역을 분리하고 네 크기 차고를 다시 확인했다.
- 남악 낮음30초 평균16.68/p9516.90/최대33.40ms/>50ms0회, CPU제출5.32ms. 이전16.80ms 대비p95+0.10ms.
- 해안 높음 최초 적용본은23.17/49.70/216.60ms/>50ms20회, CPU11.37ms로 이전p9533.50보다 나빴다. 나쁜 표본을 보존하고 해금 전 사본의 네 변경 파일 해시가 품질 최종본과 일치함을 확인했다. 같은 세션/1280×720/DPR1.25/카메라/실제 페달/고스트 없음/30초 구간에서 적용본→사본→적용본 p9549.70→50.10→50.10ms, CPU평균11.37→11.30→12.57ms였다. 사본과 마지막 적용본의 끝 지점/시뮬레이션 시간/시간손실도 일치한다(약911m/30.03초/0초). 메달 기능의2ms 초과 악화는 이 비교에서 재현되지 않았다. PC의 큰 변동이 해결됐다는 뜻은 아니다.
- 새 GLB·오디오 추가0bytes. 최종 제품 JSgzip83.54kB/CSS6.35kB(품질 단계82.59/6.23). 남악 새 DEV origin의 첫 관측 encoded34,261,331/transfer34,293,731bytes, cacheHits0; 개발 모듈을 포함하므로 제품 콜드 로딩 수치로 확대하지 않는다.

DEV 검수 페달은 측정 완료 때 꺼진다. 첫 재개와 iframe 상단 클릭에서 켜짐을 확인하지 못해 정차한 검수 시도를 보존했다(`progression-flow-attempt-1/2.json`). 키보드 활성화와 실제 켜짐을 확인한 새 출발에서 위 완주를 얻었다. 이 시간 손실을 완주 기록에서 빼거나 메달 기준을 완화하지 않았다.

실제844×390 내용 창에서 KeyW down/up, GAS·조향·BRAKE pointerdown/up/lostpointercapture, ESC 메뉴 진입을 관측했다. 메뉴에서 throttle/brake/steer=0이다. 단위 시험은 두 입력 소유자·취소·포커스 상실을 포함한다. 실제 다중 손가락/휴대폰 검수는 아니다. `progression-browser-input.json`에 사건과 상태를 남겼다.
