# MUMU CIRCUIT — Visual Direction

학습 게임의 흔적을 제거하고, **저폴리 서킷 페스티벌**을 핵심 콘셉트로 잡는다.

## 레퍼런스 보드

- [Race Condition — 저폴리 피트·관중석·컬러 블로킹](https://store.steampowered.com/app/1209950/Race_Condition/)
- [Forza Horizon — 페스티벌 스타트와 레이스 HUD](https://forza.net/horizon)
- [PolyTrack — 모듈형 트랙과 타임어택](https://kodub.itch.io/polytrack)
- [pmndrs Racing Game — React/Three.js 카메라·차량 구조](https://github.com/pmndrs/racing-game)

## 적용 원칙

1. 초록 지형과 진회색 노면, 시안·노랑 포인트 컬러를 강하게 대비한다.
2. 출발선은 표지판·조명·콘·배리어를 밀집시켜 페스티벌 허브처럼 만든다.
3. 카메라는 추적·범퍼·드론 3종으로 속도와 트랙 구조를 모두 보여준다.
4. Kenney CC0 차량·도로·토이 트랙 팩은 전체 보관하고, 화면에는 구간별로 선별 배치한다.
