# 웹 렌더링 최적화 · 2026-10-09

## 문제와 변경

복구 월드는 558개 메시와 약 300만 삼각형을 포함한다. 숲의 나무줄기·잎과 일부 건물 장식이 수백 미터 범위의 메시로 묶여 있어, 일부만 보여도 그 덩어리를 전부 그렸다.

`src/rebuild/worldRendering.js`에서 큰 정적 장식을 XZ 256m 구역으로 나누고, 같은 구역의 작은 장식은 재질·정점 속성·그림자·레이어 설정이 같은 경우 묶는다. 큰 숲은 분할하여 화면 밖 구역을 제외하고 작은 표지판은 묶어서 호출 부담을 줄인다. 실제 월드는 64개 큰 메시에서 500개 구역 조각을 만들고 281개 호환 객체를 42개 묶음으로 합친다. 최종 메시 수는 755개로 늘어난다. 전체 메시 개수 감소가 목표가 아니다.

삼각형, 정점 색상·법선·UV와 원래 재질을 보존한다. 도로·160개 충돌 메시와 스폰에 쓰는 객체는 대상에서 제외한다. 차량·서스펜션·120Hz 물리·카메라·화질 설정은 유지한다. 월드와 세 차량 GLB의 변경 전후 해시를 검증한다.

Three.js의 [Frustum](https://threejs.org/docs/pages/Frustum.html)으로 메시 범위별 가시성을 판단할 수 있게 경계 상자·구를 다시 계산한다. [renderer.info](https://threejs.org/docs/pages/WebGLRenderer.html)의 프레임 통계를 명시적으로 초기화하여 본 장면과 그림자 패스의 그리기 횟수·삼각형을 합산한다. 프레임 간격의 평균·95백분위·최대·50ms 초과 횟수도 진단 데이터에 남긴다.

## 비교 방법과 증거

`artifacts/render-polish-20261009/inspection.html`은 실제 GLB·차량 여섯 대·같은 카메라와 PBR 조명·2048 그림자를 쓰는 로컬 검수 페이지다. 같은 페이지에서 원본을 측정한 후 최적화를 적용한다. 각 장면은 예열 2초, 측정 12초다. 창 크기 변화나 탭 이탈 시 측정을 취소한다.

Windows의 Codex 인앱 브라우저, 캔버스 1280×555 CSS px, 픽셀 비율 1.25. GPU/CPU 모델은 확인하지 않았다. 정지 장면이며 Rapier 주행 연산을 포함하지 않는다. 물리와 함께 실행하는 최종 빌드는 별도 검수한다.

초기 비교에서는 결과 줄 증가로 스크롤바가 생겨 항구 후측정 폭이 1265px로 줄었다. `initial-benchmark.json`에 그 결과를 보존하고 최종 비교에서 제외했다. 검수 페이지의 바깥 스크롤을 막고 각 기록에 해상도를 포함해 다시 측정했다. 초기 30→약50 FPS 관찰은 재측정 결과와 구분한다.

## 검증 범위와 남은 작업

- 구역 분할·합치기에서 모든 삼각형과 정점 속성, 월드 변환, 충돌 객체, 공유 자원 수명을 검사한다.
- 숲 시험 데이터는 실제 프러스텀을 이용해 보이는 구역과 제외되는 구역이 모두 생기는지 확인한다.
- 프레임 계측은 느린 프레임과 재설정 동작을 확인한다.
- 기존 충돌·입력·차량 리그·여섯 차의 전체 6.84km 주행 회귀 시험을 수행한다.

최종 `npm run check:rebuild`: **49개 통과 / 실패0**, 약19.1초. Vite 웹 빌드 통과, 기존 500kB 청크 크기 경고 유지. 로그는 `final-check.log`. 최초에는 숲 시험의 열 간격240m가 새256m 구역보다 작아 10개 분할 기대가 실패했다. 열 간격을320m로 하여 서로 다른 구역을 검증하고 모든 삼각형·속성 일치와 4m 이하 폭 검사 강도를 유지했다. 최초 실패 로그는 `check-cell-fixture-failure.log`에 보존했다.

최종 빌드 브라우저 검수:

- 세 차종 차고 선택, 수프라 레이스 출발·약129km/h 가속·제동43km/h 확인. 직진만 입력해 커브를 벗어난 뒤 아래 지형에 도착했으며 C 도로 복귀로 높이10.32m·4륜 접지·0km/h·중립 입력 복원 확인. 새 렌더링 분할이 충돌 지형을 바꾼 결과로 해석하지 않는다.
- 메뉴 클릭 후 ESC 재개, 차고 복귀·새 레이스 출발 확인. 오류 콘솔0건.
- 실제 주행의 650×668 / 픽셀비1.25 / 240프레임 구간은 평균16.81ms, p95 16.8ms, 최대33.4ms, 50ms 초과0회. `production-driving.json`, 복귀 후는 `production-recovered.json`. 특정 구간의 약4초 기록이며 원본 대비 주행 FPS 비교는 아니다.
- 844×390 가로 화면 회전 때 일시정지·재개 후52km/h, 390×844 세로 화면에서 새 레이스61km/h와 터치6버튼 표시·차고 복귀 확인. 임시 화면 크기는 복원했다. 직접 손가락 두 개로 운전한 모바일 시험은 아니다.
- 가로 높이390px에서 터치 버튼이 차체 뒤쪽과 겹친다 (`landscape-driving.png`). 기존 UI 배치의 잔여 문제이며 다음 UI 정리 항목이다.
- `hash-check.json`: 월드·수프라·SLK·머스탱 GLB SHA256 모두 유지.

원본 로딩 뒤 구역을 나누는 일회성 CPU 작업이 추가된다. 장시간 주행, 모바일 실기기 메모리·발열·동시 터치는 별도 검증이 필요하다. 정지 장면 평균 FPS를 모든 구간의 주행 성능으로 해석하지 않는다. 현재 변경은 로컬 웹 제작본이며 공개 Unity v53에는 반영하지 않는다.
