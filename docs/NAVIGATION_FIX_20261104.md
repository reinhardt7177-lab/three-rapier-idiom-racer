## 원인과 수정

- 세계 좌표는 위쪽 +Y, 기준 진행 +Z다. 차 뒤에서 +Z를 보는 운전자 화면에서는 +X가 왼쪽이다. 기존 `atan2(dx,dz)` 변화량의 양수를 오른쪽으로 분류해 네 코스에서 좌우가 반전됐다.
- 기존 heading 배열만 사용한 시험도 같은 잘못된 부호를 기대했다. 실제 중심선 위치·도로 접선·Three.js 카메라 투영으로 독립적으로 판정하는 시험을 추가했다. 문턱값을 낮추지 않았다.
- `routeGuidance.js`에서 양수→left/음수→right로 수정했다. 좌우 SVG를 각각 명시하고 CSS 미러 변환을 제거했다. 이 SVG 변경으로 성능이 좋아졌다는 주장은 하지 않는다.
- 표시 거리에 따른 기존 안내·종료·랩 계약을 유지한다. 경로, 충돌, 물리, AI, 교통량, 메달, 그래픽 품질을 바꾸지 않았다.

수정 제품 파일은 `src/rebuild/routeGuidance.js`, `main.jsx`, `rebuild.css`다. 새 `scripts/navigation.test.mjs`를 전체 검사에 등록하고 기존 방향 기대값 4곳을 독립 기하 근거로 교정했다.
