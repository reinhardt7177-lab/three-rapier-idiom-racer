# 차고지 품질 라운드 5

## 이번 라운드 목표

차량을 고르는 메뉴가 아니라, 실제 팀 정비소에서 머신을 출고하는 느낌이 나도록 차고지의 시선 흐름과 전시 연출을 정리했다.

## 반영 내용

- 영웅 차량을 더 가까운 전시 카메라로 배치해 차체와 휠 실루엣이 먼저 읽히도록 조정
- 원형 전시 플랫폼과 저강도 색상 링을 추가하되, 시야를 가로지르는 과한 아치 연출은 제거
- 서비스 베이에 좌우 리프트 기둥과 경고등을 추가
- `LIVE / DIAGNOSTICS` 패널에 상태 바를 추가해 빈 화면처럼 보이지 않게 구성
- 차고 후면의 천장 기둥·정비 동선·피트 라이트를 보강
- 최근 주행 카드와 선택 차량 카드를 세로로 분리해 겹침 제거
- 카메라 버튼을 차량 스펙 카드 아래로 이동해 정보 계층을 고정
- Retro Urban GLB가 참조하는 원본 PNG 텍스처 22종을 함께 배치해 외부 텍스처 누락 오류 제거

| 항목 | 기준 | 결과 |

| 차량 주목성 | 차가 UI 뒤에 묻히지 않고 중앙 주인공으로 읽힘 | 통과 |
| 카드 충돌 | 최근 주행·차량 스펙·카메라 컨트롤이 서로 겹치지 않음 | 통과 |
| 차량 규격 | APEX GT와 VOLT X 선택 시 화면 점유율이 안정적임 | 통과 |
| 피트 분위기 | 후면 그랜드스탠드·리프트·진단 패널이 화면에 층을 만듦 | 통과 |
| 모바일 회귀 | 기존 모바일 전용 배치 규칙 유지 | 기존 검증 통과 |
